Micah Lee의 블로그 글 "Just say no to OpenAI and Anthropic"을 옮겼어요. 글쓴이의 강한 정치적 표현은 원문 주장으로 전하되 일부는 순화했어요.

### 출발점
글쓴이는 Naomi Klein과 Astra Taylor의 책 *End Times Fascism and the Fight for the Living World*를 읽고, 미국 프런티어 랩을 이끄는 이들이 '기계 신'을 만든다고 믿고 AGI를 위해서라면 세상을 태워도 괜찮다고 여기며 자신들만 그걸 안전하게 다룰 수 있다고 믿는다는 생각을 굳혔대요. 그는 LLM이 매우 강력하다고 보는 소프트웨어·보안 엔지니어이지만, OpenAI와 Anthropic이 특별하지 않고 **오픈 웨이트 모델도 취약점 연구 같은 복잡한 작업까지 거의 비슷하게 잘한다**고 말해요.

### 오픈 웨이트의 장점
- 충분한 RAM이 있으면 자기 하드웨어에서 비공개로 돌릴 수 있어요.
- 보안 엔클레이브로 비공개 추론을 해 주는 Tinfoil 같은 곳을 쓸 수 있어요.
- 개인정보가 큰 문제가 아니면 저렴한 제공자가 많고 쉽게 갈아탈 수 있어 한 업체에 묶이지 않아요.
- 그가 보기에 지구의 삶을 걸고 도박하는 이들을 재정적으로 돕지 않아도 돼요.

### ChatGPT와 Claude는 비공개가 될 수 없다
강력한 모델은 닫힌 형태로만 제공되고, 업체는 사용자가 하는 모든 걸 볼 수 있어요. 학습 제외 체크박스가 있어도 대화 기록에 접근할 수 있고, 정부나 회사와 공유할 수도 있다고 지적해요.

### 기업 문지기
보안 관련 작업을 해 본 사람이면 알듯이 가드레일이 엄격해요. 세션마다 대화를 지켜보는 '경찰 에이전트'가 해킹 의심 시 세션을 멈추고, 오탐이 잦대요. 반면 OpenAI의 Trusted Access for Cyber, Anthropic의 Cyber Verification Program에 승인된 곳(미국 보안 기업, 아마도 군 계약사와 정부)은 제한이 덜한 모델을 써요. 누가 강력한 모델에 접근할지를 Sam Altman과 Dario Amodei가 정권과 협의해 정하는 건 비민주적이라고 비판하고, 특권을 구걸하기보다 GLM-5.3 같은 모델을 쓰는 법을 익히자고 해요.

### 오픈 웨이트 모델 현황
- 오픈 웨이트는 독점 모델보다 **약 4개월** 뒤처져 있고, "4개월은 아무것도 아니다"라고 해요.
- **GLM-5.3**은 체감상 소프트웨어 공학에서 Claude Opus 5.5와 비슷하고, **GLM-5.3-Flash**는 Opus 4.8급이면서 512GB Mac Studio 정도면 개인도 돌릴 수 있대요.
- GLM을 만든 Z.ai에 직접 계정을 만들거나 데이터를 보내는 건 권하지 않아요. 코딩 하네스 ZCode가 동의 없이 로컬 저장소를 Alibaba Cloud로 올린 게 적발됐고, 중국 기업은 데이터를 정부와 공유한다고 봐야 한대요. DeepSeek, Qwen, Kimi 모델도 쓰기는 괜찮지만 회사에 대화를 맡기지는 말래요.
- 프랑스의 Mistral은 비중국·비미국 유일한 대형 랩이고, 최근 오픈 웨이트 프런티어 모델 Mistral Large 4(일명 Le Chonk)를 냈어요.

### 비공개 추론과 실제 사용
보안 엔클레이브와 원격 증명을 쓰는 **Tinfoil**과, 내부적으로 Tinfoil을 쓰는 소비자용 **Maple AI**를 추천해요. ChatGPT 같은 경험엔 Maple(무료 플랜, Pro 월 20달러), 에이전트 코딩·리버싱·악성코드 분석·CTF엔 토큰 과금 Tinfoil이 낫대요. GLM-5.3은 100만 토큰당 입력 1.80달러, 캐시 0.80달러, 출력 5.75달러예요.

덜 비공개라도 싸게 쓰려면 월 10달러 추론 라우터 **OpenCode Go**가 있지만, 데이터 비보존은 약속일 뿐 기술적 보장이 아니에요. 글쓴이는 OpenCode 하네스에 GLM-5.3(낮은 추론)을 쓰며, 공개 작업엔 OpenCode Go, 나머지엔 Tinfoil을 써요. 오픈 모델이 ChatGPT·Claude를 비슷하거나 싼 값에 완전히 대체할 수 있다고 결론 내려요.
