### mitmproxy란
**mitmproxy**는 콘솔 인터페이스를 갖춘 대화형 가로채기(intercepting) 프록시예요. SSL/TLS를 지원하고 **HTTP/1, HTTP/2, 웹소켓** 트래픽을 다뤄요. 앱과 서버 사이에 끼어 들어 오가는 요청과 응답을 보고, 멈추고, 고칠 수 있어서 API 디버깅, 모바일 앱 분석, 보안 테스트에 많이 쓰여요.

### 세 가지 도구
- **mitmproxy**: 터미널에서 쓰는 대화형 콘솔 버전이에요.
- **mitmdump**: 명령줄 버전이에요. README는 "HTTP용 tcpdump라고 생각하면 된다"고 설명해요. 스크립트나 자동화에 맞아요.
- **mitmweb**: 브라우저에서 쓰는 웹 기반 인터페이스예요.

### 설치와 문서
- 설치 방법은 공식 안내 페이지에 있고, 소스에서 설치하려면 CONTRIBUTING.md를 보라고 해요.
- 일반 정보, 튜토리얼, 미리 빌드된 바이너리는 mitmproxy 웹사이트에서 받을 수 있고 문서도 거기 있어요.
- 사용법 질문은 GitHub Discussions에 올려 달라고 해요.

### 기여
오픈소스 프로젝트로서 모든 형태의 기여를 환영한다고 해요. CI 상태 배지와 autofix.ci 배지가 붙어 있어 자동 검사와 자동 수정이 돌아가는 저장소예요.
