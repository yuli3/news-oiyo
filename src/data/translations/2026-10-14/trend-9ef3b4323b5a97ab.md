### 만든 이유
한글 파일을 AI로 다루려면 보통 두 방법뿐이었어요. 따로 유료 AI 프로그램을 쓰거나, AI가 여러 GitHub를 뒤지고 바이너리 구조를 분석해 매번 파이썬 코드를 새로 짜는 거예요. 두 번째는 오래 걸리고 수정이 번거로우며 서식이 어긋나거나 파일이 깨지기 쉬웠어요.

나래 한글은 글씨·표·그림 생성과 편집을 미리 안정화해 두고, 에이전트가 바로 쓸 수 있는 **CLI + 스킬 문서 + 템플릿**으로 묶었어요. AI는 바이너리를 분석하지 않고 정해진 명령만 부르면 돼요.

### 특징
- **표와 서식은 두고 내용만 수정**하는 게 기본이에요.
- 자주 쓰는 양식을 **JSON 템플릿**으로 저장해 반복 생성해요.
- ChatGPT·Claude **웹 대화창**에 패키지(또는 GitHub 주소)와 한글 파일을 올리면 AI가 `SKILL.md`를 읽고 같은 방식으로 작업해요. 단 코드 실행 환경이 있을 때만 직접 수정하고, 없으면 작업 JSON만 만들어 줘요.
- **한컴 없이 동작**: HWPX는 XML, HWP 5.0은 바이너리를 직접 읽고 고쳐요. 실패하면 한컴 COM으로 넘어가요.
- "'비고' 셀 테두리 없애줘" 같은 **자연어 명령**을 작업 목록으로 바꿔 실행해요.

### 지원 기능
| 구분 | 내용 |
|---|---|
| 표 | 셀 병합·분할, 내용 지정, 행 삽입·삭제, 셀 크기·여백, 4면 개별 테두리, 배경색 |
| 글자·문단 | 굵게, 크기·색, 정렬 |
| 표·그림 위치 | 글자처럼 취급, 가로 정렬, 그림 크기·비율 |
| 문서 | 새 문서, 기존 문서 확인(inspect), 쪽수 검증 |

자연어 명령은 일부(병합, 분할, 내용 변경, 굵게, 정렬, 배경색, 테두리, 표·그림 정렬)만 해석하고, 나머지는 `--ops-json`으로 직접 지정해요.

### 템플릿
형식 템플릿 11종(보고서 3쪽 세트, 기안문, 현장체험학습 계획서, 연수 결과보고서, 교수학습 지도안, 보도자료, 가정통신문·신청서, 회의록 등)과 문구 템플릿 7종(개조식 기호, 추진목적·기대효과, 안전지도·비상대응 등)이 들어 있어요. 학교·공공기관 문서에 맞춘 구성이에요.

### 에이전트 연결
Claude Code는 `CLAUDE.md`에 경로를 적거나 `.claude/skills/`에 넣고, Codex는 `AGENTS.md`에 적고, Hermes Agent는 스킬·컨텍스트 파일로 등록해요. Python 3.10 이상이 필요하고, 렌더링·PDF 검증에만 PySide6가 필요해요. `--output`을 빼면 원본을 덮어쓰니 중요한 파일은 먼저 복사하라고 해요.

### 알아둘 점
- 실제 쪽수는 한컴에서 열어 보는 게 가장 정확해요. 내장 뷰어는 추정 레이아웃이에요.
- 본문 높이 262mm 기준이고, 줄 넘김이 생기면 글자 크기 대신 자간을 −5%~−10% 줄이길 권해요.
- 문서마다 내부 구조가 달라 모든 파일에서 똑같이 동작한다고 보장하지 않아요.
