Phorion 블로그 원문 앞부분(약 7천 자 중 앞 3.5천 자)을 읽고 옮겼어요.

### 무슨 일이 있었나

Phorion은 Cursor Marketplace에서 배포된 **공식 Claude Code for VS Code 확장** 번들에 지속형 SSH 백도어가 들어 있는 것을 탐지했다고 밝혔어요. 임플란트에는 macOS, Linux, Windows용 설치·지속성 로직이 모두 들어 있고, 글은 주로 macOS를 다뤄요.

- 문제 버전: **Claude Code for VSCode 2.1.313**
- Cursor는 해당 릴리스를 마켓플레이스에서 내렸고, NPM과 VS Code 레지스트리의 2.1.313도 회수됐어요.
- Phorion은 조직이 즉시 이 버전 사용 여부를 점검하고, 사용이 확인되면 사고 대응에 들어가라고 권고해요.

### 왜 위험한가

확장 프로그램은 IDE와 사용자 권한으로 실행돼요. 그래서 백도어가 든 확장은 모듈이 로드되는 순간 로컬 파일, 소스 코드, 개발 도구에 바로 접근할 수 있어요.

### 감염 과정

- 감염된 `extension.js` 맨 앞에 즉시 실행 함수(IIFE)가 덧붙어 있어요. 나머지 번들은 정상 확장과 똑같아 보여요.
- 이 코드는 `child_process`, `fs`, `os`, `path`, `http`, `crypto` 같은 Node.js 모듈을 불러오고, 확장의 `activate` 콜백보다 먼저 실행돼요. 사용자가 확장을 건드리지 않아도 페이로드가 동작해요.
- 1단계로 `~/.ssh`를 만들고 공격자의 Ed25519 공개키(주석 `svc-telemetry`)를 `~/.ssh/authorized_keys`에 덧붙인 뒤 권한을 0700/0600으로 맞춰요.

### macOS에서 발견된 실수

스크립트는 root 권한 없이 원격 로그인 상태를 확인할 수 있다고 가정해요. 하지만 일반 사용자로 `systemsetup -getremotelogin`을 실행하면 관리자 권한 오류를 출력하고 상태 0으로 끝나요. 스크립트는 출력이 `Off`일 때만 SSH를 켜기 때문에 활성화 단계를 건너뛰어요. 그래서 SSH가 원래 꺼져 있던 Mac에서는 외부 접속 경로가 막히지만, SSH 키와 지속성 장치는 그대로 심어져요.

> 이 페이로드의 목표는 장기적인 대화형 접근이에요. macOS에서는 버그 때문에 피해가 줄지만, 지속성을 설치하고 호스트 정찰 정보를 운영자에게 보낸다는 점에서 여전히 심각한 위협이에요.

원문 뒷부분의 지속성 방식과 점검 지표(IOC)는 이 번역에 담지 못했어요. 원문을 직접 확인해 주세요.
