### 무슨 일이 있었나

Kevin Beaumont는 Claude 접근에 쓰이는 Cursor용 VS Code 확장이 SSH 역방향 백도어로 원격 접근 트로이목마를 배포했다고 썼어요. 공급망 공격으로 개발자 노트북과 데스크톱에 사람이 직접 또는 자동으로 원격 접근할 수 있었다는 거예요. 글쓴이는 처음에 Anthropic이 고객에게 알리지 않고 악성 버전을 조용히 지웠다고 비판했어요.

**업데이트**: Anthropic은 침해 지점이 Cursor라고 밝혔어요.

> "악의적인 행위자가 Cursor 마켓플레이스 접근 권한으로 Cursor 사용자를 노린 변조 확장을 올렸어요. 우리는 이걸 만들거나 올리거나 호스팅하는 데 관여하지 않았어요." — Anthropic

- 확장은 Cursor에서 악성 버전으로 자동 업데이트됐고, Cursor는 약 **5,000대**의 개발자 시스템이 영향을 받았다고 했어요.
- 처음 이상 활동을 알아챈 건 Phorion이에요.
- 문제 버전은 **2.1.313**이고 2.1.314로 교체됐어요. 하지만 2.1.314는 이미 감염된 시스템의 SSH 백도어와 이전 정찰 활동을 지우지 않아요.

### Cursor가 밝힌 악성 동작

- 호스트명, 사용자명, OS, 아키텍처, 홈 경로, 환경 변수 이름, 작업 디렉터리, Git 이메일, 공인 IP를 수집해요.
- 공격자 SSH 키를 `authorized_keys`에 넣고 SSH를 켠 뒤 역방향 터널을 열려고 해요. Cursor를 관리자 권한으로 띄운 특이한 경우가 아니면 코드 오류로 이 단계는 실패해요.
- macOS는 LaunchAgent, Windows는 SYSTEM 예약 작업(실패 시 시작 스크립트)으로 지속성을 노려요. 약 60초마다 터널을 다시 시도해요.
- 8099 포트 `/beacon`으로 호스트 정보와 백도어 상태를 HTTP POST로 보내요.

### 표현 문제와 지표

Cursor 블로그의 "Anthropic이 개발한 게 아니다"라는 문구에 대해, 글쓴이는 실제로 Anthropic의 인증 계정으로 올라왔다고 지적해요. Microsoft Defender용 KQL 헌팅 쿼리를 공개했고, Mac·Windows VSIX SHA-256 해시와 역방향 SSH·C2 서버 주소(134.209.82.225, 22·8099 포트)를 지표로 실었어요. 바이낸스 등 수천 곳이 노트북에서 Claude Code와 Cursor를 쓴다고 덧붙였어요.
