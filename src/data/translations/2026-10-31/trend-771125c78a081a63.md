### 무엇인가요

**Tailscale** 은 "WireGuard® 사설 네트워크를 쉽게" 만드는 서비스예요. 이 저장소에는 Tailscale 오픈소스 코드 대부분이 들어 있고, 특히 **tailscaled 데몬**과 **tailscale CLI** 가 있어요.

- tailscaled는 Linux, Windows, macOS에서 돌아가고, FreeBSD와 OpenBSD에서도 어느 정도 동작해요.
- iOS와 Android 앱도 이 저장소 코드를 쓰지만, 모바일 GUI 코드는 여기 없어요.
- macOS, iOS, Windows 클라이언트는 이 코드에 작은 GUI 래퍼를 더한 거고, 비오픈소스 플랫폼의 GUI 래퍼는 공개되지 않아요.
- Android 앱, Synology·QNAP 패키지, Chocolatey 패키징은 별도 저장소에 있어요.

### 쓰기와 빌드

- 여러 배포판과 플랫폼용 패키지는 pkgs.tailscale.com에서 받을 수 있어요.
- 빌드는 항상 최신 Go 릴리스(현재 Go 1.27)가 필요해요. 릴리스는 자체 Go 포크로 빌드하지만 꼭 쓸 필요는 없어요.
- `go install tailscale.com/cmd/tailscale{,d}`로 설치할 수 있고, 배포용 패키징이라면 커밋 ID와 버전 정보를 넣어 주는 `build_dist.sh`를 쓰라고 권해요.

### 기여

PR은 환영하지만 버그를 먼저 등록해 달라고 해요. 커밋 메시지는 버그를 참조해야 하고, DCO(Developer Certificate of Origin) Signed-off-by 줄이 필요해요.
