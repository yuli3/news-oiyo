Hugging Face 모델 카드의 소개 부분을 기준으로 옮겼어요. 벤치마크 표는 이미지·HTML 표라 수치는 옮기지 않았어요.

### 무엇인가
Agnes-AI는 agnes-3.0-qwen을 자사의 **가장 강력한 추론 모델**로 소개해요. 에이전트 코딩, 도구 사용, 과학 문제 풀이, 긴 문맥 분석, 멀티모달 이해를 겨냥한 멀티모달 추론 모델이고, **오픈 가중치**로 내놨어요. Reddit 제목에 따르면 QFN(Qwen3.8-Flash-Next 계열) 파인튜닝이에요.

### 구조
- **하이브리드 선형 어텐션 / 전체 어텐션** 구조예요.
- **Mixture-of-Experts**: 전문가 512개 가운데 토큰마다 10개가 활성화돼요.
- **다중 토큰 예측(MTP) 헤드**가 있어요.
- 긴 문맥 이해와 코딩·에이전트·과학 추론을 실제 서비스에 필요한 처리량과 비용으로 제공하는 게 목표래요.

### 추론 effort
채팅 템플릿을 보면 추론 effort를 `xhigh`(기본), `medium`, `low`로 고를 수 있어요. xhigh는 핵심 가정을 검증하고 대안을 따져 정확성을 우선하라고, low는 짧게 생각하고 바로 결론으로 가라고 지시해요.

### 비교 대상
카드는 GPT-5.6 Sol(Max), Gemini 3.8 Flash, DeepSeek V4 Flash(Max), MiniMax-M3, Claude Opus 4.8(Max), Qwen3.8 Max(0902)와 비교해요. agnes-3.0-qwen 결과는 공개 벤치마크에서 **자체 보고**한 값이고, 비교 수치는 공개 보고서에서 가져왔다고 밝혀요.
