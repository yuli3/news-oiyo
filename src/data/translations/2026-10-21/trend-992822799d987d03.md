AI타임스 기사의 대부분을 읽고 정리했어요. 기사 끝부분 일부는 읽지 못했어요.

### 무엇인가
스카이폴 AI(Skyfall AI)는 19일(현지시간) 복잡한 물리 제품 설계를 자동화하는 월드모델 **스카이-001(SKY-001)**을 공개했어요. 아이디어나 2D 스케치를 넣으면 설계 구조를 계층적으로 나누고, **CAD**(컴퓨터 지원 설계)와 **BIM**(건축정보모델링) 소프트웨어에서 실제로 구현할 수 있는 단계별 제작 계획을 만들어요. 회사는 LLM 중심 접근을 넘어 장기적인 공간 계획과 반복적인 3D 추론을 하도록 설계했다고 밝혔어요.

### 해결하려는 문제
기존 생성 AI는 3D 형상을 그럴듯하게 보여 줄 수는 있지만, 부품 간 계층 구조, 기계적 제약, 설계 이력까지 정확히 다루는 데는 한계가 있어 실제 제작 가능성을 보장하기 어렵대요. 엔지니어는 복잡한 시스템을 부품과 조립 구조로 나누고 각 부품의 형상과 제작 순서를 정하는 데 많은 시간을 써 왔어요.

### 작동 방식
결과물뿐 아니라 **만드는 과정까지** 함께 계획해요. 두 단계로 움직여요.
1. **계층형 컴포저(Hierarchical Composer)**가 전체 설계를 만들고 여러 단계의 구성 요소로 나눠요.
2. **구축 월드모델(Construction World Model)**이 각 요소를 실제 형상으로 만드는 시각적 작업 순서를 예측해요.

긴 작업 하나 대신 여러 하위 작업으로 나눠 병렬로 처리하니 계산 부담과 오류 누적이 줄어든대요.

### 예시
- **자동차 엔진**: 전체 대략 형상을 만들고 주요 조립체와 부품으로 분해한 뒤, 스케치와 돌출·절삭 같은 모델링 작업을 차례로 만들어요. 이미지 하나에서 시작해 겉에 안 보이는 내부 부품까지 구성해요.
- **건축**: 외곽선, 층별 면적, 방 크기와 배치를 설명하면 복도, 계단, 엘리베이터, 주거 공간이 들어간 평면도를 만들고 문, 창문, 설비까지 단계적으로 배치해요.
- 같은 요구 사항으로 여러 후보 설계를 만들어 비교하고, 고른 안을 세부 부품과 제작 순서로 구체화할 수 있어요.
