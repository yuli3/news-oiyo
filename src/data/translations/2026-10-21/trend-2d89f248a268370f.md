### 무엇인가
**fzf**는 범용 **명령줄 퍼지 파인더(fuzzy finder)**이자 대화형 터미널 도구 모음이에요. 파일 고르기, 명령 기록 탐색, 데이터 미리보기, 퍼지 매칭으로 복잡한 데이터 훑기, 사용자 메뉴와 작업 흐름 만들기에 쓰여요. 셸 스크립트를 풍부한 터미널 애플리케이션으로 바꾸는 부품을 준다는 게 README의 설명이에요.

### 특징
- **이식성**: 단일 바이너리로 배포돼 설치가 쉬워요.
- **속도**: 수백만 항목을 밀리초 안에 처리하도록 최적화했어요.
- **프로그래밍 가능**: 이벤트 기반 구조로 사용자 터미널 인터페이스와 작업 흐름을 만들 수 있어요.
- **기본 연동 포함**: Bash, Zsh, Fish, Nushell, Vim, Neovim 연동이 들어 있어요.

### README가 다루는 것(목차 기준)
- 설치: Homebrew, Mise, Linux·Windows 패키지, git, 바이너리 릴리스
- 셸 연동 설정, Vim/Neovim 플러그인, 업그레이드와 빌드
- 사용법: `--height` 모드, `--popup` 모드, 검색 문법, 환경 변수, 모양 바꾸기
- 명령줄 키 바인딩, 퍼지 자동 완성(파일·디렉터리, 프로세스 ID, 호스트 이름, 환경 변수·별칭)
- bash·zsh·fish·Nushell용 자동 완성 사용자화
