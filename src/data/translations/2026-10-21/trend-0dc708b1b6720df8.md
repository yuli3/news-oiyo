GitHub README 앞부분을 기준으로 옮겼어요. 융합 규칙 뒷부분은 다 읽지 않았어요.

### 무엇인가
코딩 에이전트가 쓴 토큰으로 **유희왕 카드 컬렉션**을 채우는 macOS 메뉴바 앱이에요. 한국어, 영어, 일본어를 지원해요.

### 어떻게 동작하나
- 로컬의 Claude Code, Codex, Gemini, Grok, Pi, oh-my-pi, Cursor 로그에서 **오늘 쓴 토큰**을 읽어요.
- 처음 실행하면 최근 14일 사용량도 쳐 주고, 그보다 오래된 건 세지 않아요.
- **1만 토큰 = 1코인**, **1,000코인(1천만 토큰) = 카드 5장 부스터 팩**이에요.
- 팩 10개를 사면 랜덤 팩 하나를 더 줘요.
- 1천만 토큰마다 전체 풀에서 희귀도 확률로 무료 카드 한 장을 줘요.
- 희귀도는 N, R, SR, UR, SE이고, 재판된 카드는 가장 높은 희귀도를 따라요.
- 설정에서 카드 풀 범위(DM부터 Modern까지, 기본 GX)를 고를 수 있어요.

### 수집 요소
- 일러스트가 카드 틀 밖으로 튀어나오는 공식 오버프레임 아트 카드가 25장 있고, 같은 카드 3장을 모으면 해금돼요. 팔아도 해금은 유지돼요.
- 팩을 다 모으면 아직 필요한 카드가 같은 희귀도의 다른 카드보다 10배 자주 나오고, 판매가도 3배예요.
- README에 따르면 하루 5천만 토큰을 쓰면 무료 카드 5장과 팩 5개 살 코인이 생겨요.

### 화면
메뉴바(코인·미개봉 카드 배지), 팝오버(오늘 사용량·비용, Claude/Codex 한도), 상점, 팩 열기, 도감이 있어요. 카드 이미지와 캐릭터를 숨기는 **업무 모드**도 있어요.
