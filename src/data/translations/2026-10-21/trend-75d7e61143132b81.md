GitHub README 전체를 읽고 옮겼어요. 기능 목록은 홈페이지에 있어 읽지 않았어요.

### 무엇인가
**Playnite**는 오픈소스 **비디오 게임 라이브러리 관리자이자 실행기**예요. Steam, Epic, GOG, EA App, Battle.net 같은 서드파티 라이브러리를 지원하고, **게임 에뮬레이션**도 지원해 모든 게임을 하나의 통합 인터페이스로 보여 줘요. 스크린샷과 기능 목록은 홈페이지에 있어요.

### 다운로드와 요구 사항
- 다운로드 페이지에서 설치형 또는 포터블 패키지를 받아요.
- 새 버전이 나오면 Playnite가 자동으로 알려 줘요.
- **Windows 10 또는 11**이 필요해요.

### 문제 보고
버그를 찾으면 이슈를 올리고, 충돌이나 기능 고장이라면 "About Playnite..." 메뉴에서 만들 수 있는 진단 패키지를 첨부해 달라고 해요. 가장 큰 커뮤니티는 Discord 서버와 Reddit에 있어요. 리드 개발자 요제프 네메츠(Josef Nemec)는 Patreon으로 후원을 받아요.

### 개인정보
- Playnite 자체는 **사용자 정보를 저장하지 않고**, 설치된 게임을 가져오는 데 정보를 줄 필요도 대개 없어요.
- 게임 라이브러리 데이터는 모두 **내 PC에 로컬로** 저장돼요.
- 계정 연결은 라이브러리 플러그인 구현에 따라 다르지만, 보통 공식 로그인 웹 폼을 쓰고 웹 세션 쿠키나 토큰만 저장해요. 브라우저로 그 서비스에 로그인할 때와 같은 방식이에요.

### 확장
.NET 언어로 쓴 플러그인, PowerShell 스크립트 등으로 기능을 넓힐 수 있어요.
