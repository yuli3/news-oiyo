GitHub README 앞부분을 기준으로 옮겼어요. 기능 표 뒷부분은 다 읽지 못했어요. README에 있는 데모 로그인 정보는 옮기지 않았어요.

### 무엇인가
**Immich**는 "고성능 자체 호스팅 사진·동영상 관리 솔루션"이에요. 구글 포토 같은 서비스를 내 서버에서 직접 운영하려는 사람들이 많이 써요. README는 20개 가까운 언어로 번역돼 있고, 한국어 README도 있어요.

### 경고 문구
README 맨 위에 **"소중한 사진과 동영상은 항상 3-2-1 백업 원칙을 지키세요"**라는 경고가 있어요. 3-2-1은 복사본 3개, 서로 다른 저장 매체 2종류, 그중 1개는 다른 장소에 두는 백업 원칙이에요. Immich 자체를 유일한 보관소로 쓰지 말라는 뜻이에요.

### 주요 기능(모바일·웹)
- 사진·동영상 업로드와 보기, 앱을 열 때 자동 백업, 백그라운드 백업
- 중복 업로드 방지, 백업할 앨범 선택
- 다중 사용자, 앨범과 공유 앨범, 파트너 공유, 공개 공유
- RAW 형식 지원, EXIF·지도 메타데이터 보기
- 메타데이터, 객체, 얼굴, **CLIP**으로 검색
- **얼굴 인식과 묶기**, 전 세계 지도
- LivePhoto/MotionPhoto 백업과 재생, 360도 이미지 표시(웹)
- OAuth, API 키(웹), 사용자 정의 저장 구조, 보관함과 즐겨찾기

### 문서
설치 가이드를 포함한 공식 문서는 immich.app에 있고, 데모 서버와 로드맵도 공개돼 있어요.
