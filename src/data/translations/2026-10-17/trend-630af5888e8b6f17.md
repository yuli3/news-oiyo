### 무엇인가
**Cal.diy**는 커뮤니티가 이끄는 완전 오픈소스 일정 예약 플랫폼으로, Cal.com의 포크예요. 상용 "Enterprise Edition" 기능 없이 전체가 MIT 라이선스이고, 상업적 의존 없이 일정 인프라를 직접 통제하고 싶은 개인과 자체 호스팅 사용자를 위해 만들었어요.

### Cal.com과 무엇이 다른가
| 항목 | Cal.diy |
|---|---|
| 기업 기능 | 팀, 조직, 인사이트, 워크플로, SSO/SAML 등 EE 전용 기능 제거 |
| 라이선스 키 | 필요 없음, Cal.com 계정도 불필요 |
| 라이선스 | 코드 전체 MIT, 오픈 코어 분리 없음 |
| 유지보수 | 커뮤니티 기여가 이 프로젝트로 바로 반영 |
| 호스팅 | 관리형 버전 없음, 직접 운영 |

### 경고 문구
README 맨 위에 "본인 책임으로 사용"하라는 경고가 있어요. 개인·비운영 용도를 강하게 권하고, 자체 호스팅에는 서버 관리, 데이터베이스 관리, 민감 데이터 보호에 대한 고급 지식이 필요하다고 해요. 상업·기업용 일정 인프라가 필요하면 Cal.diy가 아니라 Cal.com을 쓰라고 안내해요.

### 기술 스택과 요구 사항
Next.js, tRPC, React, Tailwind CSS, Prisma, Daily.co로 만들었고, 로컬 실행에는 Node.js 18 이상과 PostgreSQL 13 이상이 필요해요. 저장소 커밋은 1만6499개예요.
