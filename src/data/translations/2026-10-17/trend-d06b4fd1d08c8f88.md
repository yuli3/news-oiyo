### 회사
Piramidal은 뇌의 전기생리 데이터를 위한 **최초의 파운데이션 모델**을 만든다고 소개해요. 목표는 사람이 "뇌의 언어"를 이해하고 상호작용하게 하는 대규모 신경 디코더이고, 첫 제품은 최신 모델을 실시간 임상 워크플로에 넣어 의료진이 발작을 더 빨리 감지하고 대응하도록 돕는 거예요.

### 역할
실시간 신경 모니터링 플랫폼의 인프라를 만들고 키우는 일이에요. 고처리량 스트리밍, 실시간 분석, 병원 수준의 신뢰성이 핵심 과제예요.

- Python·Go 서비스로 신경 데이터 실시간 스트림을 받아 변환·제공
- 원시 신경 데이터부터 파생 시계열까지 고빈도 시계열 데이터 모델, 수집 파이프라인, 보존 정책 설계
- 임상 워크플로 API 구축
- ML 엔지니어와 함께 연구 모델을 프로덕션 추론으로 옮기고 운영
- 지표·알림·용량 계획·장애 후속 조치로 관측 가능성 확보
- 사이버보안, 추적성, 변경 관리 등 **규제 의료기기 수준**의 소프트웨어 개발

### 지원 자격
- 프로덕션 백엔드 5년 이상, 모호한 문제를 운영 중인 서비스까지 책임지고 말·글로 설명할 수 있는 사람
- 이벤트 기반·스트림 처리 실무(파티셔닝, 체크포인트, 백프레셔, at-least-once 전달)
- 동시성(스레드 vs 프로세스, asyncio)과 테스트를 포함한 강한 Python
- 컨테이너·오케스트레이션(가능하면 Kubernetes), 스키마 설계부터 쿼리 성능까지 관계형 DB

우대: Go, Azure(Event Hubs, Service Bus, Web PubSub, Blob Storage, AKS), Arrow·Parquet, 영상 스트리밍, 1초 미만 지연 시스템, 대규모 데이터 엔지니어링, PyTorch 모델 서빙, 의료 등 규제 소프트웨어 경험.
