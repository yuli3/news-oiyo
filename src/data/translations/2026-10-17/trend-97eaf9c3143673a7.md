### 무엇인가
Bitwarden Server 프로젝트에는 모든 Bitwarden 클라이언트 앱의 "백엔드"에 필요한 API, 데이터베이스, 기타 핵심 인프라가 들어 있어요.

| 항목 | 내용 |
|---|---|
| 언어·프레임워크 | C#, .NET Core, ASP.NET Core |
| 데이터베이스 | T-SQL / SQL Server |
| 개발·배포 | 윈도, macOS, 리눅스 크로스 플랫폼 |
| 이미지 | GitHub Container Registry |

### 배포하기
Docker 컨테이너로 배포하고, PowerShell·Bash 스크립트로 빠르게 시작할 수 있어요. 필요한 건 Docker와 Docker Compose(무료)예요.
- 리눅스·macOS: `bitwarden.sh` 스크립트를 내려받아 `install` 후 `start`
- 윈도: `bitwarden.ps1`을 받아 `-install` 후 `-start`
전체 온프레미스 설치 문서는 Bitwarden 도움말 센터에 있어요. README에는 미국·EU 운영 클러스터에서 쓰는 서비스별(Admin, API, Billing, Events, Identity, Notifications, SCIM, SSO 등) 운영 이미지 해시 표도 공개돼 있어요.

### 기여와 보안
- 코드 기여는 main 브랜치로 PR을 보내면 되고, 기여 가이드와 서버 설정 가이드를 먼저 보라고 안내해요.
- 보안 감사와 피드백을 환영하며, 민감한 제보는 비공개 이메일이나 HackerOne 프로그램을 이용하라고 해요.
- 자동 포맷을 위해 `git config --local core.hooksPath .git-hooks`로 pre-commit 훅을 설치하라고 권해요.
- Bitwarden 상표·로고 사용 권리는 부여하지 않는다고 밝혀요.
