### Pixel Art Studio

macOS 스타일 다크 모드를 지원하고 AI·바이브 코딩 연동에 맞춘 **가벼운 픽셀 아트 제작 PC 프로그램**이에요. Electron으로 만든 순수 픽셀 아트 편집 도구로, 사람이 직접 그릴 수도 있고 AI 에이전트(Cursor, Claude Code 등)가 2D 배열 데이터로 픽셀 에셋을 자동 생성해 게임 개발 프로젝트에 연결할 수 있게 설계했다고 해요.

### 주요 기능

- **모던 다크 모드 UI**: macOS 느낌의 반투명·둥근 디자인과 다크 테마
- **그리기 도구**: 펜, 지우개, 페인트통(채우기), 스포이트, 전체 초기화
- **그리드 옵션**: 16x16 / 32x32 크기 변경, 그리드 선 켜기·끄기
- **컬러 팔레트**: 레트로 색상 칩 8종과 자유 색상 선택기
- **AI 연동**: 픽셀 데이터를 2D Array / JSON으로 다뤄 AI 에이전트의 자동 에셋 생성과 호환
- **PNG 내보내기**: 픽셀이 흐려지지 않는 고화질 PNG

### 시작하기

Node.js(LTS 권장)가 필요해요. Windows는 `PixelArtStudio-v1.0.0-Windows.exe`, Mac은 `PixelArtStudio-v1.0.0-Mac.dmg`를 내려받아 실행하면 돼요. 저장소에는 `AGENTS.md`, `CLAUDE.md`, `CLI.md`, `cli.js`가 있어 에이전트가 쓰기 좋게 구성돼 있어요. 라이선스는 MIT이고, 읽은 시점에 커밋은 5개였어요.
