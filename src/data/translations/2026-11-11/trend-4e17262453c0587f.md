GitHub 저장소 README 앞부분(소개, 설치, pre-commit 첫머리)을 읽고 옮겼어요. 나머지는 읽지 않아 partial로 표시했어요. 이번 주 GitHub 트렌딩 수집 항목이에요.

### 공지: 기능 개발 종료

README 맨 위 경고에 따르면 **Gitleaks는 기능이 완성된 상태**예요. 메인테이너는 새 기능을 더 이상 머지하지 않고, 앞으로 릴리스는 **보안 패치만** 낸다고 해요. 대신 **Betterleaks**에 집중한다고 밝혔어요.

### Gitleaks란

git 저장소, 파일, 그리고 stdin으로 넣는 무엇이든에서 **비밀번호, API 키, 토큰 같은 시크릿**을 찾는 도구예요. 탐지 엔진 원리는 블로그 글 "Regex is (almost) all you need"에 정리돼 있다고 해요.

README 예시는 `gitleaks git -v`를 실행해 찾은 결과를 보여 줘요. 결과마다 Finding(문제 줄), Secret, RuleID(예: `sidekiq-secret`), Entropy, File, Line, Commit, Author, Email, Date, Fingerprint가 나와요.

### 설치

Homebrew, Docker, Go로 설치할 수 있고, 여러 플랫폼용 바이너리가 릴리스 페이지에 있어요. 저장소에 pre-commit 훅으로 넣거나 GitHub Action(Gitleaks-Action)으로 쓸 수도 있어요.

```bash
# macOS
brew install gitleaks
# Docker
docker pull zricethezav/gitleaks:latest
docker pull ghcr.io/gitleaks/gitleaks:latest
# 소스에서 (go 필요)
git clone https://github.com/gitleaks/gitleaks.git
cd gitleaks
make build
```

pre-commit을 쓰려면 pre-commit.com에서 설치한 뒤 설정 파일을 만들어요(README의 이후 단계는 읽지 않았어요).
