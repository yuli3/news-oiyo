### 무엇인가

Modern Web Guidance는 웹 플랫폼 전문 지식, 모범 사례, 브라우저 호환성 데이터를 코딩 에이전트에 바로 넣어 주는 **스킬** 모음이에요. 에이전트가 레거시 패턴에서 벗어나 최신 웹 플랫폼 기능을 쓰도록 이끄는 게 목표예요. Google Chrome, Microsoft Edge, Mozilla Firefox, MDN 팀이 웹 개발 커뮤니티와 함께 관리해요.

저장소에는 `.claude-plugin`, `.codex-plugin`, `.cursor-plugin`, `.grok-plugin`, `gemini-extension.json`, `kimi.plugin.json` 같은 여러 에이전트용 플러그인 설정이 들어 있어요.

### 빠른 시작

```bash
npx modern-web-guidance@latest install
```

대화형 마법사로 설치해요. 설치 없이도 써 볼 수 있어요.

```bash
# 관련 가이드 검색
npx modern-web-guidance@latest search "animate a dialog modal backdrop"
# ID로 가이드 가져오기
npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"
# 코드베이스에서 현대화할 레거시 패턴 찾기
npx modern-web-guidance@latest legacy-scan .
```

### 왜 필요한가

LLM 학습 데이터에는 레거시 코드가 엄청나게 많아서, 코딩 에이전트는 오래된 패턴을 기본으로 쓰는 경우가 많아요. 그래서 이제는 네이티브로 빠르게 해결되는 일에도 부풀려진 JavaScript를 만들어요. 모델이 어떤 API가 있다는 걸 알아도, 실제 운영용 코드에 필요한 최신 구현 패턴은 충분히 알지 못한다고 README는 설명해요.

이 스킬의 CLI는 전문가가 고른 지침을 에이전트 컨텍스트 창에 바로 넣어 줘요. 초점은 이래요.

- **최신 브라우저 API**: 모델이 자주 잘못 쓰는 API를 올바르게 구성하도록 도와요.
- **성능과 접근성**: 플랫폼 기본 기능을 우선하도록 해요.
