### LibreTranslate

**무료 오픈소스 기계번역 API**로, 완전히 **셀프호스팅**해요. 다른 API와 달리 Google이나 Azure 같은 독점 소프트웨어에 기대지 않고, 오픈소스 **Argos Translate** 라이브러리가 번역 엔진을 맡아요. 저장소 소개 문구는 "셀프호스팅, 오프라인 가능, 쉬운 설정"이에요.

- 온라인 체험, API 문서, 커뮤니티 포럼, Bluesky 링크를 README 첫머리에 두었어요.
- 시작하기 안내는 빠른 시작, 사용법, 커뮤니티 자료로 나뉘어 있어요.
- 저장소에는 `docker-compose.yml`, CUDA용 `docker-compose.cuda.yml`, `k8s.yaml`이 있어 Docker나 Kubernetes로 띄울 수 있어요. `AGENTS.md`도 있어요.

- 이 작업은 번역 엔진을 제공하는 Argos Translate 덕분에 가능했다고 밝혀요.
