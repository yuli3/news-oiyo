Hugging Face 모델 카드 앞부분(시작하기와 Python 예제 첫머리)을 읽고 옮겼어요. 나머지는 읽지 못해 partial로 표시했어요. r/LocalLLaMA 글은 "지난주부터 HF 인기 1위, dinov3 의존, 8GB VRAM에서 돈다"는 짧은 소개였어요.

### Idol

**이미지 한 장을 3D 가우시안 스플랫으로** 바꾸는 모델이에요. 물체 사진 한 장을 넣으면 사진에 안 보이던 옆면까지 포함해 최대 **1,048,576개 가우시안**을 표준 3DGS `.ply`로 만들어요. 렌더, 생성 이미지, 실사 사진 모두 넣을 수 있고, 배경을 지우고 물체를 프레임에 맞춘 뒤 생성해요. 소비자 GPU에서 **VRAM 7.2GB**로 **2초 안에** 돌 수 있다고 해요.

### 시작하기

1. **이미지 인코더 접근 권한 받기**: Hugging Face의 게이트 모델 두 개로 입력을 읽어요. 약관에 동의하고 `hf auth login`(또는 `HF_TOKEN`)으로 한 번 로그인해요.
   - `facebook/dinov3-vith16plus-pretrain-lvd1689m`
   - `black-forest-labs/FLUX.2-dev`(VAE만 내려받아요)
2. **코드 설치**: `idol-sdk` 저장소를 클론하고 `pip install -e .`로 설치해요. Python 3.10+, PyTorch 2.5+, CUDA NVIDIA GPU가 필요해요. 첫 실행 때 약 3GB 가중치와 인코더가 자동으로 내려받아지고, 인코더 접근이 안 되면 아무것도 받기 전에 무엇이 빠졌는지 알려 줘요.
3. **3D 생성**:

```bash
python -m idol.sample --image photo.jpg --mode real
python -m idol.sample --image renders/ --mode synthetic --out outputs
```

이미지마다 `.ply`, 모델이 본 입력 이미지(`_input.png`), 예측한 카메라(`_camera.json`)가 나와요. `--mode synthetic`(기본)은 렌더·생성 이미지용으로 물체가 프레임의 1/1.2를, `real`은 사진용으로 1/1.7을 채우게 잘라요. Python에서는 `IdolPipeline.from_pretrained("speridlabs/idol")`로 쓸 수 있어요.
