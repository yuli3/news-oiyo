### 어떤 프로젝트인가요

**Ruff**는 uv와 ty를 만든 **Astral**의 파이썬 린터 겸 코드 포매터예요. Rust로 작성됐고 MIT 라이선스예요. 여러 도구를 하나의 공통 인터페이스로 묶으면서 기존 도구보다 자릿수 단위로 빠른 게 목표래요.

### 특징

- 기존 린터(Flake8)·포매터(Black)보다 **10~100배 빠름**
- pip 설치, `pyproject.toml` 지원, **Python 3.15** 호환
- Flake8, isort, Black과 같은 결과를 내는 **드롭인 호환**
- 바뀌지 않은 파일은 다시 분석하지 않는 내장 캐시
- 안 쓰는 import 제거 같은 **자동 수정**
- flake8-bugbear 같은 인기 플러그인을 다시 구현한 **900개 이상의 내장 규칙**
- VS Code 등 공식 에디터 연동, 계층형 설정으로 모노레포 친화적

Flake8(과 수십 개 플러그인), Black, isort, pydocstyle, pyupgrade, autoflake 등을 대체할 수 있다고 해요. Apache Airflow, Superset, FastAPI, Hugging Face, Pandas, SciPy 같은 프로젝트가 쓰고 있대요.

### 사용자 후기(README 인용)

- FastAPI를 만든 Sebastián Ramírez: 너무 빨라서 일부러 버그를 넣어 정말 돌아가는지 확인할 때가 있대요.
- Elementl 창업자 Nick Schrock: 25만 줄짜리 dagster 모듈에서 pylint가 약 2.5분 걸리던 걸, Ruff는 전체 코드베이스에 0.4초 걸렸다고 했어요.
- Bokeh 공동 제작자 Bryan Van de Ven: flake8보다 150~200배 빨라 약 20초가 0.2초가 됐고, 커밋 훅으로 넣었대요.
