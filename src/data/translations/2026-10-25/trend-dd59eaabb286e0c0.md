> AI타임스 기사를 바탕으로 정리했어요. 출시 발표는 22일(현지시간)이에요.

### 무엇이 나왔나요

앤트로픽이 **구글 클라우드 기반 '앤트로픽 직접 관리형(Anthropic-managed)' 클로드 서비스**를 정식 출시했어요.

- 기존 **구글 클라우드 IAM** 인증을 지원하고, 별도 API 키 없이 **애플리케이션 기본 자격 증명(ADC)**으로 연동할 수 있어요.
- 사용료는 **구글 클라우드 청구서**에 합쳐지고, 기존 구글 클라우드 이용 약정 차감도 돼요.
- 가장 큰 특징은 **기능 격차를 줄인 것**이에요. 클로드 플랫폼에 새 기능이나 베타가 나오면 같은 날 이 서비스에도 제공돼요. 지금은 미국과 글로벌 엔드포인트로 접속할 수 있어요.

### 쓸 수 있는 기능

- **클로드 매니지드 에이전트(베타)**: 오래 실행되는 에이전트 구축
- **코드 실행**: API 호출 안에서 Python을 돌려 시각화·데이터 분석
- **컴퓨터 사용**: 브라우저나 데스크톱 조작
- **에이전트 스킬**, **파일 API**, **인용**, **웹 검색·웹 페이지 가져오기**, **MCP 커넥터(베타)**
- 비용·성능 관리용 **프롬프트 캐싱**과 **배치 처리**, 그리고 프롬프트 작성부터 사용량·비용 모니터링, 작업 공간별 권한 관리까지 하는 **클로드 콘솔**

### 모델과 패스트 모드

- 쓸 수 있는 모델은 **클로드 페이블 5.1, 오퍼스 5.5, 소네트 5.5, 하이쿠 5.5**예요. 새 모델도 출시 시점에 맞춰 추가될 예정이에요.
- **오퍼스 5.5 패스트 모드**도 정식 제공돼요. 출력 토큰 생성 속도를 최대 **2.5배** 높이고, 요금은 입력 100만 토큰당 **8달러**, 출력 100만 토큰당 **40달러**예요.

### 두 가지 관리형, 무엇이 다른가요

| 구분 | 앤트로픽 관리형 | 구글 관리형(기존) |
|---|---|---|
| 적합한 곳 | 최신 기능·베타를 빨리 쓰려는 기업 | 엄격한 데이터 저장 지역 요건, Model Armor·Agent Engine 등 구글 서비스와 긴밀한 통합이 필요한 기업 |
| 책임 | 구글 인프라 위에서 돌아도 운영·법적·데이터 처리 책임은 앤트로픽 상용 약관에 따라 앤트로픽 | 구글이 데이터 처리자 |

앤트로픽 관리형은 **구글 클라우드 마켓플레이스**에서 쓸 수 있어요. 기존 할인 계약이 있다면 시작 전에 적용 여부를 담당자에게 확인해야 하고, 이미 발생한 과거 사용료에는 약정이나 할인이 소급되지 않는대요.
