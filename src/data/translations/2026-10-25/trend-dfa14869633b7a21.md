> AI타임스 기사를 바탕으로 정리했어요. 발표는 22일(현지시간) AGNTCon·MCPCon 행사에서 나왔어요.

### 무엇을 발표했나요

구글 클라우드가 AI 에이전트 전용 컴퓨팅 서비스 **'에이전트 컴퓨트 엔진(Agent Compute Engine)'**을 공개했어요. 이미 업무용 에이전트로서 **제미나이**를 구동하는 데 쓰이고 있고, 몇 달 안에 고객 대상 **프리뷰**로 나올 예정이에요.

### 왜 필요하대요

질문에 답만 하는 모델과 달리 에이전트는 코드를 쓰고 실행하고, 도구와 브라우저를 조작하고, 여러 단계를 반복해요. 그래서 실행 환경을 **빨리 만들고, 멈췄다 다시 켜고, 작업마다 안전하게 격리**하는 인프라가 필요하다는 게 구글 설명이에요.

### 어떻게 격리하나요

- 에이전트 세션마다 **전용 마이크로VM**을 줘요. 각 VM은 자체 게스트 커널과 루트 권한을 갖고, **Cloud Hypervisor**로 다른 환경과 격리돼요.
- 하드웨어 보안 아키텍처 **티타늄(Titanium)**과 **IPU**를 쓰고, 외부 프록시·정책 검사로 **프롬프트 인젝션** 같은 위협에서 내부 비밀정보를 지켜요.
- 모델을 부르고 작업을 지시하는 **하네스는 샌드박스 밖**에서 돌고, 코드·셸·브라우저 실행 환경에는 필요한 명령만 전달해요.

### 자원을 아끼는 방식

- 에이전트는 모델 응답이나 사용자 입력을 기다리는 시간이 많아요. 도구 실행을 마치고 대기에 들어가면 마이크로VM을 **체크포인트로 저장하고 유휴 상태로** 바꾼 뒤, 작업이 재개되면 스냅샷으로 복원해요.
- 같은 OS 템플릿을 쓰는 에이전트끼리는 **쓰기 시 복사(copy-on-write)**로 메모리를 공유하고, 각 VM에 **Hyperdisk**를 붙여 작업 맥락을 유지해요.

### 오픈소스 '에이전트 서브스트레이트'

쿠버네티스에서 에이전트를 운영하려는 기업용 오픈소스 실행 환경이에요. 클로드 코드, 오픈클로, 헤르메스 등 여러 에이전트 프레임워크와 연동되고, 마이크로VM이나 gVisor로 에이전트별 환경을 격리해요. 구글 벤치마크에서는 에이전트 **20만 개**를 대상으로 초당 **500회** 활성화를 처리했고, 일시 중단·재개는 **500밀리초 미만**, 기존 대비 최대 **10배** 높은 컴퓨팅 밀도를 기록했대요.

### 거버넌스

에이전트 게이트웨이, 레지스트리, 아이덴티티, 옵저버빌리티로 권한 오남용과 데이터 유출을 통제하고, 토큰 사용량 관리, 모델 라우팅, 핑 아이덴티티·세일포인트·사비언트 같은 외부 인증 연동도 추진한대요. 구글은 "자율형 에이전트를 안전하게 실행하는 것은 근본적으로 인프라의 문제"라고 밝혔어요.
