- 공정한 벤치마크가 핵심이라 보고, 튜닝용과 최종 측정용 세트를 나눴어요. 2026년 10월 이후 공개된 영어 위키백과 글, 채팅·도구 호출 기록, GitHub 코드를 512토큰부터 128K 토큰까지 썼어요.
- Unsloth의 동적 양자화처럼 모델마다 텐서 정밀도 조합이 다른 후보 파일 10~50개를 만들고 유망한 것을 다듬었어요. 에이전트 스웜으로 무차별 힐클라이밍을 하자 SOTA와 비슷해졌지만 Unsloth, EXL3를 넘기는 어려웠대요.
- 그러다 LLM이 작은 모델의 가중치를 직접 읽고 고치는 **"Sparks of Weight-Space Programming"** 논문을 떠올렸어요. Nace의 WSP 하네스를 양자화용으로 바꾸고 Astra/Fable/Carbon 에이전트들이 텐서 정밀도 변경을 제안하고, KL을 재고, 유지하거나 되돌리게 경쟁시켰어요.
