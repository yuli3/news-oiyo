### 잉클링 2 스몰

- 씽킹 머신스 랩은 11월 5일(현지시간) 공식 블로그로 2세대 모델 '잉클링 2 스몰(Inkling 2 Small)'을 발표했어요.
- 총 5,940억 개 매개변수의 전문가 혼합(MoE) 모델로, 추론 때는 170억 개만 활성화해요.
- 텍스트·이미지 입력을 지원하고 최대 100만 토큰 문맥을 처리해요.
- 기업이 자체 업무에 맞춰 AI를 만들 수 있도록 가중치도 공개할 계획이에요.

### 성능

- 아티피셜 애널리시스(AA) 종합 지능 지수 31점으로, 7월에 낸 '잉클링 스몰'(13점)보다 18점 높아요. 비슷한 API 가격대 모델 29개 중 4위예요.
- Z.ai 'GLM-5.3 플래시', 샤오미 '미모 V2.6 플래시'는 앞섰지만 딥시크 'V4.1 플래시'에는 못 미쳤어요.
- AA는 가중치가 공개되면 현재 순위 기준 중국 밖에서 개발된 오픈 웨이트 모델 중 최고 점수가 된다고 평가했어요.
- 자체 평가에서 복잡한 소프트웨어 개발을 재는 '프론티어코드 2.0' 25.4%(GLM-5.3 플래시 14.2%), 기업 업무 평가 '엔터프라이즈벤치 코어크래프트' 71.8%를 기록했어요.
