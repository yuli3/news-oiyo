### Ruff란

Astral이 만든 Ruff는 "Rust로 쓴 극도로 빠른 Python 린터이자 코드 포매터"예요. 대안 도구들보다 몇 자릿수 빠르면서 더 많은 기능을 하나의 공통 인터페이스 뒤에 모으는 것이 목표예요.

### 주요 특징

- Flake8 같은 린터, Black 같은 포매터보다 10~100배 빠름
- Python 3.15 호환
- Flake8, isort, Black과 바로 바꿔 쓸 수 있는 동등성
- 바뀌지 않은 파일을 다시 분석하지 않는 내장 캐시
- 미사용 import 자동 제거 같은 자동 수정 지원
- 900개 넘는 내장 규칙과 flake8-bugbear 같은 인기 Flake8 플러그인의 네이티브 재구현
- VS Code 등 공식 에디터 통합
- 계층적·연쇄 설정으로 모노레포 친화적

Ruff는 Flake8(과 수십 개 플러그인), autoflake 등을 대체하면서 개별 도구보다 수십~수백 배 빠르게 실행된다고 해요.

### 사용자 추천사(README 인용)

- FastAPI를 만든 세바스티안 라미레스는 Ruff가 너무 빨라 실제로 도는지 확인하려고 일부러 버그를 넣어 볼 때가 있다고 말해요.
- Elementl 창업자 닉 슈록은 가장 큰 모듈(dagster, 25만 줄)에서 pylint가 M1의 4코어 병렬로 약 2.5분 걸리는데, 전체 코드베이스에 Ruff를 돌리면 0.4초라며 거의 1000배 빠르다고 했어요.
- Bokeh 공동 창작자 브라이언 밴 드 빈은 자기 머신에서 flake8보다 약 150~200배 빠르고, 전체 저장소 검사가 약 20초에서 0.2초로 줄어 커밋 훅으로 넣었다고 해요.
