### Unleash란

Unleash는 기능 관리(feature management)를 위한 오픈소스 솔루션이에요. 개발 흐름을 단순하게 하고 배포를 빠르게 하며, 팀이 새 기능을 언제 어떻게 사용자에게 내보낼지 제어하게 해 줘요. 코드를 더 작고 관리하기 쉬운 단위로 원하는 속도에 맞춰 운영 환경에 배포할 수 있어요.

### 기능 플래그로 할 수 있는 것

- 실제 운영 데이터로 코드를 시험해 사용자 경험에 나쁜 영향을 줄 위험을 줄여요.
- 별도 기능 브랜치 없이 여러 기능을 동시에 작업할 수 있어요.

README는 Unleash가 GitHub에서 가장 인기 있는 오픈소스 기능 플래그 솔루션이라고 소개해요. 공식 클라이언트·서버 SDK 15개와 커뮤니티 SDK 15개 이상을 지원하고, 직접 SDK를 만들 수도 있어 어떤 언어·프레임워크와도 호환된다고 해요.

### 시작하는 두 가지 방법

1. **Unleash Enterprise 무료 체험**: 호스팅 인스턴스에서 프로젝트·환경 무제한, 역할 기반 접근 제어, 변경 요청, SSO, SCIM 자동 사용자 프로비저닝 등을 쓸 수 있어요.
2. **로컬 오픈소스 실행**: git과 docker가 필요해요. 저장소를 클론해 docker compose로 띄운 뒤 브라우저에서 `localhost:4242`로 접속해 로그인해요. Node.js로 소스를 직접 실행하는 방법은 기여 가이드에 있어요.

이후 공식 SDK 목록에서 원하는 SDK를 골라 애플리케이션에 연결해요.
