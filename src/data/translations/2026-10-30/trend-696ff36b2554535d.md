GitHub 트렌딩에 오른 **블랙버드(Blackbird)** 저장소의 README를 우리말로 옮겼어요. 수집 시점 기준 별 약 9,500개, 포크 약 1,100개예요. 다른 사람의 정보를 찾는 도구라서, 쓰기 전에 법적·윤리적 범위를 꼭 확인해야 해요.

### 블랙버드는 무엇인가요

**사용자 이름(username)과 이메일로 600개가 넘는 플랫폼에서 계정을 빠르게 찾는** OSINT(공개 출처 정보) 도구예요. 여기에 무료 AI 프로파일링을 더했어요.

- 커뮤니티 프로젝트 **WhatsMyName**을 활용해서 오탐이 적고 결과 품질이 높다고 해요. WhatsMyName은 600개 넘는 사이트로 역방향 사용자 이름 검색을 해요.
- 스마트 필터, PDF/CSV 내보내기, 완전 자동 분석을 **명령줄 하나**에서 제공해요.

### 설치와 사용

- 저장소를 클론한 뒤 `pip install -r requirements.txt`로 의존성을 깔아요. README의 클론 주소는 `p1ngul1n0/blackbird`로 적혀 있어요.
- 리눅스에서는 서드파티 설치 도구 **OTinstaller**로도 설치할 수 있어요. 설치 문제는 OTinstaller 쪽 이슈 트래커에 올리라고 해요.
- 사용자 이름 검색은 `--username`, 이메일 검색은 `--email`, PDF 내보내기는 `--pdf` 옵션을 써요.

### 무료 AI 기능

계정이 발견된 사이트들을 분석해서 해당 사용자의 **행동·기술 프로필**을 돌려주는 AI 엔진이 들어 있어요.

- **민감한 데이터는 보내지 않고 사이트 이름만** 전송한다고 해요.
- 하루 사용량 제한 안에서 무료로 쓸 수 있고, AI 결과는 PDF 내보내기에도 들어가요.
- `--setup-ai`로 API 키를 만들고 `--ai` 옵션으로 써요.
