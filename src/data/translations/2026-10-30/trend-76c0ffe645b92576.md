Ferryx 웹사이트 앞부분(소개와 기능 설명 일부)을 읽고 옮겼어요. 아래쪽 기능 목록은 다 읽지 못했어요.

### 코딩 에이전트를 위한 네이티브 터미널

Ferryx는 macOS, Windows, Linux에서 쓰는 코딩 에이전트용 터미널이에요. 사이트가 내세우는 점은 세 가지예요.

- 앱을 닫아도 **Claude Code, Codex 등 CLI 에이전트가 계속 실행**돼요.
- 원격 리눅스 박스에 **SSH 없이** 연결해요.
- 탭마다 **어떤 에이전트가 사용자 입력을 기다리는지** 보여 줘요.

소스는 Ferryx License로 공개(source-available)돼 있어요. 사이트에는 사이드바, 탭, 분할 창을 보여 주는 웹 데모가 있지만, Ferryx 자체는 브라우저 앱이 아니라 네이티브 앱이라고 밝혀요. 데스크톱 앱은 분석 동의 여부와 관계없이 텔레메트리를 보내지 않는대요.

### 구조

창보다 오래 사는 **헤드리스 Rust 데몬**에, 측정된 WGPU 터미널 경로와 누수 검사를 거친 libghostty-vt 경계를 붙였다고 해요.

- **렌더링**: 네이티브 libghostty와 GPU 가속 wgpu 파이프라인으로 터미널 창을 그려요. M4 Max에서 50프레임 오프스크린 렌더링 p50이 3.10ms라고 밝혀요.
- **멀티 에이전트 작업 공간**: Claude, Codex, Antigravity 같은 에이전트를 격리된 분할 창에서 병렬로 돌리고, 에이전트마다 별도 worktree를 쓰며 실시간 상태 표시를 해요. 탭 바에서 바로 실행할 수 있어요.
- **분할 창 배치**: 창을 자유롭게 나눠 배치할 수 있어요.
