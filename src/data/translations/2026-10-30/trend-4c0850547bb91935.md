### 기드라는 무엇인가요

기드라는 **미국 국가안보국(NSA) 연구국**이 만들고 관리하는 소프트웨어 리버스 엔지니어링(SRE) 프레임워크예요. 윈도우, macOS, 리눅스 등 여러 플랫폼에서 **컴파일된 코드를 분석**할 수 있는 고급 분석 도구 모음을 담고 있어요.

- 주요 기능은 **디스어셈블, 어셈블, 디컴파일, 그래프, 스크립팅**이고, 그 밖에도 수백 가지 기능이 있어요.
- 다양한 프로세서 명령어 집합과 실행 파일 형식을 지원해요.
- 사용자가 직접 조작하는 대화형 모드와 **자동화 모드** 둘 다로 돌릴 수 있어요.
- 사용자는 **Java나 Python**으로 자체 확장 기능과 스크립트를 만들 수 있어요.

NSA는 기드라를 사이버보안 임무를 돕기 위해, 복잡한 리버스 엔지니어링 작업에서 생기는 **규모와 협업 문제**를 풀고 맞춤 확장이 가능한 연구 플랫폼을 제공하려고 만들었다고 설명해요. 악성 코드를 분석하고, 네트워크와 시스템의 잠재 취약점을 이해하려는 분석가에게 깊은 통찰을 주는 데 써 왔대요.

### 설치

1. **JDK 25 64비트**를 설치해요.
2. 기드라 릴리스 파일을 내려받아요. 공식 멀티플랫폼 릴리스 파일 이름은 `ghidra_<버전>_<릴리스>_<날짜>.zip`이고 "Assets" 목록에 있어요. "Source Code"라는 이름의 파일은 이 단계에 맞는 파일이 아니에요.
3. 압축을 풀어요. 기존 설치 위에 덮어 풀지 말라고 해요.
4. `./ghidraRun`(윈도우는 `ghidraRun.bat`)으로 실행하거나, `./support/pyghidraRun`으로 **PyGhidra**를 실행해요.

### 소스에서 빌드하기

필요한 도구는 JDK 25 64비트, Gradle 9.1.0 이상(인터넷이 되면 동봉된 Gradle 래퍼로 대신할 수 있어요), Python 3.9–3.15와 pip, 리눅스·macOS에서는 GCC나 Clang과 make, 윈도우에서는 Visual Studio 2017 이상 또는 C++ Build Tools(MSVC, Windows SDK, C++ ATL)예요. 소스를 받은 뒤 `gradle -I gradle/support/fetchDependencies.gradle`로 의존성을 받고, `gradle buildGhidra`로 개발 빌드를 만들면 `build/dist/`에 압축본이 생겨요.

### 스크립트와 확장 개발

이클립스용 **GhidraDev 플러그인**으로 사용자 스크립트와 확장을 만들 수 있어요. Script Manager의 VS Code 아이콘을 눌러 VS Code로 편집할 수도 있고, CodeBrowser 창에서 VS Code 모듈 프로젝트를 만들 수도 있어요. 다만 두 방식 모두 완전히 빌드된 기드라 설치본을 기준으로만 개발할 수 있어요. 기드라 자체를 개발하려면 개발 과정이 맞춰져 있는 이클립스를 권장해요.
