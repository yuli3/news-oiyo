GitHub 트렌딩에 오른 **러스트데스크(RustDesk)** 저장소의 README를 우리말로 옮겼어요. 수집 시점 기준 별 약 12만7,500개, 포크 약 2만200개이고, 라이선스는 AGPL-3.0이에요.

### 러스트데스크는 무엇인가요

저장소 설명은 **"자체 호스팅을 위해 설계된 오픈소스 원격 데스크톱 앱, 팀뷰어의 대안"**이에요. README는 Rust로 만든 또 하나의 원격 데스크톱 솔루션이라고 소개해요.

- **설정 없이 바로** 쓸 수 있어요.
- 데이터를 완전히 직접 통제할 수 있어서 보안 걱정이 없다고 해요.
- 러스트데스크가 운영하는 **랑데부/릴레이 서버**를 쓰거나, **직접 서버를 세우거나**, 아예 자기만의 랑데부/릴레이 서버를 만들 수도 있어요.

### 오용 금지 안내

README 맨 앞에는 경고문이 있어요. 개발자들은 이 소프트웨어를 비윤리적이거나 불법적으로 쓰는 것을 지지하지 않고, **무단 접속, 무단 제어, 사생활 침해** 같은 오용은 지침에 정면으로 어긋난다고 밝혀요. 오용에 대한 책임은 지지 않는다고 해요.

### 빌드 개요

- 데스크톱 버전 GUI는 **Flutter** 또는 Sciter(더 이상 권장하지 않음)로 만들어요. README의 튜토리얼은 시작하기 쉬운 Sciter 기준이고, Flutter 버전 빌드는 CI 설정을 참고하라고 해요.
- 기본 순서는 Rust와 C++ 빌드 환경 준비 → **vcpkg** 설치와 `VCPKG_ROOT` 설정 → libvpx, libyuv, opus, aom 설치 → `cargo run`이에요.
- 우분투, openSUSE, 페도라, 아치 리눅스별 패키지 설치 명령과, 페도라에서 libvpx를 다시 빌드하는 방법도 적혀 있어요.
- **도커**로 빌드 컨테이너를 만들어 빌드할 수도 있어요. 첫 빌드는 의존성 캐시 때문에 오래 걸리고, 이후엔 빨라져요. `--release`를 붙이면 최적화 빌드가 돼요.

### 코드 구조

- `libs/hbb_common`: 비디오 코덱, 설정, TCP/UDP 래퍼 등 서버와 공유하는 유틸리티
- `libs/scrap`: 화면 캡처, `libs/enigo`: 플랫폼별 키보드·마우스 제어, `libs/clipboard`: 윈도우·리눅스·macOS 파일 복사/붙여넣기
- `src/server`: 오디오·클립보드·입력·비디오 서비스와 네트워크 연결
- `src/rendezvous_mediator.rs`: rustdesk-server와 통신하며 TCP 홀 펀칭 직접 연결이나 중계 연결을 기다려요
- `flutter`: 데스크톱과 모바일용 Flutter 코드
