### 자기 꼬리를 먹는 하네스

이름처럼 자기 출력을 먹고 자라는 Claude Code 하네스예요. 세션마다 피드백 흔적이 남고, 월간 점검이 그걸 소화하고, 거기서 나온 규칙은 토큰 예산과 비교한 뒤에야 컨텍스트에 들어가요. 플러그인이나 프레임워크가 아니라, ML 연구·엔지니어링에 여러 서버에서 실제로 쓰는 `~/.claude`를 정제한 단방향 미러라고 해요. 내부 프로젝트, 문서, 데이터셋, 사고 세부 같은 프로젝트별 자료는 내보낼 때 빼요.

손으로 고친 파일은 없고, 허용 목록 → 줄·문구 제거 → 정제 → 문법 게이트 → 금지 패턴 게이트 → 시크릿 스캔 → 새 히스토리 동기화로 이어지는 fail-closed 파이프라인이 릴리스마다 저장소를 다시 만들어요. 로고까지 코드로 생성해요. 규칙과 스킬은 한국어로 쓰여 있고, 구조와 README는 영어예요.

### 무엇이 다른가요

- **제로섬 토큰 예산**: 상시 컨텍스트(CLAUDE.md + rules/)에 바이트 상한이 있고 커밋 훅이 매번 확인해요. 넘으면 막지 않고 경고만 해요. 핵심 규칙 문장을 잃는 비용이 더 크다고 봐서예요. 넘친 만큼은 점검의 "다이어트" 주기에서 갚아요.
- **기준값을 기록하는 자기 점검 루프**: 월간 점검 스킬이 목록 드리프트, 참조 무결성, 문서·구현 불일치, 만들고 안 쓰는 코드를 지난 주기 수치와 비교해요.
- **증거로 판정하는 "완료"**: 검증 출력 없이는 성공을 주장하지 않고, 서브에이전트의 주장은 file:line으로 다시 확인해요.
- **판단 근거를 산출물에 남김**: 트레이드오프와 도구 선택 측정치를 규칙·스킬·스크립트에 적어, 다음 세션이 파일만으로 추론을 재현하게 해요.
- **결정은 UI로**: 결정 팝업이 장단점 표, 실험 요약 표, 선택지별 예시를 한 번에 하나씩 보여 줘요.
- **한국어 문장 게이트**: Confluence 게시 때 끼워 넣은 대시와 늘 틀리는 맞춤법을 막고, 종료 훅이 오타를 고칠 보고서를 돌려줘요.
- **사용자 주권**: 푸시, 삭제, 학습 실행, 파괴적 쓰기는 항상 사용자가 직접 해요. 신뢰할 수 없는 웹 콘텐츠는 읽기 전용 에이전트에 격리해요.
