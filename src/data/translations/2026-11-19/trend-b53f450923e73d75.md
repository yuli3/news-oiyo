### 모델과 결과

오늘 RadixArk의 첫 모델 DaisyRose-27B를 공개해요. 기반은 Qwen3.8-27B이고, 오픈소스 강화학습 프레임워크 Miles로 학습했어요. 세션이 최대 1M 토큰인 장기 에이전트 과제로 훈련했고, 엄선한 과제 1,200개를 H200 GPU 144장에서 18일 돌렸어요. Terminal-Bench 4.1 pass@1은 5.6%에서 12.0%로 올랐고, 다른 추론·지시 따르기·코딩 벤치마크에서도 이득이 있었다고 해요. 글에 나온 차트에서는 위에 표시된 모든 벤치마크에서 원래 Qwen3.8-27B보다 점수가 높고, 가장 큰 이득은 어려운 장기 벤치마크인 Terminal Bench 4.1이라고 해요. BF16, FP8, NVFP4 체크포인트를 공개해 누구나 쓰고 이어서 만들 수 있다고 해요.

핵심은 고품질 학습 데이터, 효율적인 학습 백엔드, 안정적인 샌드박스 세 가지라고 정리해요.

### 학습 데이터

과제는 Eigent AI와 함께, 머신러닝·소프트웨어 공학·과학 등 Eigent AI의 큰 과제 풀에서 출발해 후보 수천 개를 만들었고, 최종 학습 세트에는 약 1,200개가 들어갔어요. 선정 기준은 셋이에요.

- 각 과제는 원래 모델이 하는 실수를 겨냥해요. 원래 Qwen3.8-27B를 모든 학습 과제에 돌려 보고, 멈추게 하고 싶은 실수가 드러나게 과제를 다시 설계한 뒤, 풀이율이 너무 쉽지도 어렵지도 않은 구간에 오도록 조정했어요.
- 모든 과제는 여러 문제가 이어진 긴 작업이에요. 에이전트가 추론·계획·실행의 여러 단계를 지나야 하고, 시도마다 샌드박스에서 최대 1.5시간, 도구 호출 100회 이상, 출력 토큰 256k 이상을 쓸 수 있어요.
- 보상 해킹 여지가 없도록, 모든 과제와 모델의 시도를 검토해, 실제로 풀지 않고도 통과할 수 있거나 설계 결함이 있는 과제는 학습 전에 고치거나 빼 버렸어요.

### 학습 인프라와 샌드박스

DaisyRose-27B는 Miles를 완전 비동기 모드로 학습했어요. 에이전트가 과제를 하는 동안 모델이 배우고, 서로 기다리지 않아요. H200 128장은 에이전트 과제 추론을 돌리고, 16장은 트레이너가 궤적에서 배워요. 매 스텝 뒤 갱신된 모델이 에이전트를 돌리는 128장으로 나가요. 내부 학습 백엔드는 에이전트 학습용으로, 각 스텝이 아주 긴 세션 몇 개(어떤 것은 1M 토큰)를 하니스 요약으로 여러 궤적에 접어 학습한다고 해요.

이번 릴리스에서 백엔드의 유용한 학습 작업(MFU)은 GPU 피크 연산의 37%였고, Megatron 기반 오픈소스 트레이너는 비슷한 실행에서 16%여서, 같은 학습에 GPU 시간이 57% 덜 들었다고 해요. 이득은 전문가 혼합 모델에서 더 커서, Qwen3.6-35B-A3B에서 6.2배, 약 3,000억 파라미터 GLM-5.3-Flash에서는 10배가 넘는다고 해요. 엔드투엔드는 2배 빨라서, 에이전트가 과제에 쓰는 시간까지 세면 이번 실행은 144장에서 초당 약 16,800토큰을 학습했고, 오픈소스 트레이너는 같은 GPU에서 약 8,300이었어요. 학습은 144장의 H200에서 몇 주, 총 63,000 GPU-시간이었고, 처음부터 끝까지 속도와 효율이 안정적이었다고 해요.

학습 중 에이전트의 모든 시도는 샌드박스(과제의 환경을 새로 복사한 곳)에서 명령 실행, 파일 수정, 채점을 해요. 이번 릴리스의 모든 작업은 오픈소스 AgentENV에 기반하고 수정도 기여하는 자체 서비스에서 돌렸어요. 9월 중순부터 11월 중순까지 이 프로젝트용 샌드박스가 약 944,000개 실행됐고, 동시에 최대 1,566개가 돌았어요. 서비스는 기계 한 대에서 최대 12대까지 커졌고, 업그레이드 10회 거의 전부를 학습이 돌아가는 동안 넣었어요. 아홉 주 동안 샌드박스 생성 성공률은 99%였고, 10월 말 이후는 99.95%가 넘어요. 메모리가 바닥날 때 기계가 멈추지 않게 하는 등의 수정을 이어 갔다고 해요. 프로젝트 샌드박스의 클라우드 인프라 비용은 인기 있는 클라우드 샌드박스 제공자로 같은 샌드박스를 돌릴 때보다 약 80% 낮았고, 한 방법은 실제 사용량에 따라 메모리가 늘고 줄어 기계당 더 많은 샌드박스를 돌리는 것이라고 해요.

Hugging Face에서 DaisyRose-27B를 받을 수 있고, Miles로 직접 에이전트를 학습할 수 있어요. 평가 주석에 따르면 Terminal Bench 4.1은 과제당 8회 평균이고 내부 mini-swe-agent 하니스에 요약을 켰으며, Terminal Bench 2.1은 과제당 5회에 Terminus 2 하니스를 썼어요. DeepSWE v1.1과 SWE Bench Pro v2는 각각 8회·5회 평균에 mini-swe-agent를 썼고, HLE(텍스트만)는 문제당 5회 평균으로 GPT-6 Luna가 채점하며 도구는 쓰지 않아요. IFBench는 300개 프롬프트 각 4회 평균으로 allenai/IFBench 공식 채점기의 prompt-level loose accuracy를 최종 응답(사고 과정 제외)에 적용하고, GPQA Diamond는 198문항 각 8회 평균이며 simple-evals 객관식 템플릿과 답 추출을 쓰고 실행마다 보기 순서를 섞어요.

 Eigent AI의 데이터 협력, Qwen 팀의 Qwen3.8-27B, Miles와 SGLang 커뮤니티, slime, AgentENV, Harbor 등 오픈소스에도 감사한다고 적어요.
