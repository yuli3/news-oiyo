AI타임스(박찬 기자)가 퍼플렉시티가 17일(현지시간) 밝힌 내용을 전한 기사를 끝까지 읽었어요.

복잡한 일을 여러 AI 에이전트가 나눠 수행하고 서로의 결과를 검증하는 기능을 선보였고, 오픈AI와 앤트로픽, 구글 모델을 동시에 넣어 분석과 가정을 교차 확인한다고 해요. 대상은 금융 분석, 기업 실사, 연구처럼 정확성이 중요한 작업이에요.

플랫폼 컴퓨터에 새 작업 수준 ‘멀티에이전트’를 더했고, 기존 최고 단계 울트라보다 위이며, 하나의 주도 에이전트가 최대 16개 보조 에이전트를 운영하며 일을 병렬로 진행한다고 해요. 예전에는 주도가 일을 나눠 맡기고 결과를 모았지만, 이제는 보조끼리도 직접 소통하며 조사 결과를 공유하고 오류를 지적할 수 있고, 다른 결과가 나오면 추가 조사를 한다고 해요.

기본 구성은 클로드 오퍼스 5.5, GPT-6.1 솔, 제미나이 4 카본이고, 클로드 페이블 5.2가 전체 작업을 계획하고 일을 배분하며, 사용자가 요청하거나 특정 작업에 필요하면 GPT-6 아스트라 등도 넣을 수 있다고 해요. 공동 작업 파일도 함께 수정해, 한 에이전트가 재무 모델의 매출 전망을 바꾸면 다른 에이전트에 알려 기업가치 평가에 반영할 수 있다고 해요.

울트라는 위임과 취합, 멀티에이전트는 직접 협업으로 공동 결과물을 만들고, 모델 카운슬은 여러 모델이 같은 질문에 독립적으로 답한 뒤 일치와 차이를 비교하는 기능이라고 구분해요. 멀티에이전트는 웹 버전의 퍼플렉시티 맥스 구독자에게 제공되고, 작업 강도 설정에서 고를 수 있으며, 참여 에이전트와 사용 모델도 확인할 수 있고, 스레드를 중단하면 전체 작업도 중단된다고 해요. 퍼플렉시티 공식 게시에는 크레딧을 많이 쓰니 가장 중요한 일에만 쓰라는 안내가 있어요.

기사는 지난해 브라우저 코멧, 올해 2월 컴퓨터, 최근 팀메이츠에 이은 확장이며, 자체 모델 성능 경쟁보다 여러 회사 모델을 조합하는 플랫폼에 집중한다고 짚어요.
