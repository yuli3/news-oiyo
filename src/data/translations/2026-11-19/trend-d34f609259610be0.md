### 공식 문서가 보탠 설정

factory.mastra.ai에 따르면 Mastra Factory는 저장소를 연결하면, 팀이 정한 단계·스킬·승인을 따라 이슈를 계획, 구현, 검토된 풀 리퀘스트로 바꿉니다. 기본은 Mastra 플랫폼 위에서 전부 돌아가지만, 서버를 로컬에서 돌리면서 플랫폼 자원을 쓰거나, 인증·저장소·샌드박스를 각각 따로 설정해 직접 호스팅할 수도 있어요.

권장 설정 중 하나는 Factory 서버는 자기 컴퓨터에서 돌리고, 인증, PostgreSQL, 클라우드 샌드박스는 Mastra 플랫폼이 제공하는 방식이에요. 에이전트가 고칠 저장소와는 별도 디렉터리에 `npm create factory@latest`로 프로젝트를 만들고, 플랫폼에 로그인해 조직과 리전을 고르면 설치기가 서버 파일과 의존성을 차리고 플랫폼 자원을 준비하며 `.env`에 로컬 설정을 쓴다고 해요. 그다음 GitHub 저장소, 모델 제공자, 이슈 인테이크를 연결하고, 작은 테스트 이슈를 만들어 Factory 목록에 뜨는지 확인하라고 안내해요.
