GitHub 저장소 README 앞부분(약 9,000자)을 읽고 정리했어요. Docker 설치와 커넥터 목록 등 뒷부분은 반영하지 못했어요. 이 글은 정보 제공용이며 투자 권유가 아니에요.

### 어떤 프로젝트인가

**Hummingbot**은 자동매매 전략, 즉 **봇**을 설계하고 배포하도록 돕는 오픈소스 프레임워크예요. 여러 **중앙화·탈중앙화 거래소**에서 돌아가요. README에 따르면 지난 1년간 사용자들이 **140곳 넘는 거래소**에서 **340억 달러 넘는 거래량**을 만들었어요. 코드는 Apache 2.0 라이선스로 공개돼 있고, 고빈도 매매를 '민주화'하는 게 목표래요.

### Condor: AI 하네스

**Condor**는 에이전트형 전략과 봇을 만들고 돌리는 **AI 하네스**예요. LLM 기반 의사결정을 Hummingbot API를 통한 **결정론적 주문 집행**과 연결하고, 텔레그램이나 웹 대시보드로 조작해요.

### hbot CLI

권장 실행 방법은 `hbot` 명령줄 도구예요. 봇 시작·중지, 설정 작성·조정, 거래 내역·손익·로그·상태 조회를 비대화형으로 할 수 있고, 결과를 간결한 마크다운과 안정적인 종료 코드로 돌려줘 스크립트나 **에이전트 워크플로**에 넣기 좋아요.

- Anaconda/Miniconda가 필요하고, 저장소를 받은 뒤 `make install`로 설치해요.
- 처음 쓸 때 거래소 API 키를 암호화할 키스토어 비밀번호를 정해요.
- `simple_pmm` **모의 거래** 스크립트는 바이낸스 실시간 시세로 매매를 흉내 내서 API 키 없이 시험해 볼 수 있어요.
- 실거래는 `hbot connect`로 API 키를 연결하고 `pmm_mister` 같은 전략 컨트롤러를 돌려요. 설치 하나당 봇 하나예요.

### 주의

자동매매 봇은 실제 자금 손실로 이어질 수 있어요. 처음엔 모의 거래로 충분히 시험해 보는 게 좋아요.
