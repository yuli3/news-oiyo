### 어떤 프로젝트인가

**Nitro**는 'Next Generation Server Toolkit'을 표방하는 서버 툴킷이에요. 필요한 기능을 갖춘 웹 서버를 만들고, 원하는 곳 어디에나 배포할 수 있게 해 준대요. MIT 라이선스이고 GitHub 스타는 약 1만1,300개예요.

### v3 브랜치

지금 저장소 기본 화면은 **v3 브랜치**예요. 현재 안정 버전은 Nitro v2라고 README가 따로 안내해요.

v3 README의 핵심 설명은 한 줄이에요. Nitro는 **Vite 앱을 확장해 프로덕션용 서버를 붙여 주고**, 그 서버는 **어디서나 돌아가도록** 설계됐어요.

- 서버 라우트를 추가할 수 있어요.
- 여러 플랫폼에 배포할 수 있어요.
- 설정 없이(zero-config) 쓸 수 있어요.
