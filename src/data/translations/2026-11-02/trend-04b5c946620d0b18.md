### 규칙 발견과 앤트로픽의 인정

10월 27일 X 이용자 chasm이 클로드 코드에 새로 들어간 게임 개발 규칙을 찾아냈어요. 독창적 게임, 장르 게임, 이용자가 직접 설계한 게임은 만들 수 있지만 **이미 있는 특정 게임을 이름만 바꾸거나 독창적이라 주장하며 재현해서는 안 된다**는 내용이에요.

앤트로픽의 Addy Osmani는 10월 30일 X에서 "다른 사람의 특정 게임을 재현하지 않도록 **Opus 5.5용 클로드 코드 프롬프트에 두 문장을 추가했다**"며 "클로드로 지식재산권을 침해하는 건 이용 정책 위반"이라고 설명했어요.

### 정상 작업까지 막힌다는 신고

Tom's Hardware에 따르면 Opus 5.5를 쓰는 개발자들이 게임 제작과 역공학 작업에서 잇따라 거부 메시지를 받았어요.

- 클로드 코드 GitHub에 개발 중 작업이 갑자기 멈추거나, 특정 게임의 작동 방식을 참고해 기능을 만들다 막혔다는 신고가 올라왔어요. 테이블톱 게임 형태 프로그램 수정이 거부된 사례도 있어요.
- 자기 게임의 **부정행위 방지 시스템**이나 **보안 취약점 점검** 작업도 안전 정책을 이유로 거절당했다는 주장이 나왔어요.
- 'Reverse Engineer Anything' 도구 사용 자체가 막혔다는 주장, 윈도우 **크래시 덤프 분석**이나 삼성 TV 불필요 소프트웨어 제거가 거부됐다는 사례도 있어요.

다만 이 사례들이 모두 같은 규칙 때문인지는 확인되지 않았어요. 앤트로픽은 10월 6일 '사이버 검증 프로그램'을 넓혀 고급 보안 기능 접근을 3단계로 나눴는데, 게임 복제 규칙과 같은 시스템인지도 확인되지 않았어요.
