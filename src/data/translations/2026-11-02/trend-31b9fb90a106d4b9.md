### 어떤 프로젝트인가

**Qlib**은 Microsoft가 공개한 **AI 중심 퀀트 투자 플랫폼**이에요. 아이디어 탐색부터 실제 운영까지 퀀트 리서치에 AI를 쓰도록 돕는 게 목표예요. 지도학습, 시장 동역학 모델링, 강화학습 같은 여러 ML 방식을 지원해요.

README에 따르면 Qlib은 데이터 처리, 모델 학습, 백테스트로 이어지는 **ML 파이프라인 전체**를 담고, **알파 탐색, 리스크 모델링, 포트폴리오 최적화, 주문 집행**까지 퀀트 투자 전 과정을 다뤄요. 금융 시장의 변화에 맞추는 개념 드리프트 대응 기술과, 연속적인 투자 결정을 강화학습으로 모델링하는 기능도 있어요.

### 구조

구성 요소들은 느슨하게 결합된 모듈이라 **하나씩 따로 쓸 수도 있어요.** 데이터 인프라, 다양한 학습 방식을 지원하는 학습 프레임워크, 여러 수준의 매매 전략과 집행기를 겹쳐 함께 최적화하는 구조, 그리고 종합 분석과 저비용 온라인 서빙이 들어 있어요.

### RD-Agent

최근 기능으로 **RD-Agent**를 소개해요. LLM 기반 자율 에이전트로 퀀트 R&D의 **팩터 발굴과 모델 최적화를 자동화**하는 도구이고, 논문 'R&D-Agent-Quant: A Multi-Agent Framework for Data-Centric Factors and Model Joint Optimization'(2025)도 함께 공개됐어요.
