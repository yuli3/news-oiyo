### Windows 빌드에서 알아 둘 것

- 64비트 Windows Vista 이후는 적절한 디지털 서명 없이는 VeraCrypt 드라이버를 실행할 수 없어요.
- 공식 바이너리의 `.sys`·`.exe` 파일은 GlobalSign이 발급한 **IDRIX** 인증서로 서명돼 있어요.
- 직접 빌드한 바이너리가 서명되지 않았다면 공식 바이너리보다 보통 **약 10KiB 작아요**. 컴파일러·SDK 버전이 다르면 차이가 더 생길 수 있어요.
- 서명·패키징은 `WSDK81` 환경 변수를 Windows 8.1 SDK 경로로 지정한 뒤 `Signing` 폴더의 `sign.bat`으로 해요.
