### 무엇인가

**desk-look**은 Claude Code용 플러그인(MIT)이에요. Claude Code CLI를 **Claude 데스크톱 앱의 Code 탭처럼 보이고 동작하게** 다시 그려요. 엔진은 그대로 두고 **화면을 그리는 방식만** 바꾼대요.

### 설치

Claude Code 입력창에 붙여 넣으면 돼요.

```
/plugin install desk-look --marketplace KyongSik-Yoon/cc-desktop-mod
```

소스는 GitHub에 있고 릴리스 노트도 제공해요.

### 무엇이 달라지나

소개 페이지는 같은 작업(todo.py에 `done <n>` 명령 추가, README 갱신, 명령 표와 저장 위치 노트로 답하기)을 기본 CLI와 desk-look으로 나란히 보여 줘요.

| 기본 CLI | desk-look |
|---|---|
| `● Read (todo.py)`, `● Update (...)`처럼 도구 호출이 한 줄씩 길게 나열 | "Read 2 files, edited 2 files +25 −4 ›"처럼 묶어서 접고 펼침 |
| 명령 실행이 `● Bash (...)`와 출력으로 표시 | "Ran a command ›"로 요약 |
| 표가 박스 문자(┌─┐)로 그려짐 | 일반 표처럼 렌더링 |
| `> [!NOTE]`가 ▎ 기호로 표시 | 'ⓘ Note' 블록으로 표시 |
| "Baked for 12s" | "Baked for 12s · done 10:24 AM"처럼 완료 시각 추가, 응답 복사·인용 버튼 |

데모에서 Claude는 실제 todos.json을 건드리지 않도록 스크래치패드에서 명령을 실행해요. 화면 표현만 바뀌고 작업 내용은 같다는 걸 보여 주는 예시예요.

> 소개 페이지의 설명과 비교 데모를 기준으로 옮겼어요. 설정 옵션과 릴리스 노트는 읽지 않았어요.
