### 무엇인가

**Spring AI Privacy Guardrails**는 Spring AI 애플리케이션에 개인정보 보호, 도구 권한 제어, 콘텐츠 검사를 적용하는 오픈소스 라이브러리예요. Spring Blog의 'This Week in Spring'에 소개됐고 Awesome Spring AI 확장 목록에도 올라 있어요.

> 감지한 PII를 모델에 닿기 전에 토큰화하세요. 도구가 필요한 원본만 보여 주고, 그 결과는 다시 보호하세요.

### 세 가지 핵심 기능

따로 쓰거나 함께 쓸 수 있어요.

| 필요한 것 | 기능 |
|---|---|
| 감지한 PII를 모델에서 숨기고, 선택한 도구에만 원본 허용 | Privacy |
| 현재 사용자 권한으로 도구 노출과 실행 제한 | Tool Authorization (Spring Security) |
| 규칙, 로컬 ONNX, HTTP 가드 모델로 요청·응답 검사 | Content Inspection |

PII 감지는 Presidio나 JVM 로컬 OpenNLP로 할 수 있어요.

### 적용 방법

- 요구 사항: Java 17+, Spring AI 2.0.0+, Spring Boot 4.0.0+
- 클라이언트 스타터 `spring-ai-privacy-guardrails-chat-client-spring-boot-starter:0.4.0`을 추가해요.
- `application.yml`에서 `spring.ai.privacy.rules`를 켜고 `COMMON` 프리셋을 쓰면 이메일 주소를 감지해요.
- `GuardrailsChatClientFactory`로 `GuardrailsPolicy.builder().privacy()` 정책을 넣은 ChatClient를 만들어요.

"Contact alice@example.com."을 보내면 모델은 이메일 대신 대체 토큰을 받아요(예: `Contact [EMAIL_TOKEN].`).

### 세 기능을 함께

고객 조회 예제는 세 기능을 묶어요.

- `AuthorityAuthorizationManager.hasRole("ADMIN")`으로 관리자만 도구를 쓰게 해요.
- `ToolDisclosurePolicy`로 `customerLookup` 도구에만 원본 `EMAIL_ADDRESS`를 넘겨요.
- 콘텐츠 검사를 통과했다고 조회 도구 실행 권한이 생기지는 않아요.
