### 무엇인가

**Nerd Fonts**는 개발자용 폰트에 많은 수의 글리프(아이콘)를 패치하는 프로젝트예요. Font Awesome, Devicons, Octicons 같은 인기 '아이콘 폰트'의 글리프를 추가해요. 저장소 설명 기준으로 아이콘 **3,600개 이상**, 패치된 폰트 **50종 이상**이에요.

### 설치 방법 9가지

| 방법 | 언제 쓰나 |
|---|---|
| 릴리스 아카이브 | 굵게·기울임 등 변형 묶음을 받고 싶을 때 |
| Homebrew | macOS/Linux |
| 설치 스크립트 | 자동화·스크립트 |
| Chocolatey·Scoop | Windows(비공식) |
| Arch Extra/AUR | Arch Linux |
| PowerShell 설치기 | 대화형 설정 |
| Font Fallback | 폰트 하나만 설치해 모든 폰트에 쓰기 |
| 저장소 클론 | 완전한 제어(용량이 커서 기여용이 아니면 비추천) |
| Font Patcher | 내 폰트를 직접 패치 |

### 주의할 점

- master 브랜치 파일 경로는 **안정적이지 않다**고 명시돼 있어요. 저장소 URI를 참조할 땐 확인해야 해요.
- 저장소 용량 때문에 기여할 게 아니면 클론을 권하지 않아요.

### 패처

FontForge Python 스크립트로 어떤 폰트든 패치할 수 있고, 고정폭(모노스페이스) 변형을 만드는 옵션도 있어요. Vim 플러그인이 필요하면 VimDevIcons를 보면 돼요.
