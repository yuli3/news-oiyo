### 어떤 제품 이야기인가

이 문서(2026년 8월 18일)는 **Claude for Work, Anthropic API, Claude Gov** 같은 **상업용 제품**에 관한 내용이에요. Claude Free·Pro·Max 같은 소비자 플랜(그 계정으로 쓰는 Claude Code 포함)은 별도 문서를 보라고 안내해요.

### 기본 원칙

- 상업용 제품의 입력과 출력은 **기본적으로 모델 학습에 쓰지 않아요.**
- 사용자가 엄지 위/아래 버튼 등으로 **피드백이나 버그를 명시적으로 보내거나**, 데이터 사용을 직접 허용하면 대화와 코딩 세션을 학습에 쓸 수 있어요.
- 더 자세한 건 Trust Center와 Commercial Terms를 보라고 해요.

### 피드백을 보내면

- 관련 **대화 전체**(내용, 커스텀 스타일, 대화 설정, 모델 설정 포함)를 보안 백엔드에 **최대 5년** 보관해요.
- Google Drive 같은 커넥터나 원격·로컬 MCP 서버의 원본 내용은 포함하지 않아요. 다만 대화에 직접 붙여 넣은 내용은 들어갈 수 있어요.
- 사용 전에 사용자·고객 ID와의 연결을 끊어요.
- 서비스 효과 분석, 연구, 사용자 행동 연구, 그리고 관련 법이 허용하는 범위에서 모델 학습에 쓸 수 있어요.
- 피드백을 다른 대화와 합치지는 않아요.

### 피드백 끄기

Team·Enterprise 플랜의 Primary Owner나 Owner는 **조직 설정 > 데이터 및 개인정보 > Rate chats**에서 구성원이 엄지 버튼으로 피드백을 보내지 못하게 끌 수 있어요.
