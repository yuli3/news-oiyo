### 무엇을 하나요

"Claude Code용 크리스마스 모드"예요. 컨텍스트 창이 찰수록 눈이 쌓여요(README 이미지는 컨텍스트 0%와 53% 상태를 비교해 보여 줘요).

- **색 테마 3가지**(`/santaclaude-color`): classic, frost, candle
- **크리스마스 창**(`/santaclaude-pane`): 반짝이는 전구가 달린 픽셀아트 트리가 컨텍스트만큼 높아지는 눈밭 위에 서 있고, 이번 세션의 커밋마다 트리 밑에 선물이 하나씩 놓이고, 크리스마스까지 카운트다운이 나와요. Santa Claude가 가끔 깡충 뛰거나 옆으로 공중제비를 돌거나 몸을 흔들고, 마우스를 올리거나 클릭해도 반응해요. 눈이 내리고, 가끔 루돌프가 지나가고, 12월 25일엔 썰매가 날아가요. 창 높이를 줄이면 하늘부터 포기하고 트리·산타·눈은 남겨요.
- **눈사람**: 기본은 숨김(`/santaclaude-snowman on`)이에요.
- **환영 카드**: 세션을 시작하면 Santa Claude가 나와요.
- **크리스마스 인사말 100개**: "Ho ho ho, Santa Claude is here."부터 "Rudolph found your lost semicolon."까지, 세션마다 환영 카드에, 턴마다 창 제목에 새로 나와요.
- **스피너 문구 약 48개**: "Wrapping presents…"부터 "Waking Rudolph…"까지.
- **토스트 알림**: 눈(컨텍스트)이 50%, 80%, 95%를 넘을 때와 컴팩션으로 눈이 녹을 때 떠요.

카운트다운은 내 컴퓨터의 로컬 날짜를 써서 내 자정에 넘어가요.

### 설치와 명령

터미널 세션에서 `/plugin install santaclaude --marketplace onsenhyo/santaclaude`, 셸에서는 `claude plugin install ...`, 데스크톱 앱에서는 마켓플레이스를 추가한 뒤 플러그인을 넣어요. 다만 README 작성 시점엔 저장소가 비공개라 GitHub 읽기 권한과 git 자격 증명이 필요하다고 적혀 있어요.

| 명령 | 하는 일 |
|---|---|
| `/santaclaude-pane` | 크리스마스 창 열기·닫기 (`auto`면 넓은 터미널에서 자동) |
| `/santaclaude-color` | 장식 색 바꾸기 |
| `/santaclaude-snowman on/off` | 눈사람 보이기·숨기기 |
| `/santaclaude-on`, `/santaclaude-off` | 장식 켜기·끄기 |

설정은 세션 간에 기억돼요. 선택 기능으로 `extras/xmas-statusline.sh`가 상태 줄에 "Santa Claude 🎅 D-36" 같은 카운트다운을 찍어 줘요(bash와 GNU date 필요, Windows Git Bash 가능).
