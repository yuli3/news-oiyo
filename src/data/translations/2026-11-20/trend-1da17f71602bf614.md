AI타임스(박찬 기자) 기사 전문을 읽고 정리했어요. 원 발표는 오픈AI 공식 블로그(18일, 현지시간)예요.

### AMD GPU 설계 최적화

- 오픈AI는 AI가 GPU 회로 동작을 기술한 SystemVerilog 기반 RTL 코드를 다시 쓰게 했어요. 시놉시스의 EDA 도구로 바뀐 회로가 기존 기능을 유지하는지 검증하고, 전력·성능·면적 사이의 절충을 평가했어요.
- 대상은 AMD 엔지니어들이 수년간 최적화한 설계였고, AI가 여기서 PPA 최대 14% 개선점을 찾았어요. 오픈AI는 이를 "5개월도 안 되는 기간에 약 1년 치 진전"이라고 평가했어요.
- 기사는 이 표현이 설계 개선 규모에 대한 회사의 평가일 뿐, GPU 전체 개발 기간을 1년에서 5개월로 줄였다는 뜻은 아니라고 짚어요. 14%도 GPU 전체 처리 성능이 아니라 설계 블록의 PPA 개선 결과예요.
- AMD는 일부 변경을 최근 제조용으로 제출한 설계에 반영했고, 나머지는 향후 제품용으로 설계 파일에 넣었다고 해요. 차세대 주력 CPU의 주요 블록에서도 한 자릿수 비율의 PPA 개선을 검증했어요.

### 자체 칩 할라페뇨와 모델 평가

- 첫 자체 추론 칩 할라페뇨(Jalapeño)에서는 AI가 제안한 변경으로 벡터 연산 장치와 행렬 연산 장치의 표준 셀 면적을 각각 약 13%, 10% 줄였다고 추산했고, 실제 칩의 초기 구동에서도 검증됐다고 해요.
- AMD 작업에 쓴 모델명은 공개하지 않았어요. 오픈소스 RISC-V 코어로 모델 세대별 설계 역량을 따로 평가했는데, 기존 회로 최적화 과제에서는 'GPT-6.2 아스트라'가 두 코어 모두에서 평균 점수가 가장 높았어요.
- 시놉시스와 함께 EDA 도구를 쓰는 전용 모델 'GPT-시놉시스'도 개발 중이에요.

### AI 하드웨어 설계 흐름

기사는 비슷한 사례를 함께 소개해요. 오픈AI는 3일 아스트라로 직원 2명이 일주일 안에 외장·회로기판·소프트웨어를 설계하고 외부 업체가 시제품을 만든 실험을 공개했어요(제조 전 여러 차례 검토·수정 필요). 앤트로픽도 9일 '클로드 페이블 5.2'로 전자기기 3종을 설계해, 협력사 다이오드 컴퓨터스가 만든 기기들이 회로 수정 없이 작동했다고 밝혔어요. AI 활용이 디지털 작업을 넘어 실제 기기 설계·제작·성능 개선으로 넓어지고 있다는 평가예요.
