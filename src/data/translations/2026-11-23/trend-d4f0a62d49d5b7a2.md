AI타임스 인터뷰 기사 본문 전체를 읽고 정리했어요. 수치와 목표는 회사 측이 밝힌 내용이에요.

### 문제의식

AI 영상 품질은 크게 좋아졌지만 원하는 결과를 얻으려면 여러 번 다시 생성해야 하고, 대부분 서비스가 생성할 때마다 크레딧을 차감하는 종량제라 비용이 불어나요. 기사 첫머리에는 3분짜리 홍보 영상에 50만 원, AI 드라마 연재에 일주일 300만 원 넘게 쓴다는 창작자 목소리가 나와요.

### 러다이트의 방식

- 유료 요금제는 월 39달러부터이고, 추가 크레딧 없이 반복 생성할 수 있어요. 요금제에 따라 동시 생성 수와 처리 속도가 다르고, 과도한 자동 생성이나 여러 계정으로 제한을 피하는 건 막아요.
- 외부 모델 API 대신 오픈웨이트 모델을 자체 B300 GPU에서 직접 운영해, API 방식보다 비용을 최대 99.7% 줄였다고 해요. 추가 학습과 증류·양자화로 품질을 유지했다고 설명해요.
- 광고 없이 입소문만으로 11월 주간 결제액이 전주보다 600% 넘게 늘었다고 해요.

### 시장을 보는 시각

유 대표는 힉스필드 이후 여러 모델 API를 묶어 파는 애그리게이터가 늘었지만, 박리다매 구조인 데다 사용자가 실패할수록 돈을 버는 구조이고 역마진 마케팅 경쟁까지 있어 오래가기 어렵다고 봐요. 자체 서빙으로 원가를 통제하고, 공급사 가격 인상이나 서버 장애에 따른 중단 위험도 줄였다고 해요.

### 회사와 기술

2022년 설립된 네이션에이는 AI 3D 콘텐츠 서비스 '뉴로이드'와 인터랙티브 드라마 플랫폼 '글레이즈'를 운영해 왔어요. CES 2026 최고혁신상을 포함해 3년 연속 CES 혁신상(누적 7개)을 받았고, 10월에 85억 원 규모 시리즈A 투자를 유치했어요. 현재 영상·이미지·음성·모션 그래픽 등 핵심 모델 약 5개를 잇고, 감독·작가·촬영·VFX 역할의 AI 에이전트 약 60개가 제작팀처럼 협업하며, 하루 1만 건 이상 A/B 테스트를 돌린대요. 월정액에서는 적은 횟수로 원하는 결과를 얻을수록 회사 비용도 줄기 때문에 제작 과정 전체를 개선하는 데 집중한다고 해요.

### 목표

GPU를 더 확보해 내년 연간반복매출(ARR) 1,000억 원, 3년 안에 1조 원을 목표로 해요. 연예기획사·방송사와 협업을 논의 중이고, 음성·음악까지 무제한 제공하고 장기적으로는 온디바이스 AI 영상 제작을 열겠다고 했어요.
