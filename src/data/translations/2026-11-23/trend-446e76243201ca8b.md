저장소 README 앞부분(주요 기능 소개)을 바탕으로 옮겼어요. 워크스페이스 이후 절은 수집 길이 제한으로 읽지 못했어요.

### 무엇인가

Meshery는 클라우드 네이티브 컴퓨팅 재단(CNCF) 프로젝트예요. 셀프서비스 엔지니어링 플랫폼으로, 멀티 클라우드의 모든 쿠버네티스 기반 인프라와 애플리케이션을 설계·관리할 수 있게 해요. 확장 가능한 플랫폼으로서 시각적이고 협업적인 GitOps를 제공해, README 표현대로 YAML의 족쇄에서 벗어나 멀티 클러스터 배포를 관리하게 해 준다고 해요. 브라우저에서 바로 써 볼 수 있는 Cloud Native Playground도 있어요.

### 주요 기능

- **인프라 수명주기 관리**: 클라우드 서비스와 쿠버네티스 클러스터의 설정·배포·운영을 관리하고, 380개 넘는 클라우드 네이티브 통합을 지원해요. 모범 설정을 담은 디자인 템플릿 카탈로그도 있어요.
- **여러 클러스터와 여러 클라우드**: 어떤 인프라든 여러 쿠버네티스 클러스터를 한 화면에서 관리하고, 설정·운영·관측을 일관되게 해요.
- **드라이런 배포**: 쿠버네티스 내장 드라이런으로 실제 적용 없이 배포를 시뮬레이션해요. YAML·Helm 차트·Meshery Design의 문법과 API 서버 수용 여부를 확인하고, 잘못된 리소스 정의·누락 필드·API 버전 불일치를 미리 찾고, 생성·변경될 객체를 미리 보고, CI/CD에 넣어 사전 점검을 자동화할 수 있어요.
- **시각적 협업 관리**: GitOps 중심으로 인프라와 마이크로서비스를 그림으로 함께 설계해요. 리소스 간 관계를 자동으로 추론하고, 내장 관계를 바탕으로 사용자 정의 관계도 만들 수 있어요.
- **맥락 인식 정책**: 내장 관계를 활용해 코드에서 쿠버네티스까지 설정 모범 사례를 일관되게 강제해요. Open Policy Agent의 Rego 언어를 몰라도 돼요.
- **워크스페이스**: 팀의 클라우드 네이티브 프로젝트를 정리하는 공간으로, README는 이를 "팀의 구글 드라이브"에 빗대요.
