AI타임스 기사 본문 전체를 읽고 정리했어요.

### 무엇이 나왔나

오픈AI가 19일 개발자 커뮤니티에서 음성 에이전트용 실시간 음성 모델 'GPT-라이브-1.1(GPT-Live-1.1)'의 API 제공을 발표했어요. 이 모델은 10월 15일부터 챗GPT 플러스·프로의 음성 기능에 먼저 쓰였고, 이제 개발자도 자기 서비스에 붙일 수 있어요. 라이브 세션 엔드포인트(`v1/live/sessions`)로 제공되고 음성과 텍스트 입출력을 지원해요.

### 달라진 점

- 여러 언어에서 더 자연스럽고 일관된 억양을 내고, 문자·숫자처럼 정확성이 중요한 정보를 더 잘 다뤄요.
- 지시를 따르고 작업을 끝내는 능력도 좋아졌다고 해요.
- 이전 모델처럼 듣는 동시에 말하는 전이중(full-duplex) 구조라, 사용자가 응답 중간에 끊거나 추가 질문을 해도 대화 흐름을 유지해요.
- 복잡한 추론이나 도구 사용은 개발자가 고른 백엔드 모델에 넘길 수 있어 음성 대화가 끊기지 않아요.

### 스탠바이 설정

오래 연결해 두는 음성 에이전트의 비용을 줄이려는 기능이에요.

- 개발자가 5~60초 사이로 유휴 시간을 정하면, 그동안 음성이 없을 때 모델 추론을 잠시 멈춰요.
- WebRTC 연결과 대화 기록은 유지되고, 사용자가 다시 말하면 자동으로 재개돼요. 재개 직후 첫 응답은 평소보다 늦을 수 있어요.
- 스탠바이 요금은 분당 0.02달러로, 활성 상태 분당 0.05달러보다 60% 싸요. GPT-라이브-1과 1.1 모두 쓸 수 있고, 백엔드 모델과 도구 사용료는 따로 붙어요.

오픈AI는 다국어 음성 상담, 이름·인증번호처럼 문자와 숫자를 정확히 전해야 하는 고객 지원, 대기 시간이 긴 전화 에이전트를 주요 활용 사례로 들었어요.
