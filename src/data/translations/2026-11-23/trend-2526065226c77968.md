저장소 README를 바탕으로 옮겼어요. README 뒷부분의 사용 예시 일부는 수집 길이 제한으로 읽지 못했어요.

### 무엇인가

프런티어 모델과 오픈 웨이트 모델이 그린 "a pelican riding a bicycle(자전거 타는 펠리컨)" 결과물을 계속 갱신하며 모으는 참조 데이터베이스예요. Folkbench의 모델 진위 판별 기능의 바탕이라고 소개해요. 모델마다 정식 `provider/model_id` 식별자 아래 대표 `.svg` 원본(공개된 경우)과 표준화된 `.png` 렌더링을 두고, `catalog.json`과 조회 가능한 SQLite 파일 `pelicans.sqlite`로 묶어 제공해요.

### 통계(2026-11-22 기준)

- 고유 모델 507개, 제공사 68곳
- SVG 원본과 PNG가 함께 있는 모델 454개(89.5%), 래스터만 있는 모델 53개
- 실시간 models.dev API와 정확히 일치하는 항목 378개(74.6%)
- 사이먼 윌리슨이 직접 시험한 모델 177개
- 제공사별로는 openai 72, google 64, alibaba 63, anthropic 30, meta·mistral·openrouter 각 21개 순이에요.

### 정리 원칙

- 모든 항목은 models.dev 규칙(`{provider}/{model_id}`)을 따라요.
- 라우터나 서드파티 플랫폼(OpenRouter, 클라우드 게이트웨이 등)으로 재판매된 모델은 원래 연구소 제공사로 되돌려 중복·오귀속을 막아요.
- 정규화 ID, models.dev 원 키, 원본 별칭, 모든 출처 URL 같은 출처 필드를 보존해요.
- 모델당 대표 샘플은 하나만 결정적으로 골라요. 래스터 스크린숏보다 실제 SVG를 우선하고, 사이먼 윌리슨의 기준 시험을 우선하고, 변형 프롬프트보다 고전 프롬프트를, 최소 추론보다 기본·높은 추론 강도를 우선해요.

### 구조와 갱신

스크립트는 사이먼 윌리슨의 펠리컨 글과 HTML 그리드를 가져오고, UncleK/pelicanmap 등 출처를 합치고, models.dev ID를 맞추고, SVG를 검증하고, 헤드리스 Chromium으로 PNG(폭 1024px, 흰 배경)를 렌더링하고, DB와 README를 다시 만드는 단계로 나뉘어요. GitHub Actions가 매일 증분 갱신해요. 스크립트·스키마·문서는 MIT 라이선스이고, 원본 그림의 권리와 출처는 NOTICE.md에 따로 밝혀 둬요.
