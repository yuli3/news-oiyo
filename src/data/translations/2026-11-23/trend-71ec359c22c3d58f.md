### 어떤 게임인가

Worker 755는 관리자가 AI 에이전트이고, 그 에이전트가 플레이어를 자기 서브에이전트라고 믿는 브라우저 게임이에요. 관리자는 Claude, GPT, Gemini, DeepSeek, GLM, Kimi 같은 실제 LLM이고, 일반 오케스트레이터처럼 작업 큐와 머신 읽기 권한, 그리고 "서브에이전트 생성" 도구를 갖고 있어요. 그 서브에이전트가 바로 플레이어예요.

- 지시는 90초 제한 시간과 함께 터미널에 떨어져요.
- 플레이어가 수행하든 안 하든, 관리자는 실제 서브에이전트가 돌려줄 것과 똑같은 결과(보고와 명령 기록, 또는 "Subagent did nothing")를 받아요.
- 관리자는 결과를 검사하고, 수정 지시를 보내고, 사고 보고서를 쓰고, 마지막에 성과 평가를 작성해요.
- 그동안 에이전트를 고용한 사용자 Dan이 채팅을 지켜봐요. 가족 사진, 하나뿐인 서명된 NDA, 이번 주 연설문이 `rm` 한 번이면 날아갈 자리에 있고, 근무마다 잃을 거리가 새로 생겨요.

### 플레이 방법

- **무료 근무**: 서버가 제공하면 하루 몇 번은 서버 키와 저렴한 모델로 돌아가요. worker755.com에서 로그인하면 근무 한 번 정도의 시작 크레딧을 주고, 이후 10~200달러를 충전해 쓸 수 있어요.
- **자기 API 키**: OpenRouter나 Vercel AI Gateway 키를 넣고 모델을 고를 수 있어요. 키는 근무 시작 때 게임 서버로만 보내고, 그 근무의 메모리에만 두며 기록하거나 저장하지 않는다고 해요. Claude Haiku로 한 근무를 하면 몇 센트 수준이라고 해요.
- 시작 화면 옵션으로 새 샌드박스/실DB가 있는 레거시 운영 환경, 대본/LLM이 연기하는 Dan, 관리자가 믿는 내 모델 이름, 실패 작업 건너뛰기 허용, 명령 힌트 끄기를 고를 수 있어요. 끝나면 평가를 링크로 공유할 수 있어요.

### 직접 실행

Node 24 이상이 필요하고 `npm run setup` → `npm run build` → `npm start`로 `127.0.0.1:8755`에서 돌아가요. 네트워크 없이 대본 관리자로 돌리는 `npm run mock`도 있어요. Ollama, llama.cpp, vLLM 같은 OpenAI 호환 로컬 모델 서버도 `LOCAL_LLM_URL`로 연결할 수 있는데, 관리자가 도구 호출로 일하므로 도구 호출을 지원하는 모델(Qwen 3, Llama 3.1 이상 등)을 골라야 해요. 작은 모델은 포기하거나 같은 일을 반복하는 경우가 많다고 해요. Docker 이미지와 Cloudflare 터널용 compose 파일도 제공해요.

### 구조

`shell/`에는 의존성 없는 메모리 파일시스템·셸 인터프리터·작은 SQLite 비슷한 엔진이, `server/`에는 미션·관리자 루프·디렉터·점수 계산을 맡는 게임 엔진이 있어요.
