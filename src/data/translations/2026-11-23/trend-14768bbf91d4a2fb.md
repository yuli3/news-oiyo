AI타임스 기사 본문 전체를 읽고 정리했어요. 성능 수치는 싱킹머신즈가 밝힌 것이에요.

### 모델 개요

싱킹머신즈(Thinking Machines Lab)가 20일 '잉클링 2 미니(Inkling 2 Mini)' 가중치를 허깅페이스와 자체 플랫폼 '팅커(Tinker)'로 공개했어요.

- 전체 매개변수 264억 개, 전문가 혼합(MoE)으로 실제 활성 34억 개, 반복 실행을 반영한 토큰당 실효 활성 매개변수 54억 개
- 메모리 약 20GB로, 32GB 이상 맥북·맥 미니 같은 소비자 기기에서 돌아가요.
- 이미지·텍스트 멀티모달 입력과 최대 100만 토큰 컨텍스트를 지원해요.

### 루프형 트랜스포머

일반 트랜스포머는 토큰마다 신경망을 한 번 통과시키지만, 잉클링 2 미니는 24개 계층 중 가운데 12개를 토큰마다 세 번 반복해요. 매개변수를 늘리지 않고 내부 연산을 늘려 추론력을 높이는 방식이라, 긴 추론을 글로 다 출력하지 않고도 여러 단계 판단이 필요한 에이전트형 코딩에 강하다고 해요.

### 성능

- 1,000억 개 미만 오픈웨이트 모델 중 '딥SWE v1.1' 48.2%, '발스 인덱스 v2.2' 46.5%로 비교 모델을 앞섰고, SWE-벤치 베리파이드 79.2%를 기록했어요.
- 스탠퍼드 연구진의 '와트당 지능' 평가에서 DGX 스파크 기준 0.703점으로, 큐원3.6-35B-A3B(0.430)와 젬마4-26B-A4B(0.159)보다 높았어요.
- 비행기 안에서 인터넷 없이 맥북 프로로 몇 분 만에 비행 시뮬레이터를 만들고, 오프라인 맥북 한 대에서 가상 마을 AI 캐릭터 20개를 동시에 돌리는 시연도 했어요.
- 약점도 밝혔어요. 일반 지식 검색·사실 회상은 비슷한 크기 모델과 차이가 크지 않고, 조건이 얽힌 지시와 다중 대화에서는 큐원3.8-27B보다 낮았어요. 검색과 외부 도구로 보완할 수 있다고 해요.

### 안전성 연구

루프 구조는 내부 연산을 늘리는 대신 겉으로 드러나는 추론(CoT)을 줄일 수 있어 사람이 판단을 감시하기 어려워질 수 있어요. 이를 보려고 반복 횟수를 조절하는 연구용 모델 'TML-d24-varloop-research'도 공개했어요. 반복이 늘수록 글로 생각하지 않고 풀 수 있는 작업 범위가 넓어졌지만, 출력된 사고 과정의 가독성은 유지됐고 은밀한 방해 행동이 늘어나는 뚜렷한 경향은 없었다고 해요.

아파치 2.0이라 연구·상업 이용이 가능하고 올라마, vLLM, SGLang, llama.cpp를 지원해요.
