저장소 README를 바탕으로 옮겼어요. 문제 해결 절 뒷부분은 수집 길이 제한으로 읽지 못했어요.

### 무엇인가

"네트워크 트래픽을 편하게 모니터링하는 앱"이에요. README는 크로스플랫폼, 직관적, 안정적이라는 세 가지를 내세우고, 20개 넘는 언어로 번역돼 있어요. 완전 무료 오픈소스이고 후원으로 개발을 이어 가요.

### 설치

Windows(x64·arm64·x86), macOS(Apple silicon·Intel), Linux(DEB, RPM, AppImage) 설치 파일을 GitHub 릴리스에서 바로 받을 수 있고, 다른 설치 방법도 안내해요. 운영체제별로 필요한 의존성을 함께 설치해야 한다고 강조해요.

### 기능

- 살펴볼 네트워크 어댑터 선택, 관찰할 트래픽에 필터 적용
- 캡처 보고서를 PCAP 파일로 가져오기·내보내기
- 다른 장비가 내보낸 IPFIX 플로 데이터 수집·분석
- 전체 통계와 실시간 트래픽 강도 차트
- 로컬 네트워크 연결 식별, 원격 호스트의 지리적 위치, 도메인 이름과 ASN 확인
- 6,000개 넘는 상위 계층 서비스·프로토콜·트로이목마·웜 식별
- 어떤 프로그램이 대역폭을 쓰는지 확인
- 자주 보는 호스트·서비스·프로그램 즐겨찾기, 최소화 상태에서도 감시
- 연결마다 실시간 검색·조사, 특정 이벤트 알림 설정
- 사용자 IP 차단 목록을 가져와 위험할 수 있는 연결 강조
- 사용자 정의 테마 지원

### 문서와 문제 해결

설정부터 고급 기능까지 다루는 Sniffnet Wiki가 사용 설명서 역할을 해요. 오류 대부분은 어댑터 분석에 필요한 의존성이 없어서 생기고, 오래된 하드웨어나 그래픽 드라이버에서 iced의 기본 wgpu 렌더러가 화면 깨짐을 일으키면 환경 변수로 tiny-skia 렌더러로 바꿀 수 있다고 안내해요.
