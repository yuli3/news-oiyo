Pandex 소개 페이지 전체를 읽고 옮겼어요. 수치는 모두 회사가 밝힌 것이에요.

### 무엇인가

EU와 유럽 7개국의 법령과 최고법원 판결을 그것을 발행하는 기관에서 직접 가져와, 검색과 AI 에이전트가 바로 쓸 수 있게 만든 API예요. 공식 문서 280만 건, 텍스트에 연결된 인용 3,700만 개, 기관 41곳 중 33곳은 완전 수집 상태라고 해요. Claude, Cursor, GitHub Copilot, Windsurf, Zed, Gemini 같은 도구와 함께 쓸 수 있어요.

### 기능

- 모든 관할을 하나의 REST API와 하나의 MCP 서버로 제공하고, 결과는 Markdown이나 JSON이에요.
- 어떤 언어로든 키워드·의미·혼합 검색을 할 수 있어요. 영어로 물어 프랑스 판결과 답이 되는 구절을 찾는 식이에요.
- 시점별 법령, 전체 인용 그래프, 정확 조회를 지원하고 공식 출처만 써요.
- 페이지 예시로 "배달 앱 자전거 배달원은 근로자인가?"에 프랑스 파기원 2018년 11월 28일 판결을, "독일 고용주가 즉시 해고할 수 있는 기한은?"에 독일 민법 626조 2항(사유를 안 날부터 2주)을 보여 줘요.
- 법률 AI·에이전트, 법 개정 추적이 필요한 컴플라이언스, 나라마다 스크레이퍼를 만들기 싫은 법률 리서치 제품을 대상으로 해요.

### 수집 범위

판결 240만, 법령·법전 42만 1천, 검색 가능한 구절 1억 1,200만 건이에요. EU(약 10만 건), 프랑스(약 90만 건), 독일, 네덜란드, 영국, 오스트리아, 스위스, 룩셈부르크와 유럽평의회(유럽인권재판소)를 다뤄요. 기관별로 완전·부분·미보유를 공개하는데, 예를 들어 프랑스 파기원은 2020년 이후 Judilibre로만 공개된 판결에 계정이 필요해 부분 수집이고, 일부 기관은 브라우저가 아닌 클라이언트를 거부하거나 Cloudflare 챌린지를 걸어 빠진 자료가 있다고 밝혀요. 다음 대상은 스페인, 이탈리아, 아일랜드, 벨기에, 폴란드, 체코, 에스토니아, 핀란드예요.

### 가격

- 무료: 베타 기간 하루 1,000건, 모든 관할
- 사용량제: 1,000건당 1유로, 월말 청구, 최소 금액 없음
- 피드: 월 1,000유로부터, 모든 텍스트·버전·인용을 파일로 매일 제공
- 창립 고객 10곳: 2년간 월 300유로 고정, 월 100만 건까지, 다음 수집 국가 지정 가능, 피드 반값
