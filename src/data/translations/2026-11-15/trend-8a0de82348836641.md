### 어떤 프로젝트인가요

**Jellyfin**은 "자유 소프트웨어 미디어 시스템"이에요. 내 미디어를 직접 관리하고 스트리밍할 수 있게 해 주고, 상용 서비스인 **Emby와 Plex의 대안**으로 전용 서버에서 여러 앱을 통해 기기로 미디어를 보내 줘요. Emby 3.5.2 릴리스에서 갈라져 나와, 완전한 크로스 플랫폼 지원을 위해 .NET 플랫폼으로 옮겨졌어요.

README는 "조건도, 프리미엄 라이선스나 기능도, 숨은 의도도 없다. 더 나은 걸 함께 만들고 싶은 팀일 뿐"이라고 소개해요.

### 이 저장소의 역할

- Jellyfin **백엔드 서버** 코드예요. Jellyfin GitHub 조직에는 웹 클라이언트(jellyfin-web) 등 다른 프로젝트도 많아요.
- 시작하려면 다운로드 페이지나 설치 가이드, 빠른 시작 가이드를 보면 되고 소스에서 빌드할 수도 있어요.
- 문제는 GitHub 이슈로, 새 아이디어는 기능 요청 허브로, 번역은 Weblate로 참여할 수 있어요.

### 개발 환경

- **.NET 10 SDK**가 필요하고, 서버를 디버깅하려면 IDE도 설치해야 해요. 미디어 처리를 위해 **jellyfin-ffmpeg**도 설치해야 해요.
- FreeBSD를 뺀 주요 운영체제에서 지원돼요.
- 서버는 기본적으로 웹 클라이언트 정적 파일도 함께 호스팅해요. 웹 클라이언트 파일은 jellyfin-web 저장소에서 직접 빌드하거나, 기존 설치본(예: Windows의 `C:\Program Files\Jellyfin\Server\jellyfin-web`)에서 가져올 수 있어요. 개발할 때는 웹 클라이언트를 따로 호스팅하는 방식을 권해요.
- Visual Studio에서는 솔루션(`.slnx`) 파일을 열고 F5로 실행하면 되고, VS Code나 명령줄로도 실행할 수 있어요.
