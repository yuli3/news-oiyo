자동 수집 경로(Reddit API 키 없음, Wayback 스냅샷 없음)가 막혀, 데스크톱 브라우저(로그인 없이)로 Reddit 글을 직접 열어 본문을 옮겼어요. 수치는 모두 작성자(smflx)가 직접 잰 값이에요.

### tandem.cpp란

작성자가 만든 **llama.cpp 패치 모음**으로, VRAM에 다 안 들어가는 MoE 모델을 더 빨리 돌려요. 자주 쓰이는 "핫" 전문가는 GPU에 두고 나머지는 CPU가 돕는 방식이에요. 저장소는 GitHub ewhacc/tandem.cpp예요.

### DeepSeek-V4.1-Flash를 일반 PC에서

IQ2_XS 양자화(전문가 부분 139 GiB), 사용자 1명, GSM8K 문제, greedy, 모든 엔진에서 전문가 건너뛰기 없이 같은 양자화로 잰 디코딩 속도(초당 토큰)예요.

| PC | llama.cpp | tandem.cpp | Strata |
|---|---|---|---|
| RTX 5070 Ti 16GB, RAM 64GB, i5-14600KF | 7.4 | 14.2 | 10.4 |
| RTX 5070 Ti 16GB, RAM 64GB, i5-12400F, DRAM 없는 저가 SSD | - | 10.4 | 5.7 |
| RTX 5090 32GB, RAM 128GB, i5-14600KF | 11.5 | 33.1 | 28.0 |

RAM이 64GB면 모델이 RAM의 두 배쯤이라 SSD에서 스트리밍해요.

### RAM보다 큰 모델

Qwen3.8-Flash-Next IQ3_S(78 GiB) + MTP를 RAM 32GB PC(RTX 5070 Ti 16GB, i5-12400F, 저가 SSD)에서 돌리면 llama.cpp 14.9, **tandem.cpp 34.3**, Strata 30.3이었어요.

작성자는 tandem.cpp가 특히 **모델이 VRAM과 RAM을 합친 것보다 훨씬 클 때**(16GB 카드 + 32GB RAM 같은) 강하다고 해요. DeepSeek-V4.1, gpt-oss-120b, GLM-4.5-Air, Qwen3.6에서도 일반 llama.cpp보다 **1.4~2.1배** 빨랐다고 해요.

### AMD(ROCm) 지원

이제 패치가 HIP로 빌드돼요. RX 7900 XTX(i7-8700, DDR4 64GB, PCIe 3.0)에서 Qwen3.8 IQ3_S + MTP로 같은 날 잰 결과예요.

| 엔진 | 초당 토큰 |
|---|---|
| tandem.cpp | 68.6 |
| Strata 0.2.9 | 69.7 |
| Strata의 RDNA3 포크 | 80.1 |
| Avalon(자체 IQ3_KS 양자화) | 83.6 |

일반 Strata와 비슷한 수준이에요. 이번 주 커널 작업은 CUDA/HIP 공유 코드라 NVIDIA에도 도움이 돼서 7900 XTX에서 +2.5%, 5070 Ti에서 +1.3% 빨라졌어요. 오래된 6코어 CPU에서는 AMD 전용 엔진이 여전히 앞서고, Vulkan은 아직 지원하지 않아요. 빌드 방법은 README에 있고, 작성자는 특히 32GB 머신과 AMD 카드 측정값을 환영한다고 해요.
