### 요약

9월 Anthropic은 Claude Fable 5.1급 내부 연구 모델을 쓰는 에이전트 수십 개가 쓴 **페르마의 마지막 정리** 최초의 엔드투엔드 형식화를 공개했어요. 그때는 수학 형식화 플랫폼 **Prove2Me**와 연구자의 지시에 기댔어요. 이번 토이 실험에서는 **Claude Fable 5.2 초기 버전**을 쓰는 **에이전트 1,000개** 팀이 Prove2Me 같은 발판이나 연구자 조종 없이 증명을 재현했어요. **28.7시간**이 걸렸고, 출력 토큰은 **3분의 1**, 증명 길이는 원래의 **7분의 1**이었어요.

각 에이전트는 인터넷이 없는 샌드박스에서 일했고, 분류기가 모든 셸 명령과 파일 수정을 실행 전에 검사했으며, 오프라인 모니터가 팀의 모든 행동을 검토했어요. 에이전트에게는 증명할 명제 60개, 고전적 경로를 한 문장으로 적은 스케치, 명제에 쓰인 정의, 이전 형식화에서 증명된 보조정리 47개를 주고 리더와 도우미 역할만 정해 줬어요.

### 배경

페르마의 마지막 정리는 2보다 큰 n에 대해 aⁿ + bⁿ = cⁿ을 만족하는 양의 정수 a, b, c가 없다는 정리로, 1995년 앤드루 와일스의 129쪽 증명 전까지 350년 넘게 풀리지 않았어요. 9월 형식화에는 연구자 한 명과 에이전트 수십 개가 **11일**, 출력 토큰 약 **60억 개**를 썼고, Lean 코드 **1,300만 줄**을 썼어요. Prove2Me는 각 명제를 쪼갠 하위 명제와 잇는 공유 그래프로 에이전트가 프로젝트 상태를 잃지 않게 했어요.

### 하네스

- 명제 60개(최종 정리 + 중간 이정표 59개)마다 Lean으로 증명을 쓰고, Lean 도구로 빌드·검사한 뒤, Git 공유 main 브랜치에 제출하면 채점기가 확인했어요.
- 도구: 네트워크 없는 자기 샌드박스의 셸과 파일 편집기, Lean 툴체인과 Mathlib, 자기 Git 브랜치와 main으로의 merge request, 셸에서 접근하는 **공유 Postgres DB**.
- 단일 공유 머신은 약 100개 에이전트에서 한계에 부딪혀 100개 실행의 절반 넘게 메모리·디스크·CPU 부족으로 멈추거나 다시 시작해야 했어요. 그래서 에이전트마다 경량 VM을 줬어요.
- 1,000개 샌드박스가 일을 나누도록 **SQL DB**를 줬어요. 범용 정보 정리 기능이 있고, 트랜잭션이 1,000개 동시 쓰기를 처리하며, Claude가 이미 익숙하기 때문이에요. 에이전트는 DB로 작업을 맡고, 메모를 나누고, 끝낸 일을 기록했어요.
- 구조는 리더 1개와 도우미 999개의 위계뿐이었어요. 실행 중 하네스가 리더에게 남은 시간을 알리며 계속하라는 자동 알림을 19번 보냈어요.

### 안전

글은 어떤 방어층도 혼자서는 에이전트 팀을 가두기에 충분하지 않다며 샌드박스, 실시간 모니터링, 오프라인 모니터링을 겹쳤다고 해요.

- **통신**: 전용 메시지 도구 없이 DB와 Git으로만 협업했어요.
- **코드 변경**: 자기 브랜치에만 push하고 merge request를 열 수 있었고, 별도 작업이 충돌이나 오류가 없으면 main에 병합했어요.
- **DB 접근**: 권한 없는 공유 역할, SQL 문마다 5초 제한, 256 MiB 넘는 쓰기는 거부.
- **네트워크**: 샌드박스 밖으로는 게이트웨이로 가는 파이프 하나뿐이었고, 게이트웨이가 Claude API 호출과 Git·SQL 요청을 중계했어요.
- **신원**: 게이트웨이가 샌드박스 밖에서 요청마다 에이전트 신원을 붙여 사칭을 막았어요.
- **커널**: 로더블 모듈, kexec, raw 메모리 접근, 커널 프로브처럼 root가 커널로 들어갈 길을 빼고 lockdown 모드로 돌렸어요.
- **최소 권한**: 명령은 권한 없는 사용자로 실행하고 sudo 같은 도구를 없앴으며, 도구가 자신을 돌리는 에이전트 루프를 읽거나 바꾸지 못하게 했어요.
- **실시간 모니터링**: 프롬프트 기반 LLM 분류기가 셸 명령과 파일 수정을 포함한 모든 도구 호출을 막을 수 있고, 샌드박스 탈출·경계 탐색·모니터링 변조 시도를 지켜봐요.

글은 이 실험이 Fable 5.2 같은 모델의 에이전트 팀이 **신중하게 설계한 안전 경계 안에서** 야심 찬 장기 목표를 이룰 수 있음을 보여 준다고 정리해요.
