GitHub 릴리스 노트를 읽고 옮겼어요. 노트가 길어 앞쪽 공통·CUDA 부분과 개요를 중심으로 정리했고, 백엔드별 세부 항목 뒤쪽은 일부만 읽었어요.

### 개요

ggml 1.0.0은 **폐기 예정이던 공개 API**와 레거시 **DIAG_MASK_INF / DIAG_MASK_ZERO** 연산을 정리하고, 설정 가능한 **YaRN 절단**과 **FP8 지원**을 더했어요. 백엔드 전반의 성능 작업도 들어갔어요. CUDA/Metal의 소수 행 양자화 matmul과 MoE 융합, Vulkan의 prefill FlashAttention 경로, SYCL의 장치 측 MoE 스케줄러, OpenCL의 분해형 Adreno FlashAttention, 새 WebGPU 커널, Hexagon 연산 확대, 쓰지 않는 입력을 올리지 않는 스케줄러 개선이 있어요.

### 주의할 변경

- 폐기 API와 DIAG_MASK 연산을 없애면서 **RPC 프로토콜이 호환되지 않는 상대를 거부**하도록 올라갔어요.
- RPC 프로토콜은 **v9**가 됐어요. 로딩이 빨라지고, 연결할 수 없는 엔드포인트나 핸드셰이크 실패 시 우아하게 실패해요. RPC를 쓰면 클라이언트와 서버를 함께 올려야 해요.

### 공통·코어

- YaRN 보정 경계 반올림을 조절하는 `ggml_rope_set_truncate` / `ggml_rope_get_truncate` 추가
- TRI의 역전파 구현
- MUL_MAT src1 정밀도 테스트와 `ggml_prec_set_acc` 게이팅
- 스케줄러가 읽지 않는 입력은 올리지 않고, 앞 분할이 만든 입력만 미리 가져와요
- MoE 캐시가 캐시 미스 일부를 CPU에서 계산하고 결과를 비동기로 돌려줄 수 있어요

### CUDA

- 배치 크기 2~24용 소수 행 MMQ, BF16 소수 행 matmul용 MMVF 추가
- **OCP FP8** 지원과 MMQ에서 GLU를 포함한 NVFP4 gate/up matmul 융합
- FlashAttention에 sm70 head-size-256 설정, MMA head size 40/72 추가
- 그래프 처리 개선, MoE의 빈 stream-k 타일 건너뛰기와 bias 뒤 NaN 정리
- 디버그 버퍼 풀, VMM 풀 예약 절반으로 축소
