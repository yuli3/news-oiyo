### 한 줄 소개

**Gopeed**(Go Speed의 줄임말)는 Go와 Flutter로 만든 빠르고 현대적인 무료 오픈소스 다운로드 매니저예요. HTTP·HTTPS, BitTorrent, 마그넷 링크, ed2k를 데스크톱, 모바일, 웹에서 지원해요. 브라우저 연동, JavaScript 확장, REST API, CLI, 셀프 호스팅 웹 UI도 있어요.

### 주요 기능

- **고속 다운로드**: 동시 작업, 다중 연결 HTTP 전송, P2P BitTorrent로 대역폭을 최대한 써요.
- **완전한 BitTorrent**: DHT, uTP, 웹 시드, 선택적 파일 다운로드, 트래커 관리, 비율·시간 기반 시딩 제한을 지원해요.
- **작업 관리**: 일시정지, 재개, 재시도, 일괄 작업, 검색, 카테고리, 재시작 후 복구가 돼요.
- **가벼운 네이티브 UI**: Flutter로 직접 그려서 Electron이나 WebView 껍데기가 없어요.
- **크로스 플랫폼**: Windows, macOS, Linux, Android, iOS, 웹을 지원하고 Docker와 QNAP 배포도 돼요. 한국어를 포함해 20개 넘는 언어를 지원해요.
- **JavaScript 확장**: 영상 플랫폼, AI 모델 허브, 클라우드 스토리지 같은 다운로드 소스를 추가할 수 있어요.
- **자동화**: REST API, CLI, 인증된 웹 UI, 웹훅, 다운로드 후 스크립트로 연동해요.

### AI 연동

Gopeed의 **MCP 엔드포인트**에 AI 에이전트를 연결하면 "윈도우용 최신 Gopeed 클라이언트를 받아 줘"처럼 자연어로 다운로드를 관리할 수 있어요. 제공 도구는 `resolve_task`(URL 메타데이터 확인), `create_task`, `list_tasks`, `get_task`, `get_task_status`, `get_task_stats`, `pause_task`, `continue_task`, `delete_task` 등이에요.

### 2.0.0 베타

**Gopeed 2.0.0**이 공개 베타 중이에요(현재 Beta 3). 새 인터페이스와 함께, 데스크톱·모바일 클라이언트가 FFI로 Go 코어와 직접 통신하는 네이티브 구조를 도입했어요. 안정성이 기준에 이르면 정식 2.0.0을 내고, 베타 사용자는 바로 업그레이드할 수 있지만 기존 안정판 사용자는 자동 업그레이드되지 않아요.
