GitHub 저장소 README 전체를 읽고 정리했어요. 오늘 GitHub 트렌딩에 오른 저장소예요.

### 한 줄 소개

**Tailscale**은 "WireGuard® 사설 네트워크를 쉽게" 만드는 서비스이고, 이 저장소에는 Tailscale 오픈소스 코드의 대부분이 들어 있어요. 저장소 설명은 "WireGuard와 2FA를 쓰는 가장 쉽고 안전한 방법"이에요.

### 저장소에 들어 있는 것

- **`tailscaled` 데몬**과 **`tailscale` CLI 도구**가 핵심이에요.
- `tailscaled`는 Linux, Windows, macOS에서 돌아가고, FreeBSD와 OpenBSD에서도 정도의 차이는 있지만 동작해요.
- Tailscale iOS·Android 앱도 이 저장소 코드를 쓰지만, 모바일 GUI 코드는 여기 없어요. Android 앱, Synology 패키지, QNAP 패키지, Chocolatey 패키징은 각각 별도 저장소에 있어요.
- macOS, iOS, Windows 클라이언트는 이 코드에 작은 GUI 래퍼를 더한 형태인데, 비공개 플랫폼용 GUI 래퍼는 오픈소스가 아니에요. 어떤 부분이 왜 오픈소스인지는 tailscale.com/opensource에 설명돼 있어요.

### 설치와 빌드

- 여러 배포판·플랫폼용 패키지는 pkgs.tailscale.com에서 받을 수 있어요.
- 빌드에는 **항상 최신 Go 릴리스(현재 Go 1.27)** 가 필요해요. 공식 릴리스는 Tailscale의 Go 포크로 빌드하지만, 포크를 꼭 쓸 필요는 없어요.
- `go install tailscale.com/cmd/tailscale{,d}`로 설치할 수 있어요.
- 배포판 패키지를 만든다면 `build_dist.sh`를 써서 커밋 ID와 버전 정보를 바이너리에 넣어 달라고 해요. 버그 리포트에 쓸모 있는 버전 정보가 남도록 하기 위해서예요.

### 기여

이슈는 GitHub 이슈 트래커에 올리면 되고, PR도 환영하지만 버그를 먼저 등록해 달라고 해요. 커밋 메시지는 버그를 참조해야 하고, **DCO `Signed-off-by`** 줄이 필요해요. 주로 Tailscale 직원들이 개발하며, WireGuard는 Jason A. Donenfeld의 등록 상표예요.
