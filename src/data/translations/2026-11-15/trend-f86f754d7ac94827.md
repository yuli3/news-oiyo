자동 수집 경로(Reddit API 키 없음, Wayback 스냅샷 없음)가 막혀, 데스크톱 브라우저(로그인 없이)로 Reddit 글을 직접 열어 본문을 옮겼어요. Reddit 글은 논문 초록과 링크를 옮겨 놓은 것이고, 논문 본문은 읽지 않았어요.

### 문제

웹을 쓰는 AI 에이전트는 웹페이지, 문서, 저장소, 도구 응답을 반복해서 읽어요. 그런데 필요한 건 일부 증거뿐인데도 읽기 인터페이스가 **객체 전체를 보여 주는** 경우가 많아요. 이런 과잉 읽기는 토큰과 지연 비용을 늘리고 관련 증거를 희석해요.

### SparseRead

에이전트 모델을 고치지 않고 **무엇을 읽어 들일지 통제하는 재사용 가능한 읽기 제어 계층**이에요. 세 가지로 이뤄져요.

- **Read Intent Protocol**: 바뀌어 가는 필요와 출처 범위를 추적해요.
- **Adaptive Reader Backends**: 증거를 어떻게 찾고 보여 줄지 골라요.
- **Budgeted Read Gate**: 에피소드마다 원문 노출 총량을 제한하되, 필요하면 원문 전체 보기로 충실하게 돌아가요.

통합 Reader 인터페이스로 서로 다른 자원에서 증거를 바꿔 가며 얻을 수 있어요.

### 결과

- Claude Opus 5를 포함한 **6개 모델, 5개 시나리오**에서 총 토큰을 **최대 92.9%**, 실행 시간을 **최대 89.0%** 줄였어요.
- **97%의 설정**에서 작업 품질을 유지하거나 높였어요.
- 웹 딥서치 작업에서는 토큰 31.0~43.0%, 완료 시간 23.0~37.0%를 줄였어요.
- 절제 실험으로 세 설계 요소를 검증했고, 세 가지 에이전트 프레임워크에 붙여 이식성을 보였다고 해요.

논문은 arXiv 2608.22237이고, GitHub(Liuzedooong/SparseReading)와 프로젝트 페이지가 함께 공개됐어요.
