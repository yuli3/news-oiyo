### 어떤 프로젝트인가

**Neovim**은 Vim을 적극적으로 리팩터링한 에디터예요. 목표는 이래요.

- 유지보수를 단순하게 하고 기여를 장려해요.
- 여러 개발자가 일을 나눠 맡을 수 있게 해요.
- 코어를 고치지 않고도 고급 UI를 만들 수 있게 해요.
- 확장성을 최대한 높여요.

### 주요 기능

- 모던 GUI
- C/C++, Go, Python, Rust, Lua, JavaScript 등 여러 언어에서 쓰는 API
- 스크립트로 다룰 수 있는 내장 터미널 에뮬레이터
- 비동기 작업 제어
- 여러 에디터 인스턴스 간 데이터 공유(shada)
- XDG 디렉터리 지원
- Ruby·Python 플러그인을 포함한 대부분의 Vim 플러그인 호환

### 설치

Windows, macOS, Linux용 빌드가 Releases 페이지에 있고 Homebrew, Debian, Ubuntu, Fedora, Arch Linux 등 패키지 관리자로도 설치할 수 있어요. 소스 빌드는 CMake 기반이에요.

### 라이선스

특정 커밋 이후 기여분은 Apache 2.0이고, Vim에서 가져온 코드는 예외예요.
