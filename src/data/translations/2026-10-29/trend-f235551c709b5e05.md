### 어떤 프로젝트인가

**Directus**는 SQL 데이터베이스 위에 API 계층과 관리 화면(Studio)을 씌워 주는 백엔드예요. 헤드리스 CMS, 관리자 패널, 앱 백엔드로 쓸 수 있어요. 다운로드 4,500만 회, 배포된 프로젝트 50만 개 이상이라고 소개해요.

### 주요 기능

- **REST·GraphQL API**: 데이터베이스 스키마에서 설정 없이 자동으로 만들어져요.
- **Visual Studio**: 개발자가 아닌 팀원도 데이터를 관리할 수 있는 화면이에요.
- **AI 어시스턴트**: 콘텐츠를 만들고 번역하고 바로 작업해요.
- **네이티브 MCP 서버**: Claude, Cursor, ChatGPT 같은 도구를 데이터에 바로 연결해요.
- **정책 기반 권한 관리**: 사람과 AI 에이전트 모두 필드 단위까지 권한을 줄 수 있어요.
- Postgres, MySQL, MariaDB 등 기존 데이터베이스를 그대로 써요.

### 라이선스

연매출 500만 달러 미만, 직원 50명 미만 조직은 무료로 쓸 수 있고, Open Innovation Grant 라이선스 키를 신청하면 돼요.
