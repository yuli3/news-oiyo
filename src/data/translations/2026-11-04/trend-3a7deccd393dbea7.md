1차 원문(GitHub 이슈 postmanlabs/postman-app-support#14370)을 읽고 정리했어요.

### 요지
제보자는 Postman 데스크톱이 충분한 고지·동의 없이 **AI 플러그인(Codex/Claude 관련으로 언급)** 을 자동 설치하고 API 데이터를 공유하려 한다고 주장해요. 이슈 제목에 `[SEVERE]`가 붙어 있어요.

### 본문 번역
- 초점은 “조용한 자동 설치”와 “API 데이터 공유 시도”예요. 사용자가 기대하지 않은 백그라운드 동작이라는 문제 제기예요.
- 데스크톱 클라이언트의 설치·권한·옵트인 UI가 충분한지 묻는 보안·프라이버시 성격의 제보예요.
- Hacker News에서도 높은 점수로 확산됐고, 토론 스레드가 함께 수집됐어요.

### 왜 민감한가
API 클라이언트는 토큰·컬렉션·환경변수 등 민감 데이터에 가깝게 동작해요. 자동 설치·공유가 사실이라면 기업 보안 정책과 충돌할 수 있다는 우려가 제보의 배경이에요. 다만 이 글은 이슈 제보를 옮긴 것이며, Postman 측 최종 해명·패치를 여기서 확정하지 않아요.
