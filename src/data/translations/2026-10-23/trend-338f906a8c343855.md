### 무엇인가요

**Nextcloud AIO**는 **Nextcloud 공식 설치 방법**이에요. 대부분의 기능을 하나의 Nextcloud 인스턴스에 담아 배포와 유지보수를 쉽게 해 줘요. 현재 기여자를 적극 찾고 있다고 해요.

### 기본으로 들어 있는 것

- Nextcloud Files 고성능 백엔드(Client Push), Redis·APCu 캐시
- 선택: **Nextcloud Office**, **Talk** 고성능 백엔드와 TURN 서버, Talk 녹화 서버
- 선택: **BorgBackup** 기반 백업, Imaginary(heic·pdf·svg·webp 등 미리보기), ClamAV 백신, Docker Socket Proxy(App API용)
- 쉬운 설치·관리 웹 화면, 업데이트·백업 알림
- 매일 백업을 켜면 그 뒤 모든 컨테이너와 Nextcloud·앱을 자동 업데이트해요.
- 백업 아카이브와 비밀번호만 있으면 새 AIO에서 인스턴스 전체를 복원해요.

### 운영 편의

- Nextcloud 보안 스캔 **A+**, Let's Encrypt 자동 TLS
- 기존 리버스 프록시나 **Cloudflare Tunnel** 뒤에서도 동작
- 공개 링크 업로드 기본 10GB(조정 가능), PHP·웹서버 타임아웃 3600초, PHP 프로세스당 RAM 512MB 기본
- 도메인 **하나**로 모든 서비스가 돌아가요.
- ffmpeg, smbclient, nodejs 기본 포함, 이미지 재빌드 없이 OS 패키지·PHP 확장 추가
- LDAP 사용자 백엔드, 기존 설치에서 AIO로(또는 반대로) 마이그레이션
- AIO 화면에서 무료 deSEC 동적 DNS(`*.dedyn.io`) 도메인 등록

### 보안·플랫폼

- Docker rootless, Docker Swarm, Kubernetes 설치 지원, Windows·macOS 포함 Docker가 도는 모든 플랫폼
- 대부분 Alpine Linux 기반, 많은 컨테이너가 non-root·읽기 전용 루트 파일시스템
- 전용 Docker 네트워크, 꼭 필요한 포트만 노출
- 서버 하나에 여러 인스턴스, 원격 borg 저장소 백업, 백업 무결성 검사·복구까지 AIO 화면에서 관리
