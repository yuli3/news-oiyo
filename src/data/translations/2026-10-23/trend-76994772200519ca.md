### 플로라는 무엇인가요

엔비디아가 10월 20일(현지시간) 로봇 학습 데이터를 만드는 오픈 모델 제품군 **플로라(Flora)**를 공개하고 가중치를 허깅페이스에 올렸어요. 사람과 로봇의 작업 영상을 보고 **무슨 일이 언제 일어났는지(시간 정보가 담긴 지시문)**와 **얼마나 잘했는지(보상과 실패 이유)**를 자동으로 기록해요.

플로라는 엔비디아 휴머노이드 로봇 파운데이션 모델 **GR00T** 학습에 실제로 쓰는 데이터 엔진이에요. GB300 GPU 서버 512개로 하루 최대 **20만 시간** 분량의 영상을 처리할 수 있대요.

### 왜 필요한가요

로봇 파운데이션 모델을 학습하려면 영상만이 아니라 동작 시점, 수행 품질, 실패 지점을 설명하는 정밀한 데이터가 필요해요. 지금까지는 사람이 직접 영상을 분석하거나 비싼 대형 멀티모달 모델 API를 써야 해서 대규모 확보에 한계가 있었어요.

### 세 가지 모델

- **Flora-TempSeg 9B**: 영상에서 작업과 하위 동작이 일어나는 구간을 나눠요.
- **Flora-Captioner 27B**: 구간마다 시간 정보가 들어간 동작 설명을 만들어요.
- **Flora-Rewarder 27B**: 동작 품질과 진행 상황을 평가하고 성공 여부와 실패 원인을 분석해요.

예를 들어 물체를 집는 영상이면, 집기가 언제 시작됐는지, 제대로 잡았는지, 어느 단계에서 미끄러졌는지를 기록해요. 1인칭 사람 영상과 로봇 영상을 모두 처리해요. 이렇게 만든 데이터는 사전학습 데이터 필터링·균형 조정, 강화학습 사후학습의 단계별 보상, 실제 배포 환경의 수행 능력 모니터링에 쓰여요.

### 성능

- 50개 에피소드 자체 평가에서 플로라 **57.1%**, GPT-6 아스트라(최대 추론) **53.7%**였어요.
- 세부 결과는 엇갈려서, 사람 영상의 동작 구간 분할은 플로라가 앞섰지만 로봇 영상 일부 항목은 아스트라가 높았어요.
- **로보리워드** 평균절대오차(MAE)는 플로라 40.0, 아스트라 55.4로 플로라가 낮았어요.
- **덴스리워드벤치** 실패 탐지 재현율은 53.3%였어요.

### 비용

엔비디아 추정으로는 GB300 GPU 8개를 시간당 10달러에 쓸 때 원본 영상 1시간 처리 비용이 **약 0.72달러**예요. GPT-6 아스트라를 최대 추론으로 쓰면 같은 분량에 **약 88.49달러**가 들어, 플로라가 약 122~125배 싸다는 계산이에요.

### 라이선스와 주의점

가중치는 엔비디아 **비상업용 라이선스**로 연구 목적에만 쓸 수 있고, 상업적 이용이나 실제 제품 환경은 지원하지 않아요. 플로라의 출력은 로봇을 제어하는 명령이 아니라 주석·평가 정보이며, 안전성을 판단하는 유일한 수단으로 쓰면 안 된다고 해요.
