> GitHub README를 기준으로 옮겼어요. 개발 환경과 서드파티 업데이트 안내 뒷부분은 줄였어요.

### 무엇인가요

**Nextcloud 서버**는 "모든 데이터를 위한 안전한 집"을 내세우는 셀프 호스팅 플랫폼이에요.

- 📁 **접근**: 파일, 연락처, 캘린더 등을 내가 고른 서버에 저장해요.
- 🔄 **동기화**: 여러 기기 사이에 데이터를 맞춰 둬요.
- 🙌 **공유**: 보여 주고 싶은 것만 다른 사람에게 열어 함께 작업해요.
- 🚀 **확장**: 캘린더, 연락처, 메일, 화상 채팅 등 앱 스토어의 수백 개 앱
- 🔒 **보안**: 암호화, HackerOne 버그 바운티, 2단계 인증

### 쓰는 방법

- 웹사이트나 앱에서 제공업체에 가입해요.
- 내 하드웨어에 직접 서버를 설치하거나, 바로 쓰는 어플라이언스를 써요.
- Nextcloud가 미리 깔린 기기를 사요.
- 회사용으로 호스팅해 주는 서비스 제공자를 찾아요.

기업, 공공, 교육 기관은 Nextcloud GmbH의 **Nextcloud Enterprise**를 볼 수 있어요.

### 기여하기

개발 말고도 번역, 디자인, 테스트, 사용자 돕기 등 기여 방법이 많아요. 개발 흐름은 로컬 환경 구성 → good first issue 고르기 → 브랜치 작업(`git commit -sm`으로 서명) → PR 생성과 리뷰어 멘션 → 리뷰 반영 → 머지예요.

- 서드파티 구성요소는 git 서브모듈이라 `git submodule update --init`이 필요해요.
- First run wizard, Activity처럼 정식 릴리스에 기본 포함된 앱 일부는 master에 없어 `apps` 폴더에 직접 클론해야 해요.
- `stable*` 브랜치는 릴리스 아카이브처럼 다룰 수 있지만 운영 환경엔 쓰지 말래요.

### 테스트

PHP 단위 테스트는 PHPUnit, PHP 통합 테스트는 Behat, JS/TS 단위 테스트는 Vitest, E2E는 Playwright를 써요. BrowserStack(크로스 브라우저), WAVE(접근성), Lighthouse(성능)도 활용해요.
