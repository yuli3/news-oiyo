### 무엇이 나왔나요

앤트로픽이 10월 21일(현지시간) AI 기반 코드 보안 분석 도구 **클로드 시큐리티(Claude Security)** 최신 버전을 **공개 베타**로 출시했어요. 대상은 **클로드 엔터프라이즈** 고객이에요. 4월 공개 베타 시작 뒤 수천 개 조직이 이 도구로 **100만 개 이상의 취약점**을 찾았대요.

### 핵심: 일회성 검사에서 지속 분석으로

- 예전에는 사용자가 직접 검사를 시작해야 했지만, 이제는 연결된 저장소의 변경을 추적해 **위험도와 복잡도에 따라 정기적으로** 분석해요.
- 초기 심층 검사 뒤에는 코드가 바뀔 때마다 점검해서, 결과가 실제 코드 상태를 반영하게 했어요.
- 프로젝트 하나에 **여러 저장소를 연결**할 수 있어요. 개별 서비스에선 안 보이지만 서비스 사이 연동에서 생기는 취약점, 예를 들어 백엔드가 클라이언트에서 검증했으리라 믿고 입력값을 그대로 받는 문제도 잡을 수 있어요.
- GitHub 앱 연결을 지원하고, GitHub Enterprise Server와 액세스 토큰을 쓴 GitLab 등도 연결할 수 있어요.

### 수정 추적과 맥락 반영

- **수정 자동 추적**: 클로드 시큐리티 안에서 고치든 다른 도구로 고치든 코드 변경을 확인해 해결되면 '수정 완료'로 표시하고, 같은 취약점이 다시 나오면 자동으로 '미해결'로 되돌려요.
- **기업별 지식 기반**: 프로젝트마다 배포 방식, 적용 중인 보안 정책, 운영 환경을 기록할 수 있어요. 코드에서 **위협 모델**을 만들고 보안 담당자가 검토·수정할 수 있어요. 이후 검사는 이 정보로 실제 위험이 큰 문제를 고르고, 이미 다른 통제로 막힌 위험은 굳이 지적하지 않아요.
- **심각도와 공격 경로**: 위협 모델 기준으로 심각도를 매기고, 공격자가 취약한 코드에 닿는 경로와 위험이 생기는 과정을 설명하며 도식도 줘요.

### 연동

- 새 **API**로 프로젝트와 취약점 목록을 조회하고, 항목을 해결하거나 다시 열고, 연결 저장소를 관리할 수 있어요.
- 새 취약점이 발견되면 **웹훅**으로 외부 시스템에 알려요.
- 클로드.ai와 클로드 코드용 **MCP 커넥터**로 같은 세션에서 취약점을 보고, 원인을 묻고, 수정하고, 해결 표시까지 할 수 있어요.
- 역할 기반 접근 제어로 조회, 분류, 프로젝트 생성 권한을 사용자별로 나눠요.

### 모델과 크레딧

클로드 시큐리티는 '클로드 미소스'를 포함한 앤트로픽 모델 제품군을 쓰고, 미소스 접근을 위한 별도 사이버 검증 프로그램 가입은 필요 없대요. 클로드 엔터프라이즈 고객은 두 달 동안 매월 **2만 5,000달러** 상당의 무료 크레딧을 받을 수 있고, 2026년 12월 31일까지의 사용량에 적용돼요.
