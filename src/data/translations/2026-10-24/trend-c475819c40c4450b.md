### 무엇인가요

**todo**는 Claude Code 채팅 옆에 TODO 목록을 띄워 두는 플러그인이에요. 창(pane)에서, `/todo` 명령으로, 또는 Claude에게 부탁해서 항목을 추가·완료·수정·삭제해요. 목록은 평범한 마크다운 파일이라 세션이 끝나도 남고 어떤 편집기로도 읽을 수 있어요.

### 기능

- 채팅 옆 창에 **전역 목록**과 **현재 프로젝트 목록** 두 탭이 있어요. git 저장소 안에서는 프로젝트 목록이, 밖에서는 전역 목록이 기본이에요.
- 프롬프트 위에 열린 항목 수, 다음 항목, 기한 지난 항목을 한 줄로 보여 줘요.
- `/todo`는 모델 턴 없이 **즉시** 목록을 바꿔요.
- "롤백 스크립트 검토를 TODO에 넣어 줘"처럼 부탁하면 Claude가 관리해요.
- 항목마다 우선순위, 마감일, 메모를 달 수 있고 우선순위→마감일 순으로 정렬해요.
- 저장 위치는 `~/.claude/todo.md`(전역)와 프로젝트 git 루트의 `TODO.md`예요.
- 한국어·영어 UI를 자동으로 골라요.

### 설치

Claude Code 프롬프트에서 `/plugin install todo --marketplace wlsdnen/claude-code-todo`를 입력하고 y로 마켓플레이스를 추가한 뒤 범위를 골라요. Claude Code CLI 2.1.287 이상, 데스크톱 앱 Code 탭, 또는 VS Code 확장 2.1.299 이상이 필요해요. `claude -p`, Agent SDK, 클라우드 세션에서는 창이 그려지지 않아요.

### 사용법

- 창에서: 행 선택 시 메모 열기, `d` 완료 전환, `e` 편집, `x` 삭제, 아래 입력란에서 추가. `ctrl+x tab`이나 클릭으로 포커스를 옮겨요.
- 명령: `/todo add Fix flaky test +2d`, `/todo -g add Ship docs !high fri`, `/todo done 2`, `/todo edit 2 …`, `/todo rm 3`. `-p`/`-g`가 없으면 기본 목록을 써요.
- 우선순위는 `!high`, `!mid`(기본), `!low`, 마감일은 `today`, `+3d`, `10/25`, `2026-10-25` 등이고 `오늘`, `내일`, `모레`, `금요일` 같은 한국어도 돼요.

### Claude 도구와 개인정보

플러그인은 Claude에게 `todo` 도구 하나를 주는데, 사용자가 TODO를 물을 때만 쓰고 스스로 항목을 추가하지 말라고 설명돼 있어요. Claude 내장 세션 작업 목록과는 별개예요. **네트워크 요청을 하지 않고** 데이터를 어디에도 보내지 않으며, 프로젝트 루트를 찾으려 `git rev-parse --show-toplevel`을 실행하고 언어 설정용 환경 변수를 읽는 정도래요.
