> VibeTerm 소개 페이지의 앞부분(기능 소개, 비교표 도입부)을 기준으로 옮겼어요. 비교표 전체와 하단 내용은 읽지 못했어요.

### 무엇인가요

**VibeTerm**은 AI 코딩 에이전트 여럿을 한 터미널에서 지휘하는 앱이에요. 누가 일하고 누가 사용자를 기다리는지 탭마다 보여 주고, 내 PC와 SSH 서버 모두에서 쓸 수 있어요. Windows·macOS·Linux용이고 무료이며 자동 업데이트돼요. 지원 에이전트는 **Claude Code, Codex, Gemini CLI, OpenCode** 네 가지예요.

### 주요 기능

- **상태 감지·알림**: 화면과 에이전트 훅을 읽어 탭마다 작업 중/입력 대기/멈춤/완료 점을 붙여요. 무엇을 묻는지까지 데스크톱 알림이나 웹훅(ntfy)으로 알려 주고, `Ctrl+Shift+N`으로 가장 오래 기다린 탭으로 가요.
- **AI ↔ AI**: 탭 사이 복사·붙여넣기를 에이전트가 직접 해요. 리더가 도우미를 별도 워크트리에 띄워 결과를 가져오거나, `vibeterm ask` 한 줄로 다른 탭의 AI에게 물을 수 있어요. 위험한 일은 승인 창으로 사람이 확인해요.
- **AI 비서**: "확인이 필요한 탭 있어?"처럼 말로 앱을 조작해요. 로그인해 둔 Claude Code로 돌아서 따로 API 키가 필요 없대요.
- **사용량·한도**: 에이전트 로그에서 토큰과 비용을 모아 오늘·7일·30일, 에이전트·모델·폴더별로 보여 주고, 24시간 예산의 80%·100%를 넘으면 알려 줘요. CSV로 저장할 수 있어요.
- **변경 보기**: AI가 고친 코드를 나란히 보고 줄에 댓글을 달아 에이전트에게 보낼 수 있어요.
- **폰에서 이어하기**: 설정 하나로 이 PC와 서버의 새 Claude 세션을 폰의 Claude 앱에 띄워요(Codex는 실험적).
- 스크린샷을 `Ctrl+V`하거나 끌어다 놓으면 서버에 올리고 경로를 프롬프트에 넣어 줘요.

### 다른 도구와 비교

페이지는 Windows 설치 파일이 **9.6MB**로 Warp의 약 14분의 1, Termius의 약 35분의 1이고, 계정이나 유료 플랜 없이 모든 기능이 0원이라고 강조해요.
