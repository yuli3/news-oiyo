### 무엇이 나왔나요

디자인 플랫폼 **Canva**가 22일(현지시간) 자체 이미지 생성 모델 **Canva Craft**를 공개했어요. 사진을 그럴듯하게 만드는 데 그치지 않고 **디자인 구성과 글자 배치**까지 이해하도록 설계해, 생성한 이미지를 바로 편집 가능한 디자인으로 쓰게 하는 게 특징이에요.

- 최대 **2K 해상도**, **30가지 이상** 화면 비율(소셜 게시물부터 포스터·배너까지)
- 공개 당시 **DesignArena** 이미지 생성 모델 순위 **4위**
- 인물 부문(87개 모델 중)과 풍경·자연 부문(85개 중) **1위**, 추상·패턴 2위, 제품 이미지 4위

### 2단계 구조

일반 모델은 프롬프트로 픽셀을 바로 만들지만, Craft는 먼저 **들어갈 요소, 배치, 상대 크기, 시각적 위계, 텍스트**를 분석해 설계안을 만들고, 별도의 렌더링 모델이 최종 이미지를 그려요. 지난해 낸 디자인 이해 모델을 완전한 자체 프런티어 생성 모델로 키운 거래요.

이 구조 덕에 이미지 속 글자가 잘 읽히고 사물 위치와 크기가 정확해요. 특정 요소를 고칠 때 전체가 바뀌는 문제도 줄어 원래 구도를 지키며 다듬을 수 있대요.

### 학습 데이터와 방법

사진 중심 데이터 대신 Canva 라이브러리의 **수백만 개 디자인 템플릿**(포스터, 소셜 콘텐츠, 프레젠테이션, 인포그래픽, 메뉴, 타이포그래피 레이아웃)으로 학습했어요. 사전 학습 뒤 지도 미세조정과 강화학습을 했고, Canva 디자이너들이 **2만5,000쌍 넘는** 이미지를 비교 평가했어요. 자동 평가와 디자이너 판단이 갈리면 디자이너 쪽을 따랐대요.

### 편집과 다국어

- **Magic Layers**로 결과물을 텍스트·이미지 같은 개별 요소로 나눠 고칠 수 있어요.
- 참조 이미지 기반 생성과 고급 편집을 더할 계획이에요.
- 프롬프트는 원하는 언어로 쓰고, 이미지 속 텍스트는 **55개 언어**로 만들 수 있어요.

### 효율과 안전, 제공 방식

모델 증류로 추론 단계를 줄이고 계획 단계용 자체 추론 엔진을 만들어 기존 내부 모델보다 크게 빨라졌대요. 더 싸고 빠른 Craft-fast, Craft-ultrafast도 준비 중이에요. 안전 검증엔 **Canva Shield**를 써서 입출력, 브랜드 안전성, 문화적 맥락을 평가하고 신고 기능도 둬요. 전 세계 사용자는 **Dream Lab** 메뉴에서 쓸 수 있고, 개발자와 기업은 공개 API로 통합할 수 있어요. MCP 서버로 외부 AI 비서와 자동화 흐름도 지원하려 한대요.
