### 무엇이 나왔나요

AWS가 22일(현지시간) 머신러닝 플랫폼 **Amazon SageMaker AI**의 새 기능 **Training Sessions**를 정식 출시했어요. 개발자가 학습 절차와 평가 기준을 **코드로 직접 정의**하면서, GPU 운영, 분산 학습, 오류 복구, 학습 상태 저장 같은 인프라는 서비스에 맡기는 방식이에요. 기업 업무에 특화된 AI 에이전트 개발을 쉽게 하려는 거예요.

### 왜 필요한가요

기업용 에이전트는 좋은 모델만으로 부족하고, 사내 절차를 따르고 알맞은 도구를 고르며 작업 성공 여부를 판단할 줄 알아야 해요. 기존 SageMaker AI도 미세조정과 강화학습을 지원했지만 GPU 종류, 학습 환경, 분산 설정을 직접 잡아야 했어요. 지난해 12월 서버리스 맞춤화를 도입했지만 세밀한 제어엔 한계가 있었대요. 이번 기능은 **서버리스의 편의와 개발자의 제어권**을 합쳤어요.

### 어떻게 쓰나요

- 답 생성부터 평가, 모델 업데이트까지 직접 구성하고, 순서를 바꾸거나 자체 보상 기준을 넣고, 여러 단계를 조합할 수 있어요.
- AWS가 든 예는 **GRPO**예요. 한 질문에 여러 답을 만들고, 개발자가 쓴 평가 함수가 점수를 매기면 상대 점수로 모델을 업데이트하는 걸 반복해요.
- 학습 중간에 결과를 보고 절차를 고칠 수 있고, 모델이 GPU 메모리에 있는 동안 별도 추론 엔드포인트 없이 RL 실험을 해요.
- LoRA부터 전체 미세조정까지 쓸 수 있지만, 모델별 지원 조합은 문서를 확인해야 해요.

### 초기 사례

- **ImagineSoftware**: 강화학습으로 의료 청구 거절 건 분류 모델을 만들었어요.
- **Karini AI**: Amazon Neptune 지식 그래프와 여러 단계로 상호작용하는 에이전트를 위해 GPT-OSS-20B를 맞춤화했어요.

기사는 이 사례만으로 정확도나 비용 효과가 입증된 건 아니고, AWS가 구체적 수치를 공개하지 않았다고 짚어요.

### 요금과 지원 범위

GPU 예약 시간이 아니라 **처리한 토큰** 기준으로 입력 처리, 답 생성, 학습에 각각 요금이 붙어요. 개발자 평가 코드가 도는 동안엔 과금이 멈춰요. 별도 컴퓨팅·스토리지·평가·서비스 운영 비용은 따로예요. 지원 모델엔 GPT-OSS-20B, Gemma-4-31B-it, Qwen3.6-27B, Qwen3.8-27B 등이 있고, SageMaker Studio나 Python SDK로 써요. 데이터와 체크포인트는 고객이 고른 리전의 S3에 저장하고, 고객 데이터나 맞춤 가중치를 다른 모델 학습에 쓰지 않는대요.
