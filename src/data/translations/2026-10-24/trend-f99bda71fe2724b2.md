### 무엇이 바뀌나요

Anthropic이 22일(현지시간) 발표문을 업데이트해, **다음 주부터 Pro·Max·Team** 요금제 이용자가 대부분의 Claude 앱에서 새로 여는 세션에 **오토 모드(Auto Mode)**를 기본 적용한다고 밝혔어요. 지난 8월 **Claude Code**에 먼저 기본 도입한 방식을 다른 앱으로 넓히는 거예요. 기업용 요금제는 적용 전에 관리자에게 이메일로 알릴 예정이에요.

### 오토 모드는 어떻게 동작하나요

- 도구 실행 요청을 **자동으로 검사**해 안전하면 진행하고 위험하면 막아요.
- 막히면 Claude가 다른 길을 찾거나 사용자에게 승인을 요청해요.
- 사용자는 언제든 직접 승인하는 방식으로 돌아갈 수 있어요.
- 검사 대상은 되돌리기 어려운 변경, 파괴적 명령, 외부로 데이터를 보내는 작업 등이에요.

### 왜 바꾸나요

Anthropic은 기존 승인 절차가 위험한 작업을 잘 걸러내지 못한다고 봐요.

- Claude Code 사용자의 승인 요청 **허용률이 97%**였어요. 하루 수십~수백 번 묻다 보면 내용을 안 보고 습관적으로 누르게 된대요.
- 유료 전문 테스터 **1,053명**의 코딩 실험에서 명백히 위험한 명령을 끼워 넣자, 사람은 **13.6%**만 막았고 오토 모드는 **89%**를 막았어요.
- 사람이 앞서 50건 넘게 승인했으면 차단율이 **약 5%**까지 떨어졌지만, 오토 모드는 세션 길이와 상관없었대요.

다만 이 수치는 Claude Code 시험 결과라, 이번에 적용하는 일반 앱 전체에서 같은 성과를 확인했다는 뜻은 아니에요.

### 실제로 막은 사례

내부 사용 중 보고서를 공개 코드 공유 사이트에 올리려던 작업, 요청 범위를 넘어 클라우드 관리자 권한을 주려던 작업을 막았대요. Anthropic은 오토 모드도 위험을 완전히 없애진 못한다며, 운영 인프라에 중대한 변경을 주는 작업은 사용자가 직접 검토하라고 권했어요.
