> 블로그 페이지가 자바스크립트로만 그려져 자동 수집에서 본문이 비었어요. 사이트 번들에 들어 있는 1.3 릴리스 글의 문장 조각을 기준으로 옮겨서, 일부 문단과 OSC-7501 설명은 읽지 못했어요.

### 어떤 릴리스인가요

Rune은 명령줄을 중심에 둔 빠른 키보드 중심 IDE예요. 1.3은 Rune을 **오픈소스로 공개한 뒤 첫 릴리스**라서 커뮤니티 기여가 처음 들어갔대요. 업그레이드는 콘솔에서 `console upgrade`, 패키지는 `console pkg update-all`로 해요.

### 새 그래픽 파이프라인

`DrawImage(Image) bool` 형태의 새 그래픽 파이프라인이 들어갔어요. 처음 쓰인 곳은 **Kitty 그래픽 프로토콜** 지원으로, 호환 터미널 앱의 이미지를 Rune 터미널 안에 띄워요. 터미널에 그치지 않고 편집기와 Agent 상태 표시줄에도 이미지를 넣을 수 있고, UI 커스터마이징이 더 온다고 해요. 새 `browser` 패키지(`pkg install browser`)도 나왔어요.

### TypeScript Tier 1 (베타)

TypeScript가 Tier 1 지원을 받았어요. JavaScript/JSX와 TSX 패키지는 Tier 2로, 언어 서버 없이도 심볼 인덱스로 이동할 수 있어요. TypeScript 패키지를 깔면 번들된 **네이티브 TypeScript 7 서버**로 완성, 진단, 이동, 이름 바꾸기, 포매팅을 쓰고, 서버를 돌리는 데 Node.js가 필요 없어요. 명령 프롬프트에서 import 정리와 quick fix도 되고, 모노레포 패키지를 넘나드는 이동도 지원해요.

### Helix 편집기와 헤드리스 노드

- 새 **Helix 편집기와 프리셋**으로 선택 후 편집하는 방식을 쓸 수 있어요.
- `rune --headless`로 띄운 노드는 네트워크에 붙고, 그 작업 공간을 로컬 Rune에서 열 수 있어요.

### 에이전트 상태 표시줄

에이전트 상태를 Idle(모델과 컨텍스트 표시), Sending, Reasoning, Receiving, Executing(도구 실행), Asking(답을 기다림)으로 보여 줘요. `runectl status wrap -- <명령>`으로 오래 걸리는 명령을 감싸 주의가 필요한 때를 알 수 있어요(`pkg install runectl`).

### 작업 공간 복원

작업 공간을 다시 열면 파일, 커서 위치, 창 배치, 터미널, 작업에 더해 **Agent 대화와 다른 확장 탭**까지 되살려요.
