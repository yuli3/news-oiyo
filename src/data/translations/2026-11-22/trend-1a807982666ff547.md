### 무엇인가

MetaMask 브라우저 확장 프로그램의 소스 저장소예요. 최신 버전은 공식 웹사이트에서, 사용 도움은 사용자 지원 사이트에서 받을 수 있어요. 일반 질문과 기능 요청은 커뮤니티 포럼으로 안내해요. Firefox, Google Chrome, Chromium 기반 브라우저를 지원하고 최신 브라우저 사용을 권장해요. MetaMask 호환 앱 개발은 Developer Docs, 기여는 Contributor Docs와 Extension Docs를 보라고 해요.

### GitHub Codespaces로 시작하기

- 로컬 대신 Codespaces로 5분 안에 개발 환경을 띄울 수 있어요. 무료 월 한도를 넘으면 실행 시간과 저장 공간 모두 과금돼요.
- 브라우저에 원격 VS Code가 열리면 Simple Browser에서 noVNC로 접속하고, 데스크톱에서 MetaMask가 미리 설치된 Chrome이나 Firefox를 띄워요. 코드를 고친 뒤 `yarn start`로 개발 모드 빌드를 하면 1~2분 뒤 변경이 보여요.
- 비용 팁: 30분 동안 쓰지 않으면 일시 중지되고 30일 동안 쓰지 않으면 자동 삭제돼요. 쓰지 않는 Codespace는 지우고 한두 개만 남기거나, 브랜치를 바꿔 재사용하라고 권해요.
- 내부 개발자가 아니면 기본 Infura 키가 무료 요금제라 초당 요청 수가 매우 제한돼요.

### 로컬 빌드

- `nvm use`로 맞는 Node 버전을 고르고, `npm install -g corepack` 후 `corepack enable`로 프로젝트별 Yarn을 써요. 최신 Yarn은 전역 설치용이 아니라고 해요.
- `.metamaskrc.dist`를 `.metamaskrc`로 복사하고 `INFURA_PROJECT_ID`에 개인 Infura API 키를 넣어요. Infura 계정은 무료로 만들 수 있어요.
- MetaMetrics를 디버깅하려면 Segment 쓰기 키, 처리되지 않은 예외를 디버깅하려면 Sentry DSN 값을 넣어요. 개발용 지갑 비밀번호를 `PASSWORD`에 넣어 매번 입력하지 않게 할 수도 있어요.
