### MuJoCo란

MuJoCo는 **Mu**lti-**Jo**int dynamics with **Co**ntact의 줄임말이에요. 로보틱스, 생체역학, 그래픽·애니메이션, 머신러닝 등 관절 구조물이 환경과 상호작용하는 모습을 빠르고 정확하게 시뮬레이션해야 하는 분야의 연구·개발을 돕는 범용 물리 엔진이에요. 구글 딥마인드가 관리해요.

### 구조

- 연구자와 개발자를 위한 C API를 제공해요. 런타임 시뮬레이션 모듈은 성능을 극대화하도록 튜닝돼 있고, 내장 XML 컴파일러가 미리 할당한 저수준 자료구조에서 돌아가요.
- 데스크톱 창과 웹 브라우저에서 인터랙티브 시각화를 할 수 있고, 다양한 유틸리티 함수를 노출해요.
- Python 바인딩과 Unity 게임 엔진 플러그인도 있어요.

### 써 보기

- 설치 없이 mujoco.org나 live.mujoco.org에서 WebAssembly 버전 MuJoCo Studio로 직접 모델을 끌어다 놓고 볼 수 있어요(네이티브 C보다 느려요).
- Getting Started 가이드로 미리 빌드된 릴리스를 받아 MuJoCo Studio나 기존 `simulate` 뷰어를 실행해요.
- Python 사용자를 위한 IPython 노트북 튜토리얼이 있어요. 기초, 절차적 모델 편집, 멀티스레드 rollout, LQR 제어기 합성, 최소제곱 튜토리얼 등이에요.
- 로봇 정책 학습·배포는 MuJoCo Playground 문서를 참고하라고 해요. GPU 가속 강화학습, 원격 조작, 시스템 식별, sim-to-real 배포를 PyTorch로 할 수 있고 JAX 워크플로도 안내해요.

### 설치와 릴리스

- Linux(x86-64, AArch64), Windows(x86-64), macOS(universal)용 사전 빌드 바이너리가 권장 방식이에요. main 브랜치 최신 커밋은 불안정할 수 있어요.
- Python 바인딩은 MuJoCo 사본을 포함해 배포되고, Linux 휠은 manylinux2014를 대상으로 해요.
- 매달 첫 주 릴리스를 목표로 하고, 3.5.0부터 수정된 시맨틱 버저닝을 써요.

### 생태계와 라이선스

MuJoCo는 수많은 로보틱스·머신러닝 패키지의 기반이에요. 로봇 모델 모음, JavaScript·WebAssembly 바인딩, MATLAB Simulink 블록셋, OpenSim·SDFormat·Onshape CAD 변환기 등이 소개돼요. 소스 코드는 Apache 2.0, 문서·이미지·영상은 CC BY 4.0이고, 구글의 공식 지원 제품은 아니라고 밝혀요.
