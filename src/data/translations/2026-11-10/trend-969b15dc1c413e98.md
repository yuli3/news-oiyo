### 무엇을 했나요

작성자 /u/armbues는 Apple Silicon에서 의사결정 모델을 돌리고 학습하는 오픈소스 도구 **mlx-decision**에 이미지 LoRA 미세조정을 추가했어요. 큰 모델이 게임하는 건 봤지만, Mac에서 게임 화면으로 모델을 학습시킬 수 있을지 궁금했다고 해요.

### 어떻게 동작하나요

의사결정 모델은 글을 쓰지 않아요. 입력(여기선 게임 프레임)과 정해진 질문을 주면, 허용한 모든 답에 대한 확률을 한 번에 돌려줘요. d1-2B는 매 프레임 세 질문에 답해요.

- 지금 쏘면 조준선의 몬스터가 맞을까요? (예/아니오)
- 가장 가까운 몬스터는 왼쪽, 가운데, 오른쪽, 없음 중 어디인가요?
- 몬스터가 위험하게 가까운가요? (예/아니오)

작은 Python 루프가 답을 동작으로 바꿔요. 몬스터 쪽으로 돌고, 맞을 때 쏴요. 결정 한 번에 약 0.1초가 걸려요.

### 학습과 결과

- 데이터: ViZDoom "Defend the Center" 아레나 프레임 약 3,000장, 게임 엔진의 몬스터 위치로 라벨링
- 먼저 readout 맞춤 7분, 이어서 비전 타워는 고정하고 텍스트 층에 LoRA 43분(2 epoch, M5 Pro)
- 510장 검증: "쏘면 맞음" 정밀도 0.79→0.92, 가장 가까운 몬스터 위치 92.7%→96.8%, 위험 근접 93.9%→98.3%
- 실제 플레이: 20판 평균 23.2킬. 영상은 총알 26발로 26킬을 한 판이에요. 몬스터 그림을 학습에서 본 적 없는 Freedoom에서도 19.7킬

작성자는 돌기만 할 수 있는 아레나일 뿐 전체 Doom 레벨은 아니라고 선을 그어요. MIT 라이선스, macOS 14 이상, Python 3.12 이상이며 `pip install mlx-decision`으로 설치해요.
