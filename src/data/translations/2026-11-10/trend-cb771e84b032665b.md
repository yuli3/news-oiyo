### 무엇인가요

TorchLens는 어떤 신경망이든 모든 연산을 **검사·시각화·개입**하게 해 주는 도구예요.

- 모델 코드를 바꾸지 않고 모든 활성값과 그래디언트, 전체 계산 그래프, 800개 이상의 메타데이터 필드를 잡아요.
- PyTorch, JAX, TensorFlow, MLX, PaddlePaddle, tinygrad를 지원해요.
- 6,400개 이상 모델에서 검증했고, 연구자와 그들의 AI 에이전트를 위해 만들었다고 해요.

### README 예제

Hugging Face의 ViT 이미지 분류 모델에 고양이 사진을 넣고 `tl.trace`로 추적해요. 5번째 층 어텐션 패턴의 모양을 바로 꺼내 볼 수 있고, `draw`로 그래프를 그려요. 이어서 5번째 층 어텐션의 3번 헤드를 0으로 지우는(zero ablate) 개입을 하면 예측이 바뀌어요.

- 1위 Egyptian cat 0.489
- 2위 tabby cat 0.341
- 3위 tiger cat 0.147

헤드 하나를 지우자 "tabby"가 "Egyptian cat"으로 바뀌었다는 예시예요.

### 왜 만들었나요

작성자는 신경망 내부 계산을 이해하고 통제하는 일, 즉 **기계적 해석 가능성(mechanistic interpretability)**을 이 시대의 가장 중요한 과학 과제라고 봐요. 일부는 깊고 열린 문제라 AI 에이전트의 도움도 필요하겠지만, 다른 일부는 활성값과 그래디언트를 꺼내고 고치는 것처럼 지루해도 끝이 있는 "배관 작업"이라고 해요. 예를 들어 PyTorch에는 임의 네트워크에서 모든 중간 활성값을 꺼내는 기본 방법이 오래 없었다고 지적하며, TorchLens가 이 배관을 맡는다고 설명해요.
