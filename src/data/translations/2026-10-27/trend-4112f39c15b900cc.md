### 설계

많은 게임이 똑같이 짜는 인프라·라이브옵스·스토어 정책·메타 시스템은 **core**로 미리 두고, 에이전트는 **게임플레이(콘텐츠 코드)**만 쓰게 해요.

1. 사람이 `create game: <이름>` 같은 명령을 줌
2. 받은 세션이 **리드 에이전트**가 되어 역할별 서브에이전트를 부름
3. 편집 → 플레이 → 판정 루프를 돌리다가 멈추고 보고

이 저장소는 에이전트가 따르는 규칙, 스킬·코어 모듈 스펙, 설정, 판단이 필요 없는 일을 하는 CLI `ogw`를 담은 **하네스**예요. Claude Code나 Codex 세션을 이 폴더에서 열어 써요.

### 상태와 요구 사항

- 활발히 개발 중. 지금까지는 **macOS**, Claude Code의 Claude Opus 5.5(high)로만 시험했고 플레이·번역 서브에이전트는 Sonnet 5.5(medium)래요. Codex는 설정만 되고 미시험.
- **빌드 명령은 아직 실행하지 않아** 이 하네스로 빌드·배포된 게임은 없대요.
- 필요: Apple Silicon macOS, Node.js 24+, Git, gh, Docker+buildx, uv, Claude Code 로그인

### 예시 게임

iso-survivors(아이소메트릭 호드), mana-clash(1:1 카드), pong, block-stack 등이 소개돼 있어요. 판정은 재미는 플레이하는 판정 에이전트, 완성도는 자동 검사가 맡고, 증거 순위는 자동 검사 > 텔레메트리 > LLM 의견이래요.
