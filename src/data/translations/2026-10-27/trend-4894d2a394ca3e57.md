OpenAI가 **GPT-6.1 Terra**를 공개했어요. 시각적 추론과 정확한 **컴퓨터 사용(computer use)**, 더 자연스러운 글쓰기를 묶은 **빠르고 효율적인 모델**이에요. 제안서 작성, 기술 도면 해석, 양식 채우기, 영상 편집처럼 업무 시간을 채우는 일을 겨냥했대요.

### 가격과 효율

- 표준 API 가격이 **GPT-5.6 Terra와 GPT-6.1 Sol보다 50% 낮아요.**
- 입력 **100만 토큰당 1달러**, 캐시 입력 **0.05달러**, 출력 **5달러**예요.
- 들어오는 송장을 읽어 회계 소프트웨어에 입력하는 식의 대량 자동화에 맞는대요.
- ChatGPT Work와 Codex에서는 같은 사용량으로 GPT-5.6 Terra보다 더 많은 일을, GPT-6.1 Sol이나 GPT-6 Astra보다는 훨씬 더 많은 일을 할 수 있대요.

### 컴퓨터 사용 성능

| 벤치마크 | 결과(OpenAI 발표) |
|---|---|
| Agents' Last Exam (중간 추론) | GPT-5.6 Terra보다 15%p 높고 비용은 약 3분의 1. GPT-6 Astra와 비슷한데 토큰당 가격은 10분의 1 |
| Agents' Last Exam (최대 추론) | Claude Opus 5.5보다 토큰 효율 3배 이상, 토큰당 가격 4분의 1 → 작업당 비용 약 9배 낮음 |
| 속도 | GPT-6 Astra, GPT-6.1 Sol보다 작업을 3배 넘게 빨리 끝냄 |
| MMMU-Pro | 모든 추론 설정에서 GPT-5.6 Terra보다 높고, GPT-6 Astra·GPT-6.1 Sol에 거의 근접 |
| OSWorld 2.1 (중간 추론) | GPT-5.6 Terra의 최고 점수를 훨씬 낮은 비용으로 넘김 |

Agents' Last Exam은 건축 도면을 3D 모델로 바꾸거나, 애니메이션 영화를 장면별로 검토해 복원팀용 타임코드 기록을 만드는 식의 전문 업무 벤치마크래요.

### 사실성과 코딩

- 오류를 유도하는 내부 프롬프트 벤치마크에서 낮은 추론 강도의 오류율이 **53.6% → 16.7%**로 37%p 가까이 줄었어요. 최대 강도에서는 18%p 줄어 **4.3%**로, GPT-6 Astra·GPT-6.1 Sol과 거의 같대요.
- **Terminal-Bench 4.0**(최대 추론)에서 **50.3%**를 풀어, GPT-5.6 Terra 공개 점수 21.5%의 두 배가 넘어요.
- **Terminal-Bench-Science 0.1**에서는 GPT-6.1 Sol을 더 낮은 비용으로 넘고, Opus 5.5와 5점 이내래요(추정 비용은 5분의 1 미만).
- 다만 가장 복잡한 코딩 작업에는 **GPT-6.1 Sol과 GPT-6 Astra가 여전히 낫다**고 OpenAI가 직접 밝혔어요.

### 안전

- Preparedness Framework에서 사이버보안 **Critical 기준**에 해당하고, GPT-6 Astra용 보호 장치를 그대로 유지해요.
- GPT-5.6 Terra보다 작업 범위를 지키고 한계나 막힌 점을 솔직히 알리는 경향이 커졌고, 프롬프트 인젝션에도 강하대요. 자세한 내용은 시스템 카드에 있어요.

### 이용 방법

오늘부터 ChatGPT Work와 Codex의 Plus, Pro, Enterprise, Edu 사용자 모두 쓸 수 있어요. API 모델 이름은 `gpt-6.1-terra`예요.
