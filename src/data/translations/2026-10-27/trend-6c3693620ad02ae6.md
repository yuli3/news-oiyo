소프트웨어가 AI로 빨리 만들어질수록, 변경을 조사해 취약점을 다루면서도 **사람이 통제권**을 갖는 도구가 필요하대요. CodeRabbit은 **GPT-6.1 Sol**을 보안 에이전트의 주 모델로 써서, 개별 diff를 넘어 복잡한 코드베이스 전체의 위험을 이해하게 돕는다고 해요.

### 어떻게 쓰나

- **PR 리뷰**: 개발 중에 변경을 분석. 공유 라이브러리·의존성·다른 곳의 안전장치에 미치는 영향을 Sol이 이어서 봐요.
- **Deep Scan**: 저장소 더 넓게, 의존성과 컴포넌트 상호작용까지 조사.
- **CodeRabbit Secure**: 공유 인증 라이브러리처럼 **연결된 저장소**로 조사를 확장.
- 리뷰는 코드를 짠 에이전트와 **독립**이고, 기존 스캐너를 보완해요. 다른 프런티어 모델과 보안 도구도 함께 쓴대요.

### 수정까지

사용자가 고른 발견에 대해 **격리 샌드박스에서 익스플로잇 검증**을 시도하고(프로덕션은 건드리지 않음), 지원되는 이슈는 **수정 PR 초안**을 만들어 사람이 검토·승인하게 한대요. 수천 개 저장소·조직에서 보안 관련 이슈를 표시해 기존 PR 워크플로에 넣는다고 보고했어요.

### 수집 메모

이 항목의 피드 요약은 이래요. CodeRabbit uses GPT-6.1 Sol to investigate security risks across complex codebases. Its security agent helps developers review findings and proposed fixes.
