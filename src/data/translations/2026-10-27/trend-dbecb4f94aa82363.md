기존 멀티에이전트는 중앙이 일을 나눠 모으지만, 수가 늘면 중앙이 병목이 된대요. **Agensh(에이전시)**는 각 에이전트가 공통 목표·동료 진행을 보고 **직접 작업을 고르고**, 겹치면 메시지로 조율한 뒤 검증·공통 저장소 병합을 반복해요.

공유 저장소, 메시지, 사실·실패 기록 보드가 있고, 개별 모델 호출은 기존 하네스(실험은 GitHub Copilot CLI)가 담당해요. 논문은 9월, 코드는 10월 24일 공개.

### ProgramBench 결과 (GPT-5.6 Sol)

- 에이전트 1개 평균 최종 통과율 **19.31%** → 128개 **28.78%**(약 +49% 상대)
- pandoc 재현: 1개 **33.89%** → 1,024개 **55.06%**
- 128개는 30분 시점에 통과율 30%를 넘겼고, 단일은 초기 2시간 동안 그 기준에 못 미쳤대요.

규모가 커지자 코드 검토·통합을 맡는 역할이 **자발적으로** 나타났다고 해요. 인터넷 차단·6시간 제한 실험이에요.

### 수집 메모

이 항목의 피드 요약은 이래요. 마이크로소프트(MS)가 중앙 관리자 없이 AI 코딩 에이전트 1024개가 협업하는 시스템을 오픈소스로 공개했다. 에이전트들이 스스로 작업을 고르고 결과를 공유하는 방식으로, 규모가 커지자 코드 검토와 통합을 맡는 역할도 자발적으로 나타났다.MS는 24일(현지시간) 깃허브를 통해 멀티 에이전트 하네스 ‘에이전시(Agensh)’의 코드와 실험 재현 도구를 공개했다. 하네스는 AI 에이전트가 도구를 사용하고 작업을 이어가도록 지원…
