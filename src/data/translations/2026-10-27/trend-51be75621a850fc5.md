**Code Understanding Coach**는 현재 코드베이스를 얼마나 이해하는지 점검하는 **에이전트 스킬**이에요.

- "이 프로젝트 이해도 점검해줘" → 주요 기능·구조·데이터 흐름을 영역별로
- "로그인 흐름 퀴즈 내줘" → 그 기능과 맞닿은 진입점·호출·상태·저장·오류 처리에 초점
- **한 번에 질문 하나**를 하고 답을 기다린 뒤, 맞은 점과 놓친 점을 **실제 코드 줄**로 보여 줘요.
- 질문은 함수 이름 암기가 아니라 **구체적 상황에서 동작을 예측하고 이유를 설명**하게 해요. 코드를 보면서 답해도 돼요(오픈북).
- 채점: understood / partial / misconception / undetermined. 숫자 점수는 없어요.
- 틀리거나 "모르겠다"면 같은 생각을 **다른 상황**으로 다시 물어요. 설명을 되풀이하는 것만으로는 통과가 아니에요.
- 세 문제마다 계속할지 묻고, "stop"이면 다룬 것·안 다룬 것·다시 볼 것 요약을 줘요.
- **코드를 읽기만** 해요. 파일 수정, 실행, Git 명령, 저장은 하지 않아요.

### 설치

Vercel Labs의 오픈소스 `skills` CLI로 설치해요.

```bash
npx skills add WooHey-P/code-understanding-coach
npx skills add WooHey-P/code-understanding-coach -a claude-code codex -y
```

Claude Code는 `.claude/skills/`, Codex는 `.agents/skills/`에 들어가요. 한국어 README도 있어요.
