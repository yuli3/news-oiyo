AI가 코드를 쏟아내는 속도에 사람 리뷰·반영이 못 따라간다는 판단이에요. GitHub Universe 26(28~29일 SF) 직전에 맞불 출시 성격이에요.

### Trails

풀 리퀘스트를 대체해, 코드가 올 때마다 여러 AI 에이전트가 사전 기준으로 **점수**를 매기고 문제를 반복 수정해요. 기준을 다 충족하면 개발자가 전체를 안 읽고도 병합할 수 있게 설계했대요.

### 저장소·메모리·CI

- GitHub 호환 분산 SCM: 전송 속도 GitHub 대비 최대 **89배**, Cursor Origin 대비 **6배** 주장
- 미·EU·인도·호주 등에 비공개 저장소
- **Continuous Memory**: 지시·작업 기록을 저장소에 보관. Codebase Graph(토큰 최대 **71%** 절감 주장), Agentic Brain(같은 실수 반복 방지)
- Buildkite·Depot CI 연결, GitHub Actions에서 이전 가능

시드 **6,000만 달러**, 직원 약 50명(GitHub·MS 출신 포함)래요.
