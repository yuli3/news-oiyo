### 무엇인가

**미르코드(Mirr Code)**는 터미널에서 쓰는 **TUI 기반 AI 코딩 에이전트**예요. 프로젝트 코드를 탐색하고 파일을 고치는 실제 개발 작업을 맡기도록 만들고 있대요.

가장 큰 차이는 Claude나 GPT 같은 **외부 모델을 골라 연결하는 방식이 아니라**, **자체 모델과 자체 인프라**로 동작한다는 점이에요.

- 지금은 자체 모델 **Mirr 1.0 Pro** 중심으로 제공해요.
- 더 가벼운 **Mirr 1.0 Flash**를 준비 중이에요.

### 왜 한국어와 사용량인가

제작자가 여러 코딩 에이전트를 쓰며 크게 느낀 건 **한국어**와 **사용량**이었대요.

- 개발 중에는 정리된 프롬프트보다 "여기 좀 이상한데 봐줘", "아까 방식 말고 다른 방법으로 해봐" 같은 요청이 훨씬 많아서, 한국어로 자연스럽게 작업을 이어가는 게 중요하대요.
- 코딩 에이전트는 결과를 보고 고치고 다시 시도하는 과정에서 많이 쓰이니, 사용량을 지나치게 신경 쓰지 않게 설계했대요. 사이트도 "토큰 걱정 없이 마음껏 쓰세요"를 내세워요.

### 사이트에 소개된 기능

| 기능 | 설명 |
|---|---|
| 한국어 네이티브 | 화면 문구, 에러 메시지, 메뉴, 설정까지 한국어 |
| 초성 검색 | `/ㅂㄹㅊㅈㅎ`처럼 초성만으로 슬래시 명령 실행 |
| Yolo 모드 | 매번 묻지 않고 끝까지 작업 (Ctrl+Y, 맥은 ⌘Y) |
| 권한 승인·체크포인트 | 바뀐 부분(diff)을 보여 주고 사람이 승인해야 실행 |
| `/압축` | 긴 세션의 맥락을 유지하며 토큰을 줄임 (예시: 187k → 24k) |
| `/스킬` | 설치된 스킬 목록 확인, 마켓플레이스에서 추가 설치 |
| `/mcp` | 이슈 트래커, DB, 내부 API를 MCP 서버로 연결 |

사이트 예시로는 엑셀 자동화, UX/UI 수정, 문서 개선, **HWPX 보고서**, 한글 파일명 깨짐(NFC·NFD 정규화) 수정 같은 작업을 들었어요. CLI/TUI 외에 Headless, Desktop, ACP, Serve 형태도 있다고 적혀 있어요.

### 받고 싶은 피드백

실제 프로젝트에 맡겼을 때의 결과, 한국어 요청 이해도, 자체 모델의 코딩 품질, TUI 사용성, 반복 작업이나 긴 세션에서의 안정성이에요. 잘 안 되는 작업이나 불편한 점도 알려 달래요.

### 참고

자체 모델의 크기, 학습 방식, 벤치마크 수치는 글과 사이트 첫 화면에 나오지 않아요. 사이트에는 런칭 한정 특가가 있다고만 적혀 있고 가격은 첫 화면에서 확인하지 못했어요.
