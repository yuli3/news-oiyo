OpenAI가 올린 고객 사례 글을 읽고 옮겼어요. 수집 상한(6,000자)에서 잘려 '팀이 주도권을 유지하는 법' 이후 마지막 부분은 읽지 못했어요. 수치는 Amplitude 측 평가예요.

### Wave란

Amplitude는 사람들이 제품을 실제로 어떻게 쓰는지 보여 주는 분석 회사예요. **Wave**는 그 인사이트를 출시된 개선으로 바꾸는 '능동형 제품 에이전트'예요. 팀이 제품 영역과 개선할 목표·지표를 주면 Amplitude 데이터, 세션 리플레이, 고객 피드백, 코드를 모아 기회를 찾고 우선순위를 매겨 해법을 만들고, 사람과 코딩 에이전트에게 구현을 맡긴 뒤 결과를 추적해요.

Amplitude는 Wave가 **약 80% OpenAI 모델**로 돌아간다고 설명해요.

- GPT-6.1 Sol: 기회 관리와 코드·데이터 심층 조사
- GPT-6 Luna: 코드 스캔, 작은 평가 검사처럼 잦고 싼 작업
- GPT-Image-2.5 Flare: 세션 리플레이 스크린샷을 참고한 제품 목업 생성

구현할 준비가 되면 기술 계획과 인수 조건을 붙여 Codex 같은 코딩 에이전트에 바로 보내요. 개선 출시는 약 한 달에서 **1~2일**로 줄어든다고 추정해요.

### 홈 추천 카드 실험

Amplitude 홈에는 AI 에이전트와 대화를 시작하도록 돕는 일반 추천 카드가 있었는데, Wave가 세션 리플레이 100건을 보니 80명은 직접 질문을 입력하고 12명만 카드를 골랐대요. Wave는 최근 본 차트·대시보드나 이전 페이지로 카드를 개인화하자고 제안하고, 자유 입력 유지·맥락이 없을 때 일반 카드 표시까지 담은 기술 계획을 만들었어요. 팀이 짧게 검토해 코딩 에이전트에 넘기고 A/B 테스트한 결과, 하루 만에 카드로 보낸 메시지가 대조군 대비 **160%** 늘었어요.

### 작업별 모델 선택

- 기회 조사(Opportunity Investigator) 평가: GPT-6.1 Sol 5점 만점에 4.06(대안 3.62, 3.52, 2.94), 다섯 기준 모두 1위, 중앙값 조사 시간 54분. 모델 비용은 1.34달러였어요.
- 데이터 과학 에이전트 평가: GPT-6.1 Sol 67.5점(다른 선도 모델 69.3점)이지만 호출당 평균 비용 1.28달러 대 2.63달러로 51% 낮았고, 도구 계약 준수·불확실성 추정·근거 연결은 더 높았어요.
- 와이어프레임 생성: OpenAI 이미지 모델 80.3점, 다른 모델 63.9점(15개 기회 대상)

CEO 스펜서 스케이츠는 "AI가 이제 우리가 맡길 생각도 못 한 유용한 일을 찾아낸다"고 말했어요.
