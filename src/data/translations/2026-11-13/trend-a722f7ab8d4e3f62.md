AI타임스 기사(박찬 기자)를 끝까지 읽고 정리했어요. 수치는 메타 연구진의 실험 결과예요.

### 무엇인가

메타 연구진이 6일(현지시간) arXiv에 **e-민즈(e-means)** 논문을 공개하고 코드를 오픈소스로 냈어요. 대규모 데이터를 비슷한 것끼리 묶는 **k-민즈**를 개선한 알고리즘이에요.

k-민즈는 비슷한 데이터를 여러 집단으로 묶고 각 집단의 평균을 중심점으로 삼는 방식이에요. 벡터 검색과 데이터 압축에 널리 쓰이지만, 데이터가 수십억 개가 되면 반복 계산에 시간과 자원이 많이 들어요.

### 어떻게 빨라졌나

- 매번 전체 데이터를 처리하지 않고 일부만 뽑아 계산하는 **미니배치** 방식에 **지수이동평균(EMA)**을 결합했어요. 최근 처리한 데이터에 더 큰 가중치를 주며 중심점을 갱신해요.
- 데이터 규모에 맞춰 처리 단위와 업데이트 폭을 자동 조정해 복잡한 설정을 줄였어요.

### 결과

- 기존 k-민즈가 25회 반복해야 도달하는 오차를 **1.4~2.6회** 만에 달성했어요.
- 실행 시간은 GPU에서 Flash-KMeans보다 **10~45배**, CPU에서 Faiss 기반 k-민즈보다 **8~15배** 빨랐어요. 데이터와 하드웨어에 따라 달라질 수 있어요.
- 100억 개 이미지 임베딩으로 된 DINO10B 데이터셋을 약 1,670만 개 군집으로 묶을 때, 2.5회 반복만으로 기존 k-민즈 25회보다 낮은 오차를 냈대요.

### 쓰는 곳

e-민즈는 메타의 오픈소스 벡터 검색 라이브러리 **FAISS 1.16.0**에 들어갔어요. 개발자는 대규모 벡터 인덱스 구축이나 임베딩 처리에 쓸 수 있어요. 기사는 이 연구가 검색·추천 시스템에서 데이터를 미리 군집화하는 비용을 줄이는 것이고, 실제 서비스 응답 속도가 같은 비율로 빨라진다는 뜻은 아니라고 짚어요.
