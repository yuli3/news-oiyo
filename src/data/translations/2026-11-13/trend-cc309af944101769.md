### 무엇인가

**AgentRun**은 쓰던 에이전트 하네스 위에 자기 개선, 내구성 있는 실행(durable execution), 컨트롤 플레인을 더하는 오픈소스 플랫폼이에요(Apache-2.0). 지원 하네스는 Claude Code, Codex, OpenCode, pi예요.

### 문제의식

에이전트는 문제를 잘 풀지만 같은 걸 매번 다시 풀어요. 백 번 한 일을 시켜도 같은 API를 다시 찾고 같은 문서를 다시 읽고 같은 계획을 다시 세우며, 그 토큰 비용을 매번 낸다는 거예요.

### 사례(README 주장)

- **코드 리뷰**: Greptile이 3월부터 리뷰당 1달러를 받으면서 월 청구가 180달러에서 6,451달러로 늘었대요. 그래서 싼 모델로 자체 리뷰어를 만들어 자기 PR로 튜닝했고, 리뷰당 18센트에 처음 보는 PR 30개에서 Greptile보다 실제 버그를 1.6배 더 잡았다고 해요.
- **가맹점 코드 분류**: Opus가 분류 방법을 익히게 한 뒤 그 지식을 싼 모델에 넘겨, 가맹점당 비용이 0.89달러에서 0.12달러로 줄었다고 해요.

### 주요 기능

- **작업을 배워요**: 에이전트 정의에 `"learning": true`를 켜면, 실행 끝에 한 턴을 더 받아 남길 것을 제안해요. AgentRun이 코드로 검사하고 채점기 하나가 평가한 뒤 통과한 것만 에이전트 전용 git 폴더에 커밋해요. 메모는 사실 하나당 짧은 markdown 파일(Claude Code 메모리 형식)이고, 스킬은 작업을 끝낸 실행만 쓸 수 있어요. 스킬이 3번 쓰이면 다음 실행에 워크플로 초안을 요청하고, 초안은 모델·도구 호출 없이 드라이런으로 검증한 뒤 보관해요.
- **실행을 잃지 않아요**: 모든 실행이 한 저장소에 있어 서버를 중간에 꺼도 다시 켜면 이어 가요. 샌드박스, 리눅스 데스크톱, 안드로이드 폰, 브라우저 중 필요한 환경을 줄 수 있어요.
- **통제권**: 승인, 비용 상한, 모든 에이전트를 보는 Mission Control 콘솔(필요한 조치, 실패, 실행 중, 비용). 워크플로 단계가 확신도를 보고 경로를 정해요(예: 승인 0.61이 기준 0.75보다 낮아 검토로 보냄). 모든 에이전트는 API로도 호출돼요.

### 시작하기

Node 24.22.3 이상, macOS·Linux에서 `npx @parcha/agentrun`으로 서버와 러너를 띄우고(포트 7340), 콘솔에서 모델 키 하나(OpenRouter, Anthropic, OpenAI 중)를 넣으면 돼요. Docker가 있으면 셸이 있는 샌드박스를 쓰고, 없으면 파일 읽기·쓰기만 돼요.
