허깅페이스 모델 페이지가 채팅 템플릿만 돌려줘서, 같은 저장소의 README 원문을 따로 받아 읽었어요. 품질 비교는 이미지 차트라 수치를 읽지 못했어요. 성능 수치는 모두 제작사 측정이에요.

### 한 줄 소개

"소비자용 GPU 한 장에서 도는 145B 에이전트 모델"이라는 게 제작사 설명이에요. 48레이어, 레이어당 전문가 512개 중 10개(+공유 전문가 1개)가 토큰마다 활성화되는 잠재 희소 MoE이고, 256K 컨텍스트를 지원하며 처음부터 4비트로 학습했다고 해요. 기반 모델은 Qwen3.8-Flash-Next예요.

### 속도(제작사 측정, tok/s)

- RTX 5090 D 24GB, Q3_K: 4K 프리필 2,169.9 / 16K 프리필 3,554.9 / 채팅 디코드 99.7 / 에이전트 디코드 121.2
- RTX 4090 24GB, Q3_K: 16K 프리필 3,179.4 / 에이전트 디코드 91.7
- Apple M2 Ultra(Metal), Q3_K: 16K 프리필 800.3 / 에이전트 디코드 57.0
- 같은 5090 D를 VRAM 16GiB + 시스템 RAM 20GiB로 제한했을 때: 16K 프리필 335 / 에이전트 디코드 44.9

16GiB+20GiB는 시험 조건이지 최소 사양이 아니라고 밝혀요. 상주 기능을 켜면 Q3_K 가중치(40.81GiB)를 VRAM 23.14GiB + RAM 31.28GiB로 나눠 담아요. Terminal-Bench 2.1 점수는 86.5라고 적혀 있어요.

### 구조

- 총 145B, 토큰당 활성 10.12B
- 4레이어마다 전체 어텐션을 쓰는 하이브리드 어텐션 + 희소 인덱서
- 전문가 풀 84.6B(잠재 폭 1,792), fp8 n-gram 임베딩 테이블 51.2B(메모리 매핑), 추측 디코딩용 1.26B MTP 헤드
- 토큰을 잠재 폭으로 투영한 뒤 512개 중 10개 전문가를 고르고 다시 원래 폭(2,560)으로 되돌려요. 전문가 하나가 고정 크기 레코드라, GPU에 수천 개만 두고 나머지는 호스트 메모리에서 스트리밍해요.

### 실행과 라이선스

전용 엔진 `edge0-infer`(Strata 엔진 확장)를 빌드해 `serve`로 띄우면 OpenAI·Anthropic 호환 엔드포인트가 열리고, 윈도우 데스크톱 앱도 있어요. 빌드 안내는 CUDA 13 기반 NVIDIA GPU 대상이에요. 개인·연구·비상업 공유·내부 사용과 생성물의 상업적 이용은 허용하지만, 모델 판매·상업 모델 서비스·독립 상업 코딩 비서 제공에는 별도 서면 라이선스가 필요하고 Qwen 라이선스 조건도 함께 따라야 해요.
