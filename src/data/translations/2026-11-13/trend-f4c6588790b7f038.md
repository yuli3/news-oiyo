### 무엇인가

**Supabase**는 스스로를 "Postgres 개발 플랫폼"이라고 소개해요. 엔터프라이즈급 오픈소스 도구로 Firebase의 기능을 만들고 있대요. Firebase를 1:1로 옮긴 건 아니고, 오픈소스 도구로 Firebase 같은 개발 경험을 주는 게 목표예요.

### 제공 기능

- 호스팅 Postgres 데이터베이스
- 인증과 권한 관리
- 자동 생성 API: REST, GraphQL, 실시간 구독
- 함수: 데이터베이스 함수, 엣지 함수
- 파일 저장소
- AI + 벡터/임베딩 툴킷
- 대시보드

### 구성 방식

MIT, Apache 2 같은 개방 라이선스 도구와 커뮤니티가 있으면 그걸 쓰고 지원하며, 없으면 직접 만들어 오픈소스로 낸다는 원칙이에요. 호스팅 플랫폼이라 설치 없이 가입해 쓸 수 있고, 셀프 호스팅과 로컬 개발도 돼요.

- **Postgres**: 30년 넘게 개발된 객체 관계형 데이터베이스
- **Realtime**: Postgres 복제 기능을 폴링해 insert·update·delete를 JSON으로 바꿔 웹소켓으로 권한 있는 클라이언트에 보내는 Elixir 서버
- **PostgREST**: Postgres를 바로 RESTful API로 바꾸는 웹 서버
- **GoTrue**: JWT 기반 인증 API
- **Storage**: S3 파일을 관리하는 REST API, 권한은 Postgres가 처리
- **pg_graphql**: GraphQL API를 노출하는 Postgres 확장
- **postgres-meta**: 테이블 조회, 역할 추가, 쿼리 실행 등 Postgres 관리 API
- **Envoy**: 엣지·서비스 프록시

### 클라이언트 라이브러리

기능별로 독립 구현을 두는 모듈식 접근이에요. 공식 지원은 JavaScript(TypeScript), Flutter, Swift, Python이고, 커뮤니티가 C#, Go, Java, Kotlin, Ruby, Rust, Godot(GDScript) 라이브러리를 만들고 있어요.
