### 무엇인가

**Transformers**는 텍스트, 컴퓨터 비전, 오디오, 영상, 멀티모달 최신 머신러닝 모델을 **추론과 학습** 모두에 쓰기 위한 '모델 정의 프레임워크'예요.

- 모델 정의를 한곳에 모아 생태계 전체가 같은 정의를 쓰게 하는 게 목표예요.
- 여기서 모델 정의가 지원되면 대부분의 학습 프레임워크(Axolotl, Unsloth, DeepSpeed, FSDP, PyTorch-Lightning 등), 추론 엔진(vLLM, SGLang, TGI 등), 인접 라이브러리(llama.cpp, mlx 등)와 호환된대요.
- 새 최신 모델 지원을 돕고, 정의를 단순하고 수정 가능하며 효율적으로 만들어 사용을 대중화하겠다고 해요.
- Hugging Face Hub에는 **100만 개 넘는** Transformers 모델 체크포인트가 있어요.

### 설치

- Python **3.11+**, PyTorch **2.6+**에서 돌아가요.
- venv나 uv(Rust로 만든 빠른 Python 패키지 관리자)로 가상환경을 만들고 `pip install "transformers[torch]"` 또는 `uv pip install "transformers[torch]"`로 설치해요.
- 최신 변경을 쓰거나 기여하려면 소스에서 설치할 수 있지만, 최신 버전은 불안정할 수 있대요.

### 빠른 시작

- **Pipeline API**는 텍스트, 오디오, 비전, 멀티모달 작업을 지원하는 고수준 추론 클래스예요. 입력 전처리를 해 주고 알맞은 출력을 돌려줘요.
- 예시는 `task="text-generation"`에 Qwen2.5-1.5B 모델을 지정해 문장을 이어 쓰게 해요. 모델은 내려받아 캐시돼 다시 쓸 수 있어요.
- 채팅도 같은 패턴이고, 시스템·사용자 메시지로 된 대화 기록을 입력으로 넘기면 돼요.
- `transformers serve`가 실행 중이면 `transformers chat` 명령으로 터미널에서 바로 모델과 대화할 수도 있어요.
