### CrowdGPT란

작성자는 일주일 전 글에 이어 **CrowdGPT v2(정확히는 v2.6)**를 발표했어요. CrowdGPT는 데이터센터와 AI 기업이 쓰는 수백만 달러 없이 LLM을 만들려는 프로젝트예요. 개념 증명으로 **10억 파라미터 모델**을 공개적으로 함께 학습하는 게 목표이고, 더 큰 밀집 모델이나 MoE로도 확장할 수 있다고 해요.

누구나 자기 PC로 독립적으로 학습한 뒤 기여분을 전체 모델에 더하고, 프로젝트 방향에 모두가 의견을 낼 수 있는 프로토콜을 구현했어요. 웹사이트는 crowdgpt.net, 코드는 GitHub `Vxtzq/CrowdGPT`예요. 작성자는 데이터 오염 실험으로 한계를 찔러 봐도 좋다며 피드백을 환영했어요.

### v2.6에서 바뀐 것

주로 지난 글 댓글의 보안 지적을 반영했고, 그 과정에서 호환성이 깨지는 변경이 많아 일부 학습 기여가 무효가 됐대요.

- 이전엔 클라이언트 자동 업데이트가 **임의 코드 실행**을 허용해, 작성자의 GitHub 자격 증명을 훔치면 사용자 기기에서 악성 코드를 돌릴 수 있었어요. 이제 클라이언트 코드는 작성자 기기에만 있는 키로 **서명**돼요.
- 이전 구조에선 기여를 위조하거나, 모델에 독을 넣거나, 매 밀리초 가짜 기여로 서버를 죽이거나, 백도어를 학습시키기 쉬웠어요.
- 그래서 **같은 데이터를 세 클라이언트가 학습**하는 중복을 감수하고 클라이언트 간 **비잔틴 교차 검사**를 넣었어요. 완벽한 연합 학습은 아니지만, 악의적 클라이언트가 차단되지 않고 넣을 수 있는 악성 데이터가 라운드당 100%에서 **2~3%**로 줄었대요.

### CrowdBench

누구나 정답이 정해진 일반 지능 문제를 추가해 LLM을 시험하는 오픈소스 공동 벤치마크 **CrowdBench**도 공개했어요. 아직 초기 단계지만 동작하고, AI를 쓰지 않고 직접 코딩했다고 해요.
