GitHub README 전체를 읽고 옮겼어요.

### 무엇인가

**KernelSU**는 안드로이드 기기를 위한 **커널 기반 루트 솔루션**이에요. README는 15개 언어로 제공되고 한국어판도 있어요.

### 기능

- **커널 기반 su와 루트 접근 관리**
- **메타모듈 기반 모듈 시스템**: 시스템 파티션을 직접 건드리지 않는(systemless) 수정을 위한 플러그인형 인프라예요.
- **App Profile**: 루트 권한을 "우리에 가두듯" 앱별로 제한해요.

### 호환성

- 공식 지원은 **Android GKI 2.0 기기(커널 5.10 이상)**예요. 이전 커널(4.14 이상)도 지원하지만 커널을 직접 빌드해야 해요.
- 이 덕분에 WSA, ChromeOS, 컨테이너 기반 안드로이드도 지원돼요.
- 아키텍처는 arm64-v8a와 x86_64예요.

> **주의**: 최근 커널 버전에 호환성을 깨는 변경이 들어가 KernelSU가 실패하고 **x86_64에서 커널 패닉**이 날 수 있어요. 자세한 내용은 공식 웹사이트(kernelsu.org)를 보라고 해요.

### 번역 정책

이제 Weblate로 번역 기여를 받지 않고 **모든 번역을 LLM으로 처리**해요. 새 언어 추가 PR은 환영하지만, 기존 영어·중국어 번역 수정은 받지 않아요.

### 라이선스와 크레딧

- `kernel` 디렉터리는 **GPL-2.0-only**, 나머지는 **GPL-3.0-or-later**예요.
- 크레딧: 아이디어를 준 Kernel-Assisted Superuser, 루트 도구 Magisk, APK v2 서명 검증의 genuine, 일부 루트킷 기법의 Diamorphine.
