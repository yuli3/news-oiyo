GitHub README를 "How it works" 절 중간까지 읽고 옮겼어요. 뒷부분은 읽지 못했어요.

### 무엇인가

여러 Claude Code와 Codex 계정의 사용 한도를 **활동 링**으로 보여 주는 macOS 바탕화면 위젯이에요. 터미널을 열지 않고 바탕화면만 보고 어느 계정에 여유가 있는지 알 수 있어요. 한국어, 영어, 일본어를 지원해요.

### 기능

- **계정마다 게이지 하나, 링 세 개**: Claude Code는 바깥이 5시간 한도, 가운데가 주간 한도, 안쪽이 주간 Fable 한도예요. Codex는 5시간과 7일 링이 있어요.
- 위젯 크기: 소(계정 1개), 중(3개), 대(3개 + 숫자).
- 임계값(기본 90%)을 넘으면 링이 빨개지고, 토큰 만료나 요청 실패는 회색 점선 게이지로 보여 줘요.
- `~/.claude-*`, `~/.codex-*` 설정 폴더를 **자동으로 찾아요.**
- 설정에서 계정별 인증 환경(폴더)을 만들 수 있고, 변경 미리보기와 설정 전 백업을 해 줘요.
- **Antigravity**의 `agy` CLI 계정도 세 번째 제공자로 보여 줘요(Gemini, Claude/GPT 주간·5시간 풀).
- 앱 안에서 Claude 계정마다 한 번 로그인하면 자체 OAuth 세션을 유지하고 Claude Code의 자격 증명은 건드리지 않아요. Codex 토큰은 Codex CLI 방식으로 갱신해요.
- 한도 임계값 초과, Codex 워크스페이스 크레딧 소진, 토큰 갱신 실패 때 알림을 보내요.

### 설치와 사용

Homebrew로 `brew install --cask typostudio/tap/ai-usage` 하거나 릴리스의 DMG를 써요. 공증(notarize)되지 않은 앱이라 Gatekeeper가 막으면 격리 속성을 한 번 지워야 해요. 앱을 한 번 실행하면 계정을 찾아 **2분마다** 갱신하고, 바탕화면 위젯 편집에서 위젯을 추가해요. 위젯은 앱이 쓴 값만 보여 주므로 앱이 켜져 있어야 해요.

### CLI와 MCP

앱에 `aiusage` 명령이 들어 있어 앱 없이도 같은 값을 JSON으로 읽을 수 있어요. `aiusage claude`처럼 제공자를 고르거나, `aiusage mcp`로 stdio MCP 서버(도구 `get_usage`)를 띄워 에이전트가 사용량을 읽게 할 수 있어요. 토큰 갱신은 파일 잠금으로 앱과 공유해 동시에 돌려도 안전하다고 해요.

### 동작 방식

각 계정의 자격 증명을 로컬에서 읽어 CLI가 쓰는 것과 같은 사용량 엔드포인트(Claude Code는 `api.anthropic.com/api/oauth/usage`, Codex는 `chatgpt.com/backend-api/wham/usage`)를 불러요. Claude 자격 증명은 `/usr/bin/security`로 키체인에서 읽어요. 결과는 App Group 컨테이너의 스냅숏 파일에 쓰고, 샌드박스 위젯은 그 파일만 읽어요. README는 토큰이 스냅숏에 쓰이지 않고 Mac 밖으로 나가지 않는다고 설명해요.
