### 무엇인가

**Apache Arrow**는 "인메모리 분석을 움직이는" 프로젝트예요. 빠른 데이터 교환과 인메모리 분석을 위한 **범용 컬럼형 포맷**이자 **다언어 도구 모음**이고, 데이터 시스템이 데이터를 효율적으로 저장, 처리, 이동하게 해 주는 기술들을 담고 있어요. Apache Software Foundation 프로젝트예요.

### 주요 구성 요소

- **Arrow Columnar Format**: 단순하거나 중첩된 여러 자료형의 표준적이고 효율적인 인메모리 표현이에요.
- **Arrow IPC Format**: 프로세스 사이, 이기종 환경 사이 통신을 위한 효율적인 직렬화예요.
- **ADBC(Arrow Database Connectivity)**: 데이터베이스와 쿼리 엔진에 접근하는 Arrow 기반 API·드라이버·라이브러리예요.
- **Arrow Flight RPC**: IPC 포맷 기반으로, 스토리지 서버나 DB처럼 Arrow 데이터를 주고받는 원격 서비스의 빌딩 블록이에요.
- **Gandiva**: LLVM 기반 Arrow 표현식 컴파일러(C++ 코드베이스 일부)예요.
- 언어별 라이브러리: C++, GLib 기반 C 바인딩, .NET, Go, Java, JavaScript, Julia, Python, R, Ruby, Rust, Swift. 일부는 별도 저장소에서 관리돼요.

### 라이브러리에 들어 있는 것

- 평면·중첩 타입을 지원하는 컬럼 벡터와 데이터프레임 비슷한 테이블 컨테이너
- Google FlatBuffers를 쓰는 언어 독립 메타데이터 메시징 계층
- 제로카피 메모리 공유와 메모리 맵 파일을 위한 참조 카운트 기반 오프힙 버퍼 관리
- 로컬·원격 파일 시스템 IO 인터페이스
- RPC와 IPC용 자기 기술형 바이너리 와이어 포맷(스트리밍, 배치/파일형)
- 구현 간 바이너리 호환성(예: Java → C++) 통합 테스트
- 다른 인메모리 자료구조와의 변환
- Parquet, CSV 등 널리 쓰는 파일 포맷 리더·라이터
