### Gamer란

**Gamer**는 복잡한 상호작용 환경에서 긴 호흡의 과제를 수행하도록 만든 범용 에이전트 프레임워크예요. 인식, 메모리 관리, 다단계 추론을 하나의 엔드투엔드 구조로 묶었고, 같은 학습·배포 파이프라인으로 일반 2D 그래픽 인터페이스와 복잡한 3D 시뮬레이션 세계를 모두 다뤄요.

### 학습 방법

1. **계속 사전학습**: 수만 시간 분량의 기기 수준 키보드·마우스 조작 데이터로 학습해요. 시뮬레이션 게임과 체화(embodied) 환경을 아우르기 때문에 물리·가상 영역의 환경 동역학을 함께 배워요.
2. **희소 사고(sparse-thinking) 인스트럭션 튜닝**: 복잡한 결정에 필요한 추론은 남기면서 불필요한 계산을 크게 줄여요.
3. **안정적인 다중 턴 강화학습**: 유한한 컨텍스트, 누적되는 롤아웃 오류, 희소한 보상 문제를 다뤄요.

### 실시간 추론

클라우드-엣지 추론 엔진이 수많은 시뮬레이션 게임 환경을 동시에 서빙하고, 컨텍스트 제한 없는 실행을 지원하며 온라인 지연을 낮게 유지해요.

### 결과와 의미

여러 어려운 3D 오픈월드 게임에서 숙련 플레이어에 견줄 일반화와 조작 효율을 보였고, 기존 2D 게임 벤치마크에서도 경쟁력 있는 결과를 냈다고 해요. 연구진은 반복적인 키보드·마우스 궤적만으로도 데이터와 학습 알고리즘을 키우면 큰 향상을 얻을 수 있고, 디지털과 물리 세계를 넘나드는 범용 에이전트로 가는 길이 될 수 있다고 봐요. 코드는 GitHub(RainBowLuoCS/Gamer), 모델은 Hugging Face(THUSI-Lab), 프로젝트 페이지는 mihoyo-gamer.github.io에 있어요.
