프로젝트 페이지(mihoyo-gamer.github.io)를 읽고 정리했어요. 인터랙티브 그래프 속 개별 점수는 페이지 텍스트에 나온 값만 옮겼어요.

### 사람처럼 게임하기

Gamer는 화면 관찰을 키보드·마우스 동작으로 바꾸는 시각-언어-행동(VLA) 모델이에요. 5Hz로 샘플링한 스크린샷과 과제, 관찰 이력, 메모리를 조건으로 키 상태, 마우스 이동, 스크롤을 출력해요. 데모에서는 **붕괴: 스타레일** 메인 스토리를 이동·상호작용·퀘스트 수행하며 진행하고, 다섯 종류 퍼즐도 같은 인터페이스로 풀어요.

### 3단계 학습

1. **CPT(계속 사전학습)**: 화면과 키보드·마우스 동작이 정렬된 1만 시간 이상의 게임 플레이로 전이 가능한 조작 기술을 배워요. 200ms마다 마우스 이동량과 33ms짜리 키 상태 블록 6개를 예측해 별도 action head 없이 30Hz 제어를 해요. 반복 키 상태에 감쇠 가중치를 주고, 궤적마다 키를 무작위로 재배치해 키 자체가 아니라 키의 기능을 배우게 해요.
2. **SFT(인스트럭션 튜닝)**: 조작·하위 목표·과제 3단계 감독을 더해요. 경로 변경, 목표 전환 같은 결정 지점에서만 추론하는 희소 추론과, 완료 목표·실패 시도·위치·남은 계획을 담는 메모리 요약을 써요. 약 1천 시간 정제 영상, 약 120만 개 Think 주석, 약 22만3천 개 메모리 주석이 들어갔어요.
3. **RL**: TA-GRPO(Temporal-Aware GRPO)가 가치 비평자나 보상 모델 없이 환경이 검증한 보상으로 메모리에 연결된 롤아웃 구간을 최적화해요.

### 결과

- 보지 않은 40개 과제, 7종 퍼즐에서 Gamer-RL 매크로 평균 성공률은 **49.7%**로 Gamer-SFT(39.2%)보다 10.5%p 높고, 가장 강한 범용 기준선 GPT-6.1-Sol은 17.1%였어요.
- **Streaming-vLLM**은 클라이언트별 KV 캐시 재사용, 전용 커널, 디코딩이 끝나기 전 동작 전송으로 H200·Qwen3.5-35B-A3B MoE에서 요청 지연을 **1,306ms → 65.12ms(20.1배)**로 줄였어요.
- MCU, ViZDoom, OmniGameArena, GameWorld에서 실시간 평가로 바꾸면 범용 모델은 평균 17~35%p 떨어졌지만 Gamer-35B-A3B-CPT는 3.4%p 올랐어요.

연구진은 게임 테스트, 접근성, 사람-AI 상호작용 연구를 응용처로 들며 책임 있는 연구·사용을 강조해요.
