GitHub 저장소 README를 끝까지 읽고 정리했어요. README가 짧아 핵심을 모두 옮겼어요.

### 무엇인가

**KernelSU**는 **안드로이드 기기를 위한 커널 기반 루트 솔루션**이에요.

### 주요 기능

- 커널 기반 `su`와 루트 접근 관리
- **메타모듈** 기반 모듈 시스템: 시스템 파티션을 직접 건드리지 않는(systemless) 수정을 위한 플러그인형 구조
- **App Profile**: 루트 권한을 '우리'에 가둬 앱별로 제한

### 호환성

- 공식 지원은 **Android GKI 2.0 기기(커널 5.10 이상)**예요. 4.14 이상의 옛 커널도 지원하지만 직접 커널을 빌드해야 해요.
- WSA, ChromeOS, 컨테이너 기반 안드로이드도 지원해요.
- 아키텍처는 arm64-v8a와 x86_64를 지원해요.

> **주의**: 최근 커널 버전의 호환성 깨지는 변경 때문에 **x86_64에서 KernelSU가 실패하고 커널 패닉이 날 수 있어요**. 자세한 내용은 공식 웹사이트를 확인하라고 안내해요.

### 번역 정책

Weblate로 번역 기여를 더는 받지 않고, **모든 번역을 LLM으로 처리**해요. 새 언어 추가 PR은 환영하지만 영어·중국어 번역 수정은 받지 않아요.

### 라이선스와 크레딧

`kernel` 디렉터리는 GPL-2.0-only, 나머지는 GPL-3.0-or-later예요. Kernel-Assisted Superuser(아이디어), Magisk, genuine(APK v2 서명 검증), Diamorphine(일부 루트킷 기법)을 크레딧으로 밝혀요. 스타는 약 2만600개예요.
