Hugging Face 모델 카드 전체를 읽고 정리했어요. 수치는 모델 카드에 나온 값 그대로예요.

### 소개

**Sage S2.1 Flash**는 상하이 인공지능 연구소(Shanghai Artificial Intelligence Laboratory)가 만든 과학 멀티모달 모델로, 여러 차례 분석과 검증이 필요한 연구 과제를 위해 설계됐어요. 과학 데이터 이해에 정보 검색, 프로그래밍, 도구 사용을 결합해, 전문 소프트웨어로 분석하고 중간 출력과 시각 피드백으로 결과를 확인하며 다음 단계를 조정해요.

**Sage SciPerception** 통합 표현 구조로 분자 그래프, 결정 구조, 단백질 서열과 3D 구조 등 **10종 이상의 과학 입력**을 받아요. 각 입력을 공통 표현 공간으로 투영해 자연어 지시와 함께 추론하고, 예측·분류·위치 찾기·정량 분석·구조 추론에 써요. 모델 크기는 321B 파라미터로 표시돼 있고, FP8 버전도 있어요.

### 평가 하이라이트

카드의 표(15개 벤치마크, 6개 모델: Sage S2.1 Flash, GLM-5.3-Flash, DeepSeek-V4.1-Flash-1017, Qwen3.8-Max, GPT-5.6 Sol, Claude Opus 5)에서 **4개 1위, 7개 2위**라고 해요.

- **ML 엔지니어링**: MLE-bench Lite 90.3으로 1위(DeepSeek-V4.1-Flash-1017 89.2).
- **문서 업무**: OfficeQA Pro 72.2, Harvey LAB 25.0, SpreadsheetBench 2 37.1로 1위.
- **도구 사용·연구 실행**: AutomationBench, ALE-CLI, BFCL V4, WebArena-Verified, DeepResearch Bench II, JobBench, OSWorld-Verified에서 2위.

참고로 같은 표에서 SWE-bench Pro는 60.6(Claude Opus 5 76.5), Terminal-Bench 2.1은 87.9(Claude Opus 5 90.2)로 코딩 쪽은 최상위가 아니에요.

### 배포

- 과학 입력은 과학 인코더와 학습된 projector로 언어 모델 임베딩 공간에 매핑해요. projector와 로딩 스크립트를 받아 CPU에서 로드를 확인한 뒤, 클라이언트가 특징을 뽑아 텍스트 임베딩과 합쳐 vLLM 서버(`--enable-prompt-embeds`)의 `/v1/completions`로 `prompt_embeds`를 보내요.
- 코딩, 오피스, 보안, 컴퓨터 사용 같은 일반 작업은 별도 배포 가이드를 따라요.
