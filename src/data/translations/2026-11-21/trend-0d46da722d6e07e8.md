AI타임스 박찬 기자의 기사 본문 전체를 읽고 정리했어요.

### 무엇이 생겼나

- 구글은 19일(현지시간) 공식 블로그에서 맥용 제미나이 앱에 **컴퓨터 유즈(Computer Use)** 기능을 추가했다고 밝혔어요. 프롬프트에 '@Computer use'를 넣고 작업을 설명하면 제미나이가 필요한 앱을 실행하고 마우스 클릭, 키보드 입력, 메뉴 탐색, 양식 작성을 직접 해요.
- 기존 '태스크(Task)' 기능도 로컬 파일이나 지메일·구글 캘린더 같은 연결 서비스에서 여러 단계 작업을 했지만, 이제는 연동을 지원하지 않는 일반 맥 프로그램도 화면을 통해 조작할 수 있어요. API 없이 사람처럼 화면을 보고 버튼을 눌러, 서로 연결되지 않은 프로그램 사이에서도 일을 이어 가요.

### 쓰임 예시

- 디자인 프로그램에서 사진 여러 장을 한꺼번에 보정하기
- 로컬 PDF에서 무게·치수·주소를 뽑아 온라인 배송 견적 양식에 입력하기
- 온라인 대시보드의 실시간 지표와 화면 이미지를 모아 구글 슬라이드 발표 자료 만들기
- 구글 제미나이 계정은 X에 빠른 스케치를 Blender에서 리깅된 3D 모델로 바꾸는 시연을 올렸어요.

### 사용자 화면은 그대로

제미나이는 사용자의 기본 화면과 분리된 가상 화면에서 일해서, AI가 앱을 다루는 동안에도 사용자는 자기 화면과 커서로 다른 일을 할 수 있어요. 채팅창에 진행 과정이 실시간으로 보이고, 중간에 지시를 바꾸거나 멈출 수 있어요.

### 늦은 출발

- 앤트로픽은 2024년 10월 클로드에 컴퓨터 조작 기능을, 오픈AI는 2025년 1월 브라우저를 조작하는 '오퍼레이터'를 내놨어요. 일반 사용자용 맥 앱 기준으로 구글은 이들보다 늦었어요.
- 구글도 2024년 12월 브라우저 에이전트 '프로젝트 마리너(Project Mariner)'를, 지난해 10월 '제미나이 2.5 컴퓨터 유즈' 모델을 개발자 API로 냈고, 이번에 일반 맥 앱으로 넓힌 거예요.

### 이용 조건

미국에서 영어로 먼저 제공되고, 애플 실리콘 맥과 macOS 세쿼이아 15 이상이 필요해요. 구글 AI 플러스·프로·울트라 구독자가 쓸 수 있어요.
