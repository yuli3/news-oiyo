### 설계 목표

세상에 JSON 라이브러리는 무수히 많지만, 이 라이브러리는 세 가지를 목표로 했다고 해요.

- **직관적인 문법:** 파이썬 같은 언어에선 JSON이 일급 데이터 타입처럼 느껴져요. 현대 C++의 연산자 기법을 모두 써서 코드에서 같은 느낌을 내려 했어요.
- **간단한 통합:** 코드 전체가 헤더 파일 `json.hpp` 하나예요. 라이브러리도, 하위 프로젝트도, 의존성도, 복잡한 빌드 시스템도 없어요. 순수 C++11로 작성돼 컴파일러 플래그나 프로젝트 설정을 바꿀 필요가 없고, 인기 패키지 매니저에 모두 들어 있어요.
- **철저한 테스트:** 예외 동작까지 포함해 코드 100%를 단위 테스트로 덮고, Valgrind와 Clang Sanitizer로 메모리 누수가 없는지 확인했어요. Google OSS-Fuzz가 모든 파서를 24시간 퍼징해 지금까지 수십억 건을 실행했고, OpenSSF Best Practices를 따르고 있어요.

### 덜 중요하게 본 것

- **메모리 효율:** JSON 객체마다 포인터 하나(유니언 최대 크기)와 열거형 1바이트의 오버헤드가 있어요. 기본적으로 문자열은 `std::string`, 숫자는 `int64_t`·`uint64_t`·`double`, 객체는 `std::map`, 배열은 `std::vector`, 불리언은 `bool`을 쓰지만 `basic_json` 템플릿으로 바꿀 수 있어요.
- **속도:** 더 빠른 JSON 라이브러리는 분명 있어요. 하지만 헤더 하나로 JSON 지원을 빨리 붙이는 게 목적이라면 이 라이브러리가 맞고, `std::vector`나 `std::map`을 쓸 줄 알면 바로 쓸 수 있다고 해요.

### 다루는 기능 (목차 기준)

파일에서 JSON 읽기, JSON 리터럴로 객체 만들기, 직렬화·역직렬화, STL 같은 접근과 STL 컨테이너 변환, JSON Pointer·JSON Patch·JSON Merge Patch, 임의 타입 변환과 enum 변환, BSON·CBOR·MessagePack·UBJSON·BJData·BON8 같은 바이너리 포맷, 제로카피 뷰, CMake·패키지 매니저·pkg-config 통합 등이 있어요.
