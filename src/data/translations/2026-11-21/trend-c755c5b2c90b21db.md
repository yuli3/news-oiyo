AI타임스 박찬 기자의 기사 본문 전체를 읽고 정리했어요.

### 새 과금 방식

- 오픈AI가 18일(현지시간) API 요청의 완료 목표 시간을 **2시간 또는 8시간**으로 설정하면 요금을 깎아 주는 옵션을 도입했어요. 2시간은 표준보다 30%, 8시간은 40% 저렴해요.
- 설정한 시간은 목표치라, 작업이 먼저 끝나면 결과도 일찍 받아요.
- 리스폰스(Responses) API 백그라운드 모드(Background Mode)에 추가된 '완료 시간(Completion Window)' 옵션이에요. 대상은 GPT-6.2 아스트라, GPT-6.2 솔, GPT-6.1 테라, GPT-6 루나 4종이고 공개 베타로 제공돼요.

### 어디에 쓰나

- 즉답이 필요 없는 대량 문서 분석, 보고서 작성, 오래 도는 에이전트 작업에 맞아요. 예컨대 수백 건 문서를 분석해 다음 날 아침까지 보고서를 내는 일이라면 8시간으로 잡아 40%를 아낄 수 있어요.
- 여러 단계 에이전트 작업에도 적용돼요. 첫 요청 뒤 문서 검색이나 외부 도구 호출로 후속 요청이 생겨도 조건을 맞추면 같은 할인 요금을 받아요. 즉답이 필요한 작업은 기존처럼 최대한 빨리 처리하게 둘 수 있고, 이때는 할인이 없어요.
- 오픈AI 개발자 계정(@OpenAIDevs)은 "모든 워크플로가 즉각적인 응답을 필요로 하지는 않는다"며 기다릴 수 있는 단일·다중 턴 작업에서 GPT-6.2 아스트라·솔 기준 표준보다 토큰당 최대 40%를 아낄 수 있다고 안내했어요.

### 플렉스의 대체

이번 변화는 기존 저비용 방식 '플렉스(Flex)'를 시간 기반 할인으로 바꾸는 흐름과 이어져요. 플렉스는 느린 응답이나 일시적 자원 부족을 감수하는 대신 싸게 쓰는 방식이었는데, 오픈AI는 GPT-6.2 아스트라와 솔부터 신규 모델에 플렉스를 제공하지 않는다고 밝혔어요. 그래서 최신 모델을 싸게 쓰려면 표준 처리에서 2시간·8시간 완료 목표를 거는 방법을 쓰면 돼요.
