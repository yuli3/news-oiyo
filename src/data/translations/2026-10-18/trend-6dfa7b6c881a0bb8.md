AI타임스(박찬 기자) 기사 전체를 읽고 정리했어요. 원문이 한국어라 번역보다는 재구성이에요.

### 무엇이 바뀌었나
오픈AI는 10월 15일 X로 크롬용 챗GPT 확장 프로그램 개선을 알렸어요. 이제 챗GPT가 **브라우저에 열린 여러 탭의 내용을 활용해 답하고**, 요청하면 **그 탭에서 직접 작업**도 해요. 웹페이지 옆 사이드바에서 대화하고, 기존 대화 기록도 거기서 볼 수 있어요.

### 쓰는 법
1. 크롬 웹 스토어에서 오픈AI 공식 '챗GPT' 확장 프로그램을 설치해요.
2. 탭 제어를 쓰려면 챗GPT 데스크톱 앱의 **설정 → 컴퓨터 사용**에서 크롬을 연결해요.
3. 크롬 도구 모음의 챗GPT 아이콘을 눌러 사이드바를 열어요. `@chrome`을 입력하면 열린 탭을 요청 대상으로 지정할 수 있어요.

| 모드 | 하는 일 |
|---|---|
| Chat | 페이지 내용을 읽고 질문에 답함 |
| Work | 탭을 직접 제어해 작업 수행 |

### 예시로 든 작업
- 쇼핑몰 세 곳의 소파 페이지를 열어 두고 크기·소재·배송 기간·반품 정책 비교
- 여러 업체의 가격 페이지에서 필요한 기능을 갖춘 요금제를 찾고, 가격·주요 기능·출처 링크를 담은 비교표 작성
- 행사 안내문 정보로 등록 양식을 채우되 **제출 직전에 멈추기**
- 여러 탭의 인테리어 업체를 비교한 뒤 적합한 업체에 보낼 이메일 초안 작성
- 메시지 전송, 파일 다운로드, 열린 탭 정리·그룹 묶기 같은 브라우저 관리

### 의미
기사는 이를 웹 탐색을 넘어 브라우저 안에서 실제 작업을 하는 AI 에이전트 기능을 강화하는 흐름으로 봐요. 여러 페이지를 오가며 복사·비교하던 과정을 줄이고 조사부터 문서 작성까지 한곳에서 처리하게 하려는 거예요. 관련 기사로 코덱스용 크롬 확장, 챗GPT·코덱스·브라우저를 합친 데스크톱 슈퍼 앱 계획이 함께 소개됐어요.
