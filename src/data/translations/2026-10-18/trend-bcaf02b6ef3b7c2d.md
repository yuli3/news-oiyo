Reddit은 API 키 없이 본문을 직접 읽을 수 없어 RSS 발췌로 옮겼어요. 발췌가 약 4,000자에서 잘려 **10개 중 7번째 항목까지만** 읽었고, 본문 이미지는 보지 못했어요.

### 배경
작성자는 다들 Qwen 3.8에 들떠 있지만 자신은 여전히 3.6을 다듬고 있고 3.8의 말투가 싫다고 해요. 5월 31일쯤 Qwen 3.5 27B로 첫 에이전트를 시작해 4개월 넘게 배운 것을, 질문하기 망설이는 새 사용자들에게 나누려는 글이에요. 모든 요령은 **llama.cpp**로 했다고 해요.

### 읽은 7가지
1. **나만의 작은 앱 만들기**: 이 글도 직접 만든 메모장 대체 앱(워드 프로세싱, 사이드 패널, 라이트·다크 모드)으로 쓰고 있다며, 문제가 생기면 "이걸 쉽게 해 줄 앱을 만들 수 있나?"부터 생각하라고 해요.
2. **채팅 UI 프런트엔드 만들기**: 창의력이 없으면 기존 것을 베끼라고 해요. 자신은 Claude 화면을 본떠 맞춤화했어요.
3. **ReAct 루프 만들기**: 도구를 쓰고 결과를 읽고 다시 쓰는 반복으로, 직접 만든 채팅 UI에 꼭 필요해요.
4. **MCP 도구 만들기**: 가장 좋아하는 기능이에요. 안전하지 않을 수 있는 서드파티 대신 원하는 MCP 도구와 필요하면 서버까지 만들게 할 수 있어요.
5. **서브 에이전트 띄우기**: 파이썬 파일 하나면 돼요. MCP 도구가 컨텍스트를 많이 먹으니, 자체 컨텍스트를 가진 서브 에이전트에 일을 넘기면 사실상 컨텍스트 한도를 두세 배로 늘릴 수 있다고 해요.
6. **파이프라인 러너 만들기**: n8n의 한계가 아쉬워 비슷한 걸 직접 만들었고, 결국 n8n 화면을 본떴대요. 순차 에이전트마다 별도 컨텍스트를 주려면 llama.cpp의 `cache-idle-slots`를 켜 KV 캐시를 CPU RAM으로 교체하라고 해요.
7. **모델 런처 만들기**: 폴더의 모델과 Jinja 템플릿, 파라미터를 골라 실행하고 마음에 들면 별칭으로 저장해 다음에 바로 고르는 도구예요.

나머지 세 항목은 발췌가 잘려 확인하지 못했어요.
