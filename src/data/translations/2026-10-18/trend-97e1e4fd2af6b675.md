### 무엇인가
Plane은 이슈 추적, 스프린트(사이클) 운영, 제품 로드맵 관리를 "도구 관리의 혼란 없이" 하게 해 주는 오픈소스 프로젝트 관리 도구예요. 저장소 소개는 Jira, Linear, Monday, ClickUp의 오픈소스 대안이라고 해요.

### 설치
| 방법 | 내용 |
|---|---|
| Plane Cloud | 무료 계정 가입, 인프라 걱정 없이 가장 빠르게 시작 |
| 셀프호스팅 | Docker, Kubernetes 배포 가이드 제공. 인스턴스 관리자는 'God mode'에서 인스턴스 설정 |

### 기능
- **Work Items**: 파일 업로드를 지원하는 리치 텍스트 에디터로 작업을 만들고, 하위 속성과 관련 이슈 참조를 붙여요.
- **Cycles**: 번다운 차트 등으로 팀의 진행 속도를 추적해요.
- **Modules**: 큰 프로젝트를 관리 가능한 작은 모듈로 나눠요.
- **Views**: 필터로 필요한 이슈만 보이게 하고 저장·공유해요.
- **Pages**: AI 기능과 리치 텍스트 에디터로 아이디어를 정리하고, 메모를 실행 항목으로 바꿀 수 있어요.
- **Analytics**: 모든 Plane 데이터에 대한 실시간 인사이트로 추세와 병목을 봐요.

### 커뮤니티와 보안
GitHub Discussions와 포럼에서 질문·버그·아이디어를 나누고, 행동 강령을 따라요. 보안 취약점은 공개 이슈 대신 security@plane.so로 알려 달라고 해요. 버그 제보, 문서 PR, 생태계 통합 소개, 인기 기능 요청 추천 등으로 기여할 수 있어요.

### 기타
라이선스는 **GNU AGPL v3.0**이에요. 저장소에 `AGENTS.md`와 `.claude/skills` 폴더가 있어요. 페이지 기준 스타 6만 1천 개, 포크 6,100개, 커밋 7,220개예요. 주제 태그에는 django, react, postgresql, redis, kanban, gantt 등이 있어요.
