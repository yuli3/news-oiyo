Black Forest Labs 블로그 글(2026-10-15) 전체를 읽고 옮겼어요. 비교 수치는 BFL 내부 평가와 NVIDIA 측정이에요.

### 무엇을 냈나
**FLUX 3 Image Klein**은 5.6B 파라미터 오픈 웨이트 모델로 텍스트→이미지 생성, 이미지 편집, **최대 10장 참조 이미지**를 쓰는 다중 참조 생성을 해요. 전체 FLUX 3 Image와 핵심 기능을 공유해요.
- 네이티브 4K 생성, 픽셀 단위 편집
- 요소 위치를 정하거나 편집 범위를 제한하는 **바운딩 박스**
- 이미지(공간), 비디오(움직임·물리), 오디오(사건·상호작용)를 함께 학습한 FLUX 3의 성과를 이어받음

파인튜닝용 base 모델과 저지연용 step distilled 모델, NVIDIA와 만든 FP8·INT8·NVFP4 빌드를 함께 내놨어요.

### 성능 주장
- 내부 평가에서 텍스트→이미지, 다중 참조, 편집 모두 **더 큰 오픈 모델보다 1위**이고, 비교한 폐쇄형 Ideogram V4.5와 FLUX.2 [pro]보다도 높았다고 해요.
- 비교 대상 중 가장 작아요(Qwen-Image 2.1 7B, Krea 2 12.9B). FLUX.2 [klein] 9B보다 파라미터는 38% 적은데 Elo가 텍스트→이미지 +91, 편집 +70이에요.
- BFL API에서 Qwen-Image 2.1, FLUX.2 [pro], Ideogram V4.5, Krea 2보다 지연이 낮다고 해요(다른 모델은 클라이언트 측 측정이라 네트워크 시간 포함).

### 로컬 실행
| 항목 | 값 |
|---|---|
| 가중치 크기 | BF16 11.2GB, FP8 5.6GB |
| 최소 VRAM | INT8 빌드로 GeForce RTX 8GB (ComfyUI·Diffusers) |
| 1MP 생성 시간(distilled+INT8) | RTX 5090 약 4초, RTX 4070 9초 미만 |
| GB300(NVFP4) | 0.6초 미만 |

Diffusers와 Ostris AI Toolkit이 첫날부터 LoRA 학습을 지원하고, ComfyUI·TensorRT-LLM·SGLang Diffusion·vLLM-Omni도 지원해요.

### 이용 방법과 라이선스
- BFL API 모델명은 `flux-3-image-klein`이고 가격은 1K 이미지당 0.009달러부터예요. 편집하지 않은 영역을 그대로 보존하는 픽셀 복원을 제공해요.
- **FLUX Kommunity License**: 개인과 연 매출 500만 달러 미만 기업은 상업적 이용 무료, 연구·비상업 이용도 허용. 큰 조직은 자체 호스팅 라이선스나 API를 써야 해요.
- 학습 데이터 필터링, 사후 미세조정, 내부 레드팀과 외부 파트너 Cinder의 평가를 거쳤다고 해요.
- FLUX 3 계열의 두 번째 오픈 웨이트로, 로봇 제어용 7B 모델 FLUX 3 Action에 이은 거예요.
