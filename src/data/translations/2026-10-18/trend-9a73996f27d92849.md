### 무엇인가
Microsoft PowerToys는 윈도우를 사용자에 맞게 바꾸고 일상 작업을 간소화하는 유틸리티 모음이에요. **30개가 넘는** 도구가 들어 있어요.

### 유틸리티 목록
| 분류(편의상 묶음) | 도구 |
|---|---|
| 창·화면 | Always on Top, FancyZones, Crop And Lock, Grab And Move, Window Hopper, Workspaces, ZoomIt, Screen Ruler, PowerDisplay, Light Switch |
| 실행·검색 | PowerToys Run, Command Palette, Command Not Found, Shortcut Guide |
| 입력 | Keyboard Manager, Mouse Utilities, Mouse Without Borders, Quick Accent |
| 파일 | File Explorer Add-ons, File Locksmith, PowerRename, Image Resizer, New+, Peek |
| 텍스트·클립보드 | Advanced Paste, Text Extractor, Color Picker |
| 시스템 | Awake, Environment Variables, Hosts File Editor, Registry Preview |

### 설치
- **GitHub 릴리스**: Assets에서 아키텍처와 설치 범위에 맞는 파일을 고르면 돼요. 대부분은 x64 사용자 범위예요.
- **Microsoft Store**에서 설치할 수 있어요.
- **WinGet**: 사용자 범위는 `winget install Microsoft.PowerToys -s winget`, 머신 전체는 `--scope machine`을 붙여요. WinGet으로 업데이트하면 기존 설치 범위를 따라가요.
- Chocolatey, Scoop 같은 커뮤니티 설치 방법도 문서에 안내돼 있어요.

### 로드맵
**v0.102**에서는 여러 유틸리티를 WinUI 3로 현대화하고, Command Palette에 탭과 JavaScript/TypeScript 확장을 더하고, 생산성 개선을 추가할 계획이에요.

### 기여와 개인정보
코드 외에도 스펙 작성, 디자인, 문서, 버그 찾기로 기여할 수 있어요. 기능을 만들기 전에 기여 가이드를 읽어 달라고 하고, 대부분의 기여는 CLA 동의가 필요해요. 앱은 기본 진단 데이터(텔레메트리)를 기록하며 자세한 내용은 Data and Privacy 문서에 있어요. 라이선스는 MIT, 페이지 기준 스타 13만 9,400개, 포크 8,700개예요.
