### 무엇인가

**openai/openai-cookbook**은 OpenAI가 운영하는 저장소로, **OpenAI API로 자주 하는 작업을 해내는 예제 코드와 가이드**를 모아 둔 곳이에요. 저장소 설명도 "Examples and guides for using the OpenAI API"예요.

### 시작하려면

- 예제를 돌리려면 **OpenAI 계정과 API 키**가 필요해요. README는 무료 계정을 만드는 링크를 안내해요.
- API 키는 `OPENAI_API_KEY`라는 **환경 변수**로 설정해요.
- VS Code 같은 대부분의 IDE에선 저장소 루트에 `.env` 파일을 만들고 `OPENAI_API_KEY=<키>`를 적어 두면 노트북들이 자동으로 읽어요.
- 키를 담은 `.env` 파일은 실수로 커밋하지 않도록 주의하는 게 좋아요.
