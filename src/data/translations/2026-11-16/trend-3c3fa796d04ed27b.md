Hugging Face 모델 카드 `higurashi-ai/Haru-4B`를 끝까지 읽고 옮겼어요(Reddit r/LocalLLaMA에서 화제가 된 글이 가리키는 원문이에요).

### 어떤 모델인가

Haru-4B는 **저지연·다국어·전이중 연속 음성 대화 기반 모델**이에요. 사람이 전화 통화를 하듯 **듣는 동시에 말해요.** 연구용으로 공개한 사전학습 기반(base) 모델이에요.

- **7.5Hz 네이티브 전이중**: 133ms마다 사용자 오디오 한 프레임을 받고 자기 오디오와 텍스트 한 프레임을 만들어요. 사용자 오디오, 모델 오디오, 모델 텍스트를 언어 모델의 한 위치에 합쳐서 듣기와 말하기가 서로를 기다리지 않아요.
- **연속 오디오, 한 번의 샘플링**: 오디오는 프레임당 64차원 잠재 벡터예요. 작은 MLP 헤드가 MeanFlow 샘플링으로 언어 모델 은닉 상태에서 한 번에 만들어요. 별도 오디오 트랜스포머나 이산 오디오 토큰이 없어요.
- **캐릭터와 목소리 제어**: 텍스트 카드로 캐릭터를, 짧은 참고 음성으로 목소리를 정해요.
- **다국어**: 영어, 스페인어, 포르투갈어, 독일어, 프랑스어, 중국어, 일본어, 러시아어, **한국어**.

### 사용법

코드는 GitHub `higurashi-ai/Haru`에 있고 웹 데모가 있는 PyTorch 구현, macOS 네이티브 앱이 있는 MLX 구현, vLLM-Omni 서빙 플러그인을 제공해요. NVIDIA GPU(메모리 약 12GB)에서 서버를 띄우고 `http://localhost:8998`에서 캐릭터를 고르고 목소리를 주면 대화할 수 있어요. 지연을 줄이려면 유선 헤드폰과 마이크를 권하고, 블루투스는 100ms 이상 더해진다고 해요.

목소리 클립은 포함하지 않아요. 화자 한 명, 3초~3분의 깨끗한 음성을 직접 올려야 하고, **사용할 권리가 있는 목소리만** 쓰라고 해요. Python API로는 `DuplexSession`에 24kHz 오디오 3,200샘플씩 넣고 받는 방식이에요.

### 구조

| 부분 | 내용 |
|---|---|
| 언어 모델 | Qwen3.5-4B 텍스트 백본, 32층, hidden 2560 |
| 오디오 코덱 | VibeVoice 음향 토크나이저, 인과적, 24kHz, 잠재 벡터당 3,200샘플 |
| 오디오 헤드 | 4층 MLP, MeanFlow, 1스텝 샘플링, guidance 1~2(기본 1.5) |
| 프레임 속도 | 7.5Hz |

전체 파라미터는 약 53억 개(BF16)라 페이지에는 5B로 표시돼요.

### 한계와 라이선스

자연스러운 대화는 하지만 **사실 정보의 믿을 만한 출처가 아니고**, 어시스턴트처럼 지시를 따르지도 않아요. 참고 음성의 목소리를 흉내 낼 수 있으니 권리가 있는 목소리만 쓰라고 거듭 강조해요. 가중치는 Apache License 2.0이에요. 수집 시점 기준 지난달 다운로드 2,098회, 좋아요 300개였어요.
