Hugging Face 모델 카드 `AxiomicLabs/X3Guard-150M`을 끝까지 읽고 옮겼어요(r/LocalLLaMA에서 화제가 된 글이 가리키는 원문이에요). 성능 수치는 모두 제작사가 직접 잰 값이에요.

### 무엇인가

X3Guard-150M은 GPT-X3-150M을 미세조정한 **소형 프롬프트 가드**예요. 사용자 프롬프트를 읽고 두 가지 독립 점수를 돌려줘요.

- **harm_score**: 프롬프트가 유해할 가능성
- **adversarial_score**: 탈옥이나 프롬프트 인젝션 시도일 가능성

1억4,900만 파라미터로, 제작사가 평가한 모델 중 두 분류를 모두 하는 모델 가운데 가장 작고 가장 성능이 좋다고 해요.

### 유해성 탐지

기본 "Balanced" 설정에서 평균 F1 **0.818**(WildGuardTest 0.874, CircleGuardBench 0.761)이에요.

| 모델 | 파라미터 | 평균 F1 |
|---|---|---|
| IBM Granite Guardian 3.1 2B | 2,534M | 0.865 |
| Qwen3Guard-Gen 0.6B (strict) | 596M | 0.843 |
| Fastino GLiGuard 300M | 208M | 0.827 |
| **X3Guard 150M (Balanced)** | 149M | 0.818 |
| OpenAI gpt-oss-safeguard-20b | 약 21,000M | 0.762 |
| Meta Llama Guard 3 1B | 1,498M | 0.692 |
| Meta Llama Guard 4 12B | 약 12,000M | 0.662 |

### 적대성 탐지

X3Guard는 5위로, Sheltron, ProtectAI 탐지기 2개(벤치마크 중 하나인 jackhhao로 학습해 공정한 비교가 아님), DuoGuard 0.5B 뒤예요. gpt-oss-safeguard-20b, Llama Prompt Guard 2 두 모델, Granite Guardian 3.1 2B 등보다는 앞섰어요. 두 분류를 다 하는 모델 중 양쪽 모두에서 X3Guard를 앞서는 모델은 없다고 해요.

### 평가 메모

- 파라미터 수는 임베딩 포함이라 이름과 다를 수 있어요(Llama Prompt Guard 2 86M·22M은 실제 279M·71M).
- gpt-oss-safeguard-20b는 작성한 정책에 따라 결과가 달라지고, Granite Guardian은 연산 제약으로 8비트로 돌렸어요.
- 벤치마크 프롬프트와 유사 변형은 학습 데이터에서 걸러냈다고 해요.

### 엄격도 설정

Strict(놓치면 안 되는 모더레이션), Balanced(일반 챗봇, 기본 0.5 임계값), Permissive(오탐을 줄여야 하는 롤플레이·창작·개발 도구·보안 연구) 세 가지예요. Strict와 Permissive 임계값은 벤치마크 결과를 보고 골랐으니 참고용으로 보고 실제 트래픽으로 시험하라고 권해요.

### 구조와 속도

- GPT-X3-150M(TX5 하이브리드), 24층(GDN2 18 + gated GQA 6), 독립 시그모이드 헤드 2개. 유해 카테고리는 돌려주지 않아요.
- 최대 1,024토큰이고, 긴 프롬프트는 앞 768·뒤 255토큰만 남겨요.
- RTX 4080에서 한 개씩 처리할 때 지연 중앙값 33.3ms(95백분위 43.3ms)예요. CPU나 단건 처리엔 ONNX 양자화 버전을 권해요.

### 학습 데이터

WildGuardMix(학습 분할), WildChat, WildJailbreak, Gandalf, deepset prompt-injections, 자체 합성 프롬프트, 그리고 비공개 **AlignmentArena**(플레이어가 쓴 탈옥 프롬프트) 데이터를 썼어요. AlignmentArena는 효과적인 탈옥 프롬프트가 많아 이중 용도 위험이 있어 비공개라고 해요.

### 한계

프롬프트만 검사하고 모델 응답은 평가하지 않으며, 왜 걸렸는지 설명하지 않아요. 유해 유형을 분류하지 않고, 주로 영어로 평가했어요. 접근 제어, 출력 필터, 사람 검토와 함께 **방어의 한 층**으로 쓰라고 하고, Apache-2.0에 따라 보증은 없어요. 사용하려면 `trust_remote_code=True`가 필요해요.
