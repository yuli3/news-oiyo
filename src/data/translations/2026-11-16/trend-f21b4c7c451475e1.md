Hugging Face 모델 카드 `meituan-longcat/LongCat-Video-Avatar-1.6`을 끝까지 읽고 옮겼어요(r/LocalLLaMA에서 화제가 된 글이 가리키는 원문이에요). 평가 수치는 제작사가 밝힌 값이에요.

### 무엇이 나왔나

메이퇀 LongCat 팀의 **오디오 기반 인물 영상 생성** 오픈소스 프레임워크 최신판이에요. 1.5를 바탕으로 표정의 자연스러움, 입술-오디오 동기화, 얼굴과 몸 동작의 조화, 긴 영상의 시각적 일관성을 개선하고 추론 최적화를 더했어요.

- **더 자연스럽고 안정된 입 모양**: 과장되거나 억지스러운 입 움직임, 지나치게 붉은 입술 색, 입 주변의 시간적 불안정을 줄였어요.
- **안정적인 긴 영상**: 자기회귀식 영상 이어 붙이기에서 오차 누적을 줄여 **10분 넘는 영상**도 화질, 인물 일관성, 시간적 연속성을 유지해요.
- **더 빠른 추론**: 파이프라인 전체와 모델 실행을 최적화했어요.

### 평가

1.6을 이전 1.5, 그리고 상용 시스템 4개(OmniHuman-2.0, HeyGen, OmniHuman-1.5, Kling Avatar 2.0)와 비교했어요. 15개 모델 쌍 전체에 대한 인간 선호 평가에서 유효 투표 **33,051표**를 모았고, 1.6은 Bradley–Terry Elo **1068.1**로 6개 시스템 중 **2위**, OmniHuman-2.0 바로 뒤였다고 해요.

### 사용법

- GitHub `meituan-longcat/LongCat-Video`를 받아 Python 3.10 conda 환경에 PyTorch 2.6(CUDA 12.4), FlashAttention 2.7.4, librosa, ffmpeg 등을 설치해요.
- 기반 모델 `LongCat-Video`와 `LongCat-Video-Avatar-1.6` 가중치를 `huggingface-cli`로 내려받아요.
- 단일·다중 인물에 대해 음성+텍스트→영상, 음성+이미지→영상, 영상 이어 붙이기 예제를 `torchrun`으로 돌려요.

### 체크포인트 구성

- 1.5와 같은 기반 구조에 작업별 LoRA 어댑터 2개(DMD LoRA, OPSD LoRA)가 들어 있어요.
- `--mix_steps=N`이면 8단계 디노이징 중 처음 N단계는 DMD와 OPSD를 섞고 나머지는 OPSD만 써요. 기본값(`--mix_steps=4 --mix_alpha=1.0`)은 처음 4단계 DMD, 나머지 4단계 OPSD예요. DMD 비중을 높이면 구조적 안정성에 도움이 될 수 있다고 해요.
- 선택적으로 가중치 전용 INT8 DiT(`--use_int8`)나 FP8(`--use_fp8`, Transformer Engine 필요)을 쓸 수 있지만 둘을 동시에 켜면 안 돼요.
- H100·H200 같은 Hopper GPU에선 FlashAttention 3를 켜면 크게 빨라지고, GPU가 2개를 넘으면 All-to-All 작업 공간 최적화를 권해요. `--compile_dit`·`--compile_vae`는 처음 몇 번은 컴파일 때문에 느리지만 이후 같은 입력 크기에선 훨씬 빨라져요.
