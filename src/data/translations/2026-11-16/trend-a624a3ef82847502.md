### 무엇인가

**UniGetUI**는 윈도우 10·11에서 흔히 쓰는 **명령줄 패키지 관리자들을 위한 직관적인 GUI**예요. 저장소 설명은 스스로를 "패키지 관리자를 관리하는 패키지 관리자 관리자"라고 농담처럼 소개해요. macOS와 리눅스용 크로스플랫폼 빌드도 있고, WinGet, Scoop, Chocolatey, Homebrew, APT, DNF, Pacman, Flatpak, Snap, pip, npm, Bun, .NET Tool, PowerShell Gallery 등을 지원해요. 한 화면에서 소프트웨어를 찾고, 설치하고, 업데이트하고, 지울 수 있어요.

### 주의할 점

- README 맨 위에서 **wingetui·unigetui 이름의 .com 사이트는 제3자가 운영하는 가짜**라고 경고해요. 공식 사이트는 devolutions.net/unigetui, 공식 저장소는 GitHub의 Devolutions/UniGetUI뿐이에요.
- UniGetUI는 연동하는 패키지 관리자와 제휴 관계가 아니고, 패키지는 제3자가 제공하니 설치 전에 출처와 배포자를 확인하라고 해요.

### Devolutions로 이전

Martí Climent가 만들었고 이제 **Devolutions**가 유지보수해요. 프로젝트는 무료·오픈소스·**MIT 라이선스**로 남고, 장기 투자, 체계적 거버넌스, 강화된 보안 절차, 기업용 로드맵을 더하면서도 독립적이고 커뮤니티 중심으로 유지한다고 해요.

### 설치

- 윈도우는 **Microsoft Store**가 권장 방식이고, 설치 파일, 포터블 zip, `winget install --exact --id Devolutions.UniGetUI --source winget`도 쓸 수 있어요.
- 릴리스는 모든 플랫폼에서 **NativeAOT**로 컴파일돼 시작이 빠르고 공격 표면이 줄었대요.
- macOS는 .dmg·.tar.gz, 리눅스는 .deb·.rpm·.tar.gz를 제공하고 glibc 2.27 이상이 필요해요.

### 주요 기능

- 패키지 검색·필터, 설치 전 메타데이터(다운로드 URL, 배포자, 크기) 확인
- 여러 패키지 일괄 설치·업데이트·제거, 자동 업데이트와 패키지별 무시·건너뛰기
- 업데이트 확인·설치·백업 일정 예약, 시스템 트레이 알림
- 패키지별 설치 옵션·이전 버전·아키텍처 지정과 저장
- 패키지 목록 내보내기·가져오기, 로컬 백업과 비공개 GitHub Gist 동기화
- 최근 1,000개 작업 기록, 윈도우 바로가기 생성 제어
