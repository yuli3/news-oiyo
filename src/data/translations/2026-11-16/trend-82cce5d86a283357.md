수집된 링크는 60초 데모 영상(mp4)이라 직접 볼 수 없어서, Reddit 소개글과 **Hugging Face 모델 카드(`charcot-ai/marimba` README)** 를 읽고 옮겼어요. 평가 수치는 제작사가 밝힌 값이에요.

### 무엇인가

작성자는 Marimba를 "오디오판 Jev"라며, 빠르고 가볍게 음성에 대한 **타입이 정해진 판단**(예/아니오, 선택, 점수)을 돌려주도록 만들었다고 소개해요. 누군가 말하고 있는지, 차례가 끝났는지, 어떤 언어인지, 특정 단어가 나왔는지를 물을 수 있어요. 고정된 **Qwen3-ASR-0.6B** 백본을 쓰고, 같은 구간의 여러 질문이 인코더 한 번 실행을 공유해요. 가중치는 Apache-2.0이고 `pip install marimba-audio`로 설치해요.

### 사용 방식

- 마지막 **8초**만 채점해요. 파일은 모노·16kHz로 바꾸고 짧으면 앞을 채워요.
- 질문 유형: `noul`(예/아니오), `score`(확률), `choice`(보기 중 선택).
- 지원하지 않는 작업은 흉내 낸 답이 아니라 예측 없음으로 돌려줘요. 단어 점수는 보정되지 않았고 실시간을 보장하지 않는다고 밝혀요.

개인정보 탐지는 실험 단계로, 사용자가 텍스트 PII 탐지기를 따로 붙여야 해요. NVIDIA L4 한 장에서 질문당 p95 지연은 차례 끝 13ms, 음성 활동 16ms, 언어 161ms, 단어 2.35초예요.

### 동작 방식

차례 끝과 화자 질문은 고정된 인코더 층 위의 선형·소형 MLP 판독기, 음성 활동은 질문 조건부 소형 헤드, 언어는 Qwen3-ASR 자체 점수, 단어는 greedy와 빔 4개 가설에서 정확히 일치하는 비율을 써요. 화자 질문은 구간 단위 판단일 뿐 사람을 식별하거나 화자 분리 타임라인을 만들지 않아요. 논문은 이번 주 arXiv에 올릴 예정이라고 해요.
