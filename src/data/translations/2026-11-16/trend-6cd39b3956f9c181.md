### 무엇인가

**Tabler Icons**는 웹 프로젝트용 **무료 MIT 라이선스 고품질 SVG 아이콘 6,545개** 모음이에요. 모든 아이콘은 **24x24 그리드, 2px 선**으로 디자인됐어요. 전체 문서는 tabler.io/docs/icons에 있어요.

### 패키지 구성

포맷과 프레임워크별 공식 패키지를 이 저장소에서 npm으로 배포하고, **모두 같은 버전 번호**를 써요. 원본 SVG(외곽선·채움)와 메타데이터, 스프라이트, 웹폰트, 그리고 각 프레임워크용 컴포넌트 패키지가 있어요. GitHub 릴리스에서 직접 내려받을 수도 있어요.

### 쓰는 법

- **SVG 그대로**: `<img>` 소스, CSS 배경 이미지, HTML 인라인으로 쓸 수 있어요. 인라인 아이콘은 `currentColor`를 상속해 CSS로 크기, 색, 선 굵기를 바꿀 수 있어요.
- **스프라이트**: `@tabler/icons-sprite`를 설치하고 `tabler-` 접두사로 아이콘을 참조해요. 채움 아이콘용, 선 굵기 고정이 없는 버전도 함께 들어 있어요.
- **웹폰트**: `@tabler/icons-webfont`의 스타일시트를 넣고 `ti ti-{이름}` 클래스로 써요. 압축본과 SCSS 소스도 있어요.

### 프레임워크

- **React**: `@tabler/icons-react`는 ES 모듈이라 안 쓰는 아이콘은 트리 셰이킹되고, `size`, `color`, `stroke` 같은 props와 자체 TypeScript 선언을 제공해요.
- 같은 API로 **Preact, SolidJS, React Native** 패키지가 있어요.
- **Vue**, **Svelte**(4 이하용과 Svelte 5 runes용 별도), **Astro**, **Angular**(독립 컴포넌트와 `provideTablerIcons()` 등록) 패키지도 있어요.

### CDN

모든 패키지는 jsDelivr로도 쓸 수 있고, `latest` 대신 특정 버전 번호를 넣어 고정할 수 있어요.
