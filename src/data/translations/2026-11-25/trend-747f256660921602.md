### Windmill이란

Windmill은 워크플로, 앱, AI 에이전트를 위한 오픈소스·셀프호스팅 가능한 코드 우선(code-first) 플랫폼이에요. 엔지니어는 20개 넘는 언어로 코드를 쓰고 Git과 동기화하고, 비즈니스 팀은 같은 플랫폼에서 AI로 만들어요. 리뷰, 환경 간 승격, 격리된 워커 덕분에 무엇이 배포될지는 엔지니어가 통제해요. Lovable, Retool, n8n, 그리고 단순화한 Temporal의 셀프호스팅 대안을 내세워요. 스크립트는 공유 가능한 UI, API, 크론 잡으로 자동 변환되고 플로우, 데이터 파이프라인, AI 에이전트, React·Svelte 앱으로 조합할 수 있어요.

### AI로 만들고 리뷰를 거쳐 배포

- AI 세션은 워크스페이스 포크에서 스크립트·플로우·앱을 만들고, 배포 전 라이브 미리보기와 diff를 보여줘요.
- 워크스페이스 역할로 팀별 작성 권한을, 폴더로 AI가 닿을 수 있는 리소스·스킬·MCP 서버를 제한해요.
- 보호 규칙은 직접 배포를 막아 엔지니어 리뷰 뒤에만 프로덕션에 반영되게 해요.
- 개발 워크스페이스는 자체 자격 증명을 갖고 Compare & Deploy나 Git PR로 프로덕션에 승격돼요.
- 워커 그룹으로 AI가 만든 코드를 별도 워커나 별도 인스턴스에서 돌릴 수 있어요.

### 핵심 개념과 데이터

Python·TypeScript·Go·Bash로 작은 스크립트를 쓰면 파라미터가 자동으로 프론트엔드가 되고, 이를 플로우로 엮고 그 위에 UI를 올려요. 스케줄, 웹훅, HTTP 라우트, Kafka, WebSocket, 이메일 등으로 실행할 수 있어요. 데이터 쪽으로는 워크스페이스별 관리형 Postgres 테이블(data tables), S3·Azure Blob 파일과 여러 DB를 SQL로 조회하는 DuckDB 스크립트, 대용량 레이크하우스 테이블인 DuckLake, 알파 단계인 Pipelines를 제공하고, 기존 dbt 프로젝트도 그대로 돌릴 수 있어요.

### 개발 도구와 스택

- CLI(`wmill init`은 Claude Code·Cursor용 에이전트 지침과 스킬을 생성), VS Code 확장, 양방향 Git 동기화, MCP 서버를 제공해요.
- Postgres DB, Rust 백엔드, Svelte 5 프론트엔드, nsjail·PID 네임스페이스 샌드박싱을 써요. TypeScript는 기본 Bun, Python은 uv로 실행해요.

### 성능과 보안

Airflow, Prefect, Temporal과 가벼운 작업 40개·긴 작업 10개 플로우로 벤치마크해 둘 다 가장 빨랐다고 해요. 큐 대기·시작·결과 기록 오버헤드는 약 50ms이고, 가벼운 Deno 잡은 총 100ms 안팎이에요. 워크스페이스마다 별도 암호화 키로 비밀 값을 저장해요.

### 셀프호스팅과 라이선스

Docker Compose(파일 3개 받아 `docker compose up -d`), Helm 차트, AWS·GCP·Azure 등 여러 클라우드에 올릴 수 있고, vCPU당 워커 1개·RAM 1~2GB를 권장해요. Community Edition은 내부 사용이 무료지만 재판매·관리형 서비스·제품 기능으로 노출하려면 상용 라이선스가 필요해요. enterprise 플래그 없는 빌드는 AGPLv3, API 클라이언트와 OpenAPI 스펙은 Apache 2.0이에요. 외부 기여는 현재 받지 않지만 작은 검증된 버그 수정 PR은 받아요.
