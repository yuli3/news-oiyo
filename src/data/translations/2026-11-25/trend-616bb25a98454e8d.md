### 논문 정보
- 제목은 "Solid-State Web Execution: Compiling Web Applications into Verified Operations for AI Agents"이고, 저자는 Protocolis의 Vahagn Boudakian이에요. 날짜는 2026년 11월 22일이며 arXiv(cs.AI) 공개 예정인 저자 사본이라고 표시돼 있어요.

### 문제와 접근
- 웹 에이전트는 보통 매 단계마다 언어 모델을 불러요. 페이지에서 무엇을 할 수 있는지 알아내기 위해, 그리고 행동이 성공했는지 확인하기 위해서예요.
- 저자는 이 두 호출을 모두 없애는 컴파일러를 제안해요. 페이지를 처음 만났을 때 페이지의 컨트롤을 타입이 지정된 작업(operation)으로 바꾸고, 모델이 그중 하나를 고르면 컴파일러가 실행한 뒤 페이지를 다시 읽어 무엇이 바뀌었는지 보고해요.
- 컴파일에는 모델 추론, 사이트별 코드, 사전 방문이 전혀 필요 없다고 해요. 저자는 실제로 동작하는 이런 컴파일러로는 처음이라고 주장해요.

### 평가와 주요 결과
- 널리 쓰이는 브라우저 도구·에이전트를 출시 상태 그대로 놓고, 세 가지 모델 크기와 세 가지 작업 길이에서 비교했어요. 메모리와 학습 기능은 껐어요.
- 모든 시스템이 시도한 긴 작업에서 기본 모드 완료율은 76%(105개 중 80개)로, 각 비교에서 가장 좋은 대안의 46%보다 높았다고 해요.
- 어떤 조건에서도 55% 아래로 떨어지지 않았고, 다른 대안은 모두 어느 조건에선가 28% 이하로 떨어졌다고 해요.
- 같은 모델에서 가장 저렴한 대안도 완료한 작업당 비용이 1.9~26배 더 들었어요.
- 작은 모델로 돌렸을 때도 프런티어 모델을 쓴 모든 대안보다 30개 짝 모두에서 저렴했고, 24개 짝에서는 완료율이 같거나 높았어요.
- 긴 작업을 끝냈다고 보고했을 때 판정자가 동의하지 않은 비율은 22%로, 대안의 56%보다 낮았어요.
- 모든 테스트는 이 설계에 가장 불리한 첫 방문 조건이었고, 집계된 실행은 3,443회예요. 작업, 판정 규칙, 모든 실행 결과를 공개하며 재현 키트도 링크돼 있다고 해요.

### 참고할 점
페이지는 판매사 사이트로, 기술이 특허 출원 중이며 유료 고객이 실제로 쓰고 있고 인수 제안도 받는다고 밝혀요. 결과는 자체 보고이고, 저자는 제품을 파는 회사 소속이에요.

원문 페이지에서는 초록과 핵심 결과만 읽을 수 있었고, 20쪽 분량의 PDF 본문(세부 방법, 과제·모델 목록, 한계)은 읽지 못해 이 범위를 기준으로 옮겼어요.
