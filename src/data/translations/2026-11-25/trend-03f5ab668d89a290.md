중국 Z.ai가 같은 신경망 레이어를 반복 실행하는 '루프 트랜스포머(Loop Transformer)' 구조의 플래그십 모델 'GLM-5.4'를 출시했어요. 오픈AI의 차세대 추론 기술로 주목받고 싱킹머신즈랩 공개 모델에도 적용된 방식으로, 매개변수를 늘리는 것과 함께 내부 연산 깊이를 높이는 경쟁이 이어지고 있어요.

### 성능 주장과 구조

Z.ai는 23일 공식 블로그에서 약 7500억 개 매개변수 규모의 GLM-5.4가 2조~3조 개 모델에 필적하는 성능을 낸다고 밝혔어요. 다만 자체 평가 결과만 제시했고 타사 모델과의 구체적인 비교 점수는 공개하지 않았어요.

루프 트랜스포머는 같은 가중치의 레이어를 여러 번 실행해 정보를 반복 처리해요. 모델 크기를 크게 키우지 않고 연산 깊이를 높일 수 있지만, 반복에 따른 추가 연산이 필요해요. GLM-5.4는 기존 GLM-5의 중간 레이어 28개를 두 번 실행해요.

### 오픈AI·싱킹머신즈랩 사례

- 지난 9월 오픈AI '아스트라'가 '순환 깊이(Recurrent Depth)' 기술을 쓴다는 보도로 이 접근법이 주목받았어요. 내부 추론 과정 감시가 어려워질 수 있다는 지적도 나왔고, 설계 정보 유출 의혹 조사 과정에서 안전 연구원 3명이 해고됐어요. 회사는 민감 정보 취급 규정 위반을 이유로 들었고, 연구원들은 유출원이라는 주장을 부인했어요.
- 싱킹머신즈랩은 20일 공개한 '잉클링 2 미니'에서 중간 레이어를 토큰마다 세 번 실행하도록 설계했어요. GLM-5.4는 이 방식을 대형 플래그십 모델에 적용한 사례예요.

### 학습과 최적화

- 처음부터 루프형으로 학습하면 같은 연산량의 일반 모델보다 성능이 떨어지는 문제를 피하려고, 사전 학습을 마친 GLM-5를 추가 학습해 루프 구조로 바꿨어요.
- 활성화 값이 지나치게 커지지 않도록 토큰별 독립 게이트를 넣었어요.
- 두 번째 루프에서 첫 연산의 희소 어텐션 인덱스와 KV 캐시를 재사용하고, 최근 구간만 처리하는 로컬 슬라이딩 윈도우를 따로 유지해 100만 토큰 규모 문맥에서도 추가 비용을 억제했어요.
- 커널 융합 등으로 비혼잡 시간대 초당 최대 200토큰, 혼잡 시간대 초당 70~80토큰의 생성 속도를 확보했다고 밝혔어요.

### 실험 결과

300억 개 매개변수 실험 모델에서 학습 연산량을 약 10% 늘렸을 때 수학·과학 추론과 긴 문맥 처리 성능이 좋아졌어요. 'GPQA-다이아몬드', 'MMLU-프로' 등 일부 평가에서는 평균 출력 길이가 10~14% 줄었는데, 추론 일부가 출력 토큰에서 내부 반복 연산으로 옮겨갔기 때문이라고 설명했어요.

### 방향과 한계, 제공 계획

Z.ai는 코드를 작성해 영상·게임을 만들고 3D 모델링과 기계 설계까지 하는 '일반화된 코딩'을 주요 방향으로 제시했어요. 모델이 장시간 자기 검토를 반복하는 '마라톤식 사고' 경향은 인정했지만, 재검토가 정확도 향상에 기여한다고 했어요. GLM-5.4는 GLM 코딩 플랜, ZCode, Z.ai 챗에서 쓸 수 있고, API와 가중치는 안전성 평가·강화 작업 이후 공개할 예정이에요.
