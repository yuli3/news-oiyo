'AI 에이전트가 사람 대신 클라우드를 직접 쓰는 시대'가 열리면서 클라우드 인프라 경쟁의 축이 GPU에서 CPU로 넓어지고 있어요. 아마존웹서비스(AWS)도 자체 CPU를 앞세워 에이전트 전용 인프라를 강화하고 있어요.

### "에이전트 작업의 80%는 CPU가 처리"

윤석찬 AWS코리아 수석 테크 에반젤리스트는 24일 열린 'AWS 리인벤트(re:Invent) 2026 미디어 브리핑'에서 2029년까지 AI 에이전트가 10억 개 이상 배포될 것이라고 전망하며 에이전트 중심 클라우드 전략을 소개했어요.

에이전트는 AI 모델 추론보다 API 호출, 코드 실행, 데이터 저장 같은 도구 작업에 훨씬 많은 연산 자원을 써요. 윤 에반젤리스트는 에이전트가 모델에 추론을 요청하는 건 한두 번뿐이고 나머지는 도구 작업이라며, 에이전트 작업의 80%를 CPU가 처리한다고 설명했어요.

### 자체 칩과 대형 계약

- 자체 CPU '그래비톤'은 가격 대비 성능이 40% 높고, AI 학습·추론 칩 '트레이니움'은 최대 30~40% 높다고 AWS는 밝혔어요. AWS 상위 1000개 고객사의 90% 이상이 그래비톤을 쓰고 있어요.
- 앤트로픽은 트레이니움과 그래비톤 기반 5GW 규모의 컴퓨팅 용량을 확보했어요.
- 오픈AI는 엔비디아 GPU와 트레이니움을 포함해 1380억 달러 규모의 컴퓨팅 사용을 확약했어요.

### 인프라 투자와 AI 팩토리

AWS는 컴퓨팅 자원에 전용 네트워크와 스토리지를 결합한 'AWS AI 팩토리'를 정식 출시했어요. 고객은 베드록, 세이지메이커 같은 AWS AI 서비스를 그대로 쓸 수 있어요. AWS는 올해 AI 인프라에 2000억 달러(약 290조원)를 투자했고, 2028년까지 엔비디아 GPU를 300만 개 이상 확보할 계획이에요.

### 데이터·보안·에이전트 서비스

- 에이전트는 같은 데이터를 수백 번씩 질의하므로 저장 단계부터 분석·검색에 맞는 구조가 필요하다고 AWS는 설명했어요. 기업 데이터를 지식 그래프로 연결해 에이전트에 맥락을 주는 'AWS 컨텍스트'를 출시할 예정이고, 오픈소스 분석 DB '덕DB'를 운영하는 덕랩스도 인수했어요.
- 보안 칩 '니트로' 기반 '니트로 샌드박스'와 '람다 마이크로VM'을 출시했어요. 에이전트와 AI가 만든 코드를 각각 독립된 가상머신에서 격리 실행해 허용 범위를 벗어나지 못하게 해요.
- 오픈AI와 함께 개발 중인 '아마존 베드록 매니지드 에이전트'도 공개했어요. 오픈AI 모델 기반 에이전트가 '베드록 에이전트코어'에서 운영되도록 할 계획이에요.

AWS는 30일부터 다음 달 4일까지 미국 라스베이거스에서 열리는 'AWS 리인벤트 2026'에서 에이전트 관련 신규 서비스를 대거 공개할 예정이에요.
