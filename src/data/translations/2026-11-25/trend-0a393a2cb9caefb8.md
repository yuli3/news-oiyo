### 무엇인가요

Loupist는 맥에서 돌아가는 로컬 우선(local-first) 데스크톱 금융 리서치 앱이에요. 사용자가 팔로우하는 자산을 지켜보면서 리서치 과정을 기록하고, 변화가 생기면 근거와 함께 설명해 줘요. 다만 주문을 직접 실행하지는 않아요.

### 데이터와 저장 방식

Loupist 하나는 맥의 폴더 하나예요. 그 안에 파일, Chats, Memory, 보관한 출처가 들어 있어서 폴더를 복사하거나 옮기면 그대로 따라와요. 계정도 없고 동기화도 없어요. 모델은 지원되는 공급자의 API 키나 계정 로그인으로 연결해 써요.

### 주요 기능

- **이어지는 학습**: 사용자가 저장한 원칙을 이후 대화에 적용하고, 반복해서 나타난 근거에서 재사용 가능한 리서치 방법론을 만들어요.
- **데이터 소스**: SEC EDGAR, FRED, 시장 데이터와 설정한 벤더, 그리고 OpenDART, World Bank, KRX, 한국투자 카탈로그를 써요. 자격 증명은 기기 안에만 남아요.
- **로컬 계산**: 셸과 네트워크 접근이 없는 샌드박스 Python 런타임에서 수치 코드를 실행해요.
- **인터페이스**: Chat, Map, Lens, Schedule과 Settings로 구성돼 있고, 브리핑과 예약 프롬프트는 앱이 열려 있는 동안 실행돼요.

### 메모리 구조

메모리는 네 종류예요. Source는 보관한 자료와 실제로 사용한 구절, World는 출처로 뒷받침되는 개체·사건·관계, Lens는 리서치 방법론과 원칙 그리고 그 수정 이력, Note/Journal은 작업 메모와 사용자의 판단을 날짜와 결과까지 함께 담아요. 'Private chat' 스위치를 켜면 그 대화에서는 메모리를 읽지도 쓰지도 않아요.

### 설치와 요구 사항

현재는 Apple Silicon 맥의 macOS 13 이상만 지원하고, 윈도우·인텔 맥·리눅스는 지원하지 않아요. 서명된 설치 파일은 GitHub Releases로 제공할 계획이고, 그전까지는 개발 환경으로 실행해야 해요. 개발 환경 요구 사항은 Node.js 26.13 이상 LTS, uv를 쓰는 Python 3.12, Rust(CI는 1.97.1로 고정)예요.

### 보안 모델과 라이선스

React 인터페이스는 파일 시스템·프로세스·자격 증명에 직접 접근하지 않고 타입이 정해진 요청만 보내요. 격리와 저장, 메모리 쓰기는 Rust 백엔드가 통제하고, 파일 도구는 허용된 경로로 제한돼요. 라이선스는 AGPL-3.0-only이고, LICENSING.md가 앱 코드와 기여, 공유 팩, 공급자 데이터, 갤러리 약관을 다뤄요.

> Loupist는 AI 리서치 동반자이고 면허를 가진 금융 자문가가 아니며, 물어보면 견해를 말할 수 있지만 거래를 실행하지는 않는다고 저장소가 밝혀 놨어요.

이 글은 정보 제공용이며 투자 권유가 아니에요. 투자 판단과 책임은 본인에게 있어요. 수치는 지연·종가 기준이며 정확성을 보장하지 않아요.
