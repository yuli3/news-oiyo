앤트로픽이 AI가 작성한 코드를 검토하고 수정하는 데서 나아가, 팀 규칙에 따라 승인 여부까지 판단하는 개발 자동화 도구를 내놨어요. 코드 생성 이후 검토와 승인에 걸리는 시간을 줄여 개발 속도를 높이겠다는 전략이에요.

### 클로드 십 베타 출시

앤트로픽은 23일(현지시간) '클로드 십(Claude Ship)'을 베타 버전으로 출시했다고 밝혔어요. 코드 변경 반영을 요청하는 풀 리퀘스트(PR)를 대상으로, 기존 '코드 리뷰(Code Review)'에 수정 도구 'PR 스튜어드(PR Steward)'와 승인 도구 '클로드 어프루벌스(Claude Approvals)'를 연결한 구성이에요.

### 세 가지 구성 요소

- **코드 리뷰**: 변경 사항과 주변 코드를 분석해 문제를 찾고, 검증한 지적을 PR에 남겨요.
- **PR 스튜어드**: 자동 검사(CI) 실패, 코드 충돌, 사람이나 리뷰 도구의 수정 요청에 대응해요. 수정할 때마다 변경 내용과 되돌리는 방법을 설명하고, 개발자는 '@claude'로 작업 방향을 지시하거나 '@claude stop'으로 중단을 요청할 수 있어요. PR을 승인하거나 병합하지는 않도록 설계됐어요.
- **클로드 어프루벌스**: 저장소에 작성한 승인 정책을 적용해요. 팀이 허용한 일상적인 변경은 클로드가 승인하고, 별도 검토가 필요한 작업은 사람의 승인을 요구하도록 설정할 수 있어요.

### 사용 방식

개발자는 클로드 코드의 '/ship' 명령으로 개별 변경 사항을 올리고 검토·수정을 진행할 수 있어요. 관리자가 저장소 전체에 기능을 켜면 팀의 PR에도 자동으로 작동해요. 회사는 클로드 코드 팀에서 대부분의 코드를 클로드가 작성하고 있으며, PR을 올린 이후 작업도 같은 속도로 진행하는 것이 목표라고 설명했어요.

### 병합과 운영 권장 사항

실제 병합은 깃허브의 브랜치 보호 규칙과 필수 검사 설정에 따라 결정돼요. 사람 승인을 요구하지 않는 정책과 깃허브 자동 병합이나 병합 대기열을 함께 쓰면 사람 개입 없이 병합될 수도 있어요. 앤트로픽은 처음에는 승인 정책의 판단 결과만 확인하는 관찰 모드로 운영하라고 권했어요. 관리자는 적용 저장소, 검토 수준, 실행 시점, 비용 한도를 정할 수 있어요.

### 제공 범위와 비용

- 깃허브 저장소를 쓰는 클로드 팀·엔터프라이즈 조직에 제공돼요. 코드 리뷰는 정식 제공, PR 스튜어드와 클로드 어프루벌스는 공개 베타예요.
- 에이전트 사용료는 구독 포함 사용량과 별도로 토큰 사용량에 따라 청구되고, 승인 정책 분류 모델 실행과 코드 리뷰에도 비용이 들어요.
- 데이터 보관 제로(ZDR), HIPAA 대응 설정, 고객 관리 암호화 키를 쓰는 조직에는 제공되지 않아요.
