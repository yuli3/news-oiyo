### 무엇인가요

CDX Agent Dock v2.1.0은 Cantor Labs가 만든 엔터프라이즈 멀티 에이전트 미들웨어예요. LangChain, CrewAI, AutoGen, 그리고 SKILL.md 기반 Hermes 에이전트를 코드 재작성 없이 한 줄 래퍼로 연결하는 것이 목표라고 해요. 긴 추론 작업의 안정성, 온프레미스 비밀정보 핀닝(BYOS), 토큰 절감을 함께 내세우고 있어요.

### 설치

- `pip install cdx-dock`
- `docker pull cdxno1/cdx-a2a-sidecar:2.1.0`
- 사이드카는 8080 포트로 띄운 뒤 `OPENAI_BASE_URL="http://localhost:8080/v1"`로 지정해요.
- 요구 사항은 Python 3.10 이상, numpy 1.24.0 이상이에요.

### 기본 엔진 네 가지

- **Universal Protocol Adapter / CDXHermesDock**: `as_crewai_tool`, `as_langchain_tool`, `as_autogen_agent`, `bridge`를 연결하고 SKILL.md 절차 중 Top-K를 골라요.
- **DockSlimmer + CDX-Tab**: 모드 A↔B 무손실 압축이고, 균일한 JSON 테이블에는 컬럼 코덱을 적용해 54.7~66% 압축을 주장해요.
- **CDXArbiter**: LLM을 쓰지 않는 인메모리 다국어(EN, KO, JA, ES, DE, FR) 도구 라우터로 1.3ms 미만을 주장해요.
- **Polyglot Docker Sidecar**: `X-CDX-Slimmer`, `X-CDX-Top-K`, `X-CDX-Pins` 헤더로 제어하는 HTTP 리버스 프록시예요.

### 애드온 모듈

CDXCloak는 `pin_secret()`으로 특정 비밀정보를 로컬 SQLite3/JSON 금고에 고정하고 외부 유출 0바이트를 주장해요. CDX-CoT-Guard는 추론 모델의 반복되는 `<think>` 루프를 끊고 KV 캐시 VRAM을 약 75% 줄인다고 해요. CDX-TokenPack-10K는 외부 벡터 DB 없이 로컬 폴더(`pack_dir`)로 1만 토큰 다국어 컨텍스트를 공유해요. v2.1 신규인 VaultPack-2K는 AES-256-GCM과 AAD, CVV/CVC 소각, 1비트 RBAC를 쓰는 별도 금고로 Growth 플랜 이상에 포함돼요.

### 성능과 가격

자체 내부 벤치마크 기준으로 어댑터는 P50 약 1.2ms, Slimmer는 약 0.59ms에 페이로드 40~55% 감소, Arbiter는 스키마 85~93% 감소, CoT-Guard는 약 0.12ms에 추론 토큰 40~60% 감소, CDXCloak 언마스크는 약 0.04ms라고 적어 놨어요. 월 요금은 30일 샌드박스 $0(150K 스텝), Starter $390, Growth $1,490, Scale $4,900, Enterprise $14,900이고 온프레미스는 별도 협의예요. 지출 상한이 기본으로 켜져 있고 쿼터를 다 쓰면 패스스루로 넘어간다고 해요.

> 모든 절감·지연 수치는 자체 측정값이고 워크로드·하드웨어·프레임워크·상위 LLM에 따라 달라지며, 페이지는 수치를 법적으로 보증하지 않는다고 밝혔어요.

카드 온라인 결제는 아직 열리지 않았고 통신판매업 신고가 진행 중이라고 해요. 에어갭 배포용 오프라인 라이선스는 `CDX-AG-V1`이에요.
