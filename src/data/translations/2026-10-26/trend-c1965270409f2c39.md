### 한 줄 요약

**Gopeed**(Go Speed의 줄임말)는 **Go와 Flutter**로 만든 빠르고 현대적인 **무료 오픈소스 다운로드 매니저**예요. HTTP, HTTPS, BitTorrent, 마그넷 링크, ed2k를 **데스크톱·모바일·웹**에서 지원해요.

### 주요 기능

| 영역 | 내용 |
|---|---|
| 속도 | 동시 작업, HTTP 다중 연결, P2P BitTorrent로 대역폭을 최대한 활용 |
| 프로토콜 | HTTP/HTTPS 파일, 토렌트, 마그넷, ed2k를 한 앱에서 |
| BitTorrent | DHT 피어 탐색, uTP, 웹 시드, 선택 다운로드, 트래커 관리, 비율·시간 기반 시딩 제한 |
| 작업 관리 | 일시정지·재개·재시도, 일괄 작업, 검색, 상태 필터, 카테고리, 재시작 후 복구 |
| 가벼움 | Flutter 네이티브 렌더링, **Electron·WebView 없음** |
| 플랫폼 | Windows, macOS, Linux, Android, iOS, 웹, Docker·QNAP 배포 |
| 외관 | 시스템 테마·라이트·다크, 강조색 8가지, 반응형 화면 |
| 언어 | 한국어를 포함한 20개 이상 |

### 확장과 자동화

- **브라우저 연동**: Chrome, Edge, Firefox 등에서 다운로드를 Gopeed로 바로 보내요.
- **JavaScript 확장**: 동영상 플랫폼, AI 모델 허브, 클라우드 스토리지 같은 다운로드 소스를 추가해요.
- **AI 연동**: Gopeed의 **MCP 엔드포인트**로 AI 에이전트를 연결해 자연어로 다운로드를 만들고 관리해요. 예를 들어 "Windows용 최신 Gopeed 클라이언트를 받아 줘"라고 말하면 돼요. URL을 먼저 해석해 메타데이터와 파일 목록을 확인하고, 작업을 만들고, 목록을 보는 도구가 있어요.
- **자동화**: REST API, CLI, 인증된 웹 UI, 웹훅, 다운로드 후 스크립트를 지원해요.
- **기본 도구**: 헤더·User-Agent 설정, 프록시, GitHub 미러, 알림, 압축 자동 해제.

### 이런 분께

Electron 기반 앱이 무겁게 느껴지고, 여러 기기에서 같은 다운로드 도구를 쓰거나 에이전트로 다운로드를 자동화하고 싶은 분께 맞아요. 저작권이 있는 콘텐츠는 권리를 확인하고 받아야 해요.
