### 한 줄 요약

**Dagger**는 소프트웨어 배포를 자동화하는 플랫폼이에요. 어떤 코드베이스든 **빌드·테스트·배포**를 안정적으로, 대규모로 해 줘요. 설치는 `brew install dagger/tap/dagger`예요.

### 네 가지 약속

| 키워드 | 의미 |
|---|---|
| 프로그래머블 | 셸 스크립트와 독자 YAML 대신 실행 엔진·시스템 API, 8개 언어 SDK, 대화형 REPL, 재사용 모듈 생태계 |
| 로컬 우선 | 한 번 자동화하면 노트북, AI 샌드박스, CI 서버, 클라우드 어디서든 똑같이 실행. 의존성은 Docker 같은 컨테이너 런타임뿐 |
| 반복 가능 | 도구는 컨테이너에서, 샌드박스 함수가 오케스트레이션. 호스트 의존성은 명시적이고 엄격한 타입 |
| 관측 가능 | 모든 작업이 OpenTelemetry 추적을 남겨 터미널이나 웹에서 바로 확인 |

### 세부 기능

- **시스템 API**: 컨테이너, 파일시스템, 시크릿, git 저장소, 네트워크 터널을 언어와 상관없이 다루는 타입 있는 API예요.
- **8개 언어 SDK**: Go, Python, TypeScript, PHP, Java, .NET, Elixir, Rust. API 스키마에서 생성돼 타입 안전성과 에디터 지원을 줘요.
- **타입 있는 아티팩트**: 상태와 함수를 가진 사용자 정의 타입을 만들고, 직렬화 없이 언어·모듈 경계를 넘겨요.
- **증분 실행**: 모든 작업이 입력값으로 키가 잡혀서, 파일 하나를 바꾸면 영향받는 작업만 다시 돌아요. 캐시는 콘텐츠 주소 기반이라 로컬과 CI에서 자동으로 공유돼요.
- **어디서나 실행**: Linux 컨테이너 런타임만 있으면 되고, macOS·Windows는 Docker Desktop 등으로 돌아요. 로컬과 CI 동작이 같아요.
- **내장 추적**: CLI에 실시간 TUI가 있고, Jaeger·Honeycomb 등 OTel 호환 백엔드로 내보낼 수 있어요.

### 이런 분께

CI 설정이 YAML 덩어리가 돼서 로컬에서 재현하기 어렵거나, AI 에이전트 샌드박스에서도 같은 빌드를 돌리고 싶은 팀에 맞아요.
