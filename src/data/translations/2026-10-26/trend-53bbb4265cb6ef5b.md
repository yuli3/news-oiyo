### 텐센트 Hy-Nomas

텍스트 명령과 카메라 움직임에 맞춰 영상을 이어 만드는 **월드 모델**을 오픈소스로 공개했어요. 생성 도중 사물을 더하거나 인물 행동, 배경, 화풍을 바꿀 수 있고 카메라 시점과 경로도 지정해요. 앞 장면 정보를 다음 구간에 쓰는 **월드 메모리**가 있고, 로봇 같은 분야용 경량 LoRA 적응도 지원해요. 가중치와 실행 코드를 주고, **RTX 4090 한 장**용 저메모리 설정도 있어요.

### 블록 데사

잭 도시가 이끄는 블록이 소개했어요. 텍스트 데이터나 사전 학습 모델 없이 **처음부터 사람 대화를 듣는 방식**으로 실시간 대화를 익혔대요. 사람 음성만으로 학습해 자연스러운 실시간 대화가 되는 첫 AI라고 주장해요.

### IBM Granite Speech 5.0 2B

20억 매개변수 소형 모델로 영어, 프랑스어, 독일어, 스페인어, 포르투갈어, 일본어 음성을 처리해요. 크기는 그대로 두고 소음·울림 환경 인식과 긴 음성·대화 번역을 개선했어요. 제품명·전문용어용 키워드를 **최대 2,000개** 지정할 수 있고 Apache 2.0이에요.

### 앤트그룹 Ling-3.0-flash-Sante

앤트그룹 인클루전AI가 가중치를 공개한 의료 특화 모델이에요. 전체 **1,240억 매개변수 중 토큰당 51억 개**를 활성화하고, 최대 **25만 6천 토큰**을 처리해요. 도구 활용과 다중 에이전트 협업도 지원해요. 개발팀은 진단·처방용 의료기기가 아닌 **연구용 모델**이라고 밝혔어요.

### 퍼플렉시티 Decider for Mac

40억 매개변수 의사결정 모델 `pplx-decider-flash-v1.2`를 맥에서 직접 돌려요. 텍스트와 이미지를 읽고 분류·선택에 필요한 **확률**을 돌려줘, 고객 문의 배정이나 문서·스크린샷 분류에 쓸 수 있어요. 자료를 외부로 보내지 않고 API 키·요금도 필요 없어요. Apple Silicon 맥, 메모리 16GB 이상이 필요하고 처음 실행할 때 5.8GB 모델을 받아요.

### 베이스랩스 매머드-1·엘리펀트-1

베이스텐 산하 베이스랩스의 의사결정 특화 모델로 각각 270억, 90억 매개변수예요. 상황과 질문을 읽고 선택지별 확률을 내요. 개발팀에 따르면 매머드-1은 'Jev 디시전 인덱스 0.4'에서 **71.24점으로 208개 모델 중 1위**였어요. MIT 라이선스예요.

### PhoneUse

Claude Code, Codex, Cursor 등에 MCP나 API로 연결하면 에이전트가 휴대전화 화면을 읽고 터치·입력·스크롤해요. 클라우드 안드로이드와 실제 스마트폰을 제공하고, 실제 아이폰은 **카메라로 화면을 읽고 물리 스타일러스로 조작**하기도 해요.

### VAST EdenLive

게임 엔진의 단순한 화면, 원하는 첫 장면, 텍스트 지시를 넣으면 배치와 움직임을 따라 실사풍이나 다른 화풍 영상을 만들어요. **50억 매개변수 모델이 RTX 5090 한 장에서 720p 초당 24프레임 이상**이래요. 게임 규칙과 사물 위치는 기존 프로그램이 맡고 AI는 화면 표현만 맡아요. 50억·140억 모델 가중치를 함께 공개했어요.

### 카일론 Annotations

마음에 드는 참고 영상을 분석하고 주석으로 수정 방향을 더해 자사 제품에 맞는 새 영상으로 재구성하는 기능이에요. 새 모델 가중치 공개가 아니라 영상 분석과 협업을 묶은 제작 기능이에요.
