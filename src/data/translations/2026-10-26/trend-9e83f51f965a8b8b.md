> GitHub README의 앞부분(기능, 설치, 권한과 동작 설명 일부)을 읽고 옮겼어요. 덮개 동작 세부와 그 뒤 내용은 읽지 못했어요.

### 만든 이유(GeekNews 글)

작성자는 맥에서 오래 걸리는 작업을 돌릴 때 쓰려고 만들었대요. Codex처럼 작업 중 잠자기를 막는 도구도 있지만 모든 AI 도구가 그렇진 않고, `caffeinate`도 있지만 작업은 계속 돌리면서 **화면만 끄거나 잠금까지** 하고 싶었대요.

### 기능

- 전역 `pmset disablesleep` 설정을 바꾸고 **실제 값을 다시 읽어** 보여 줘요. 다른 도구가 바꿔도 자동 반영돼요.
- **화면 끄기**(내장 디스플레이 하드웨어 밝기 0)와 **잠금 후 화면 끄기**(세션 잠금 요청 → 디스플레이 잠자기)를 제공해요.
- 잠자기 방지 중 **덮개가 닫히면** 선택한 동작(화면 끄기, 잠금+화면 끄기)을 할 수 있어요.
- Dock과 메뉴 막대에 있고, 창을 닫아도 앱은 돌아가요. 종료해도 전역 전원 설정은 그대로예요.
- 영어·한국어를 즉시 전환하고, 시스템 라이트/다크 모드를 따라요.
- **계정, 분석, 네트워크 접근, 서드파티 런타임 의존성이 없어요.**

### 설치

- macOS 14 이상, **Apple Silicon(M 시리즈)** 맥용 ZIP을 받아 Applications에 끌어 넣으면 돼요. Intel 바이너리는 없어요.
- **ad-hoc 서명**이라 Developer ID 서명·Apple 공증이 없어 첫 실행이 막힐 수 있어요. 릴리스에 SHA-256 체크섬이 있어요.
- 잠금 기능에는 손쉬운 사용(Accessibility) 권한이 필요하고, 잠자기 방지 변경에는 관리자 인증을 요청할 수 있어요.
- 소스 빌드는 Xcode와 Swift 6 툴체인이 필요하고, `--diagnose` 옵션으로 진단할 수 있어요.

### 동작을 정확히 밝힌 부분

- **잠자기 방지**는 임시 assertion이 아니라 시스템 전체에 남는 `pmset -a disablesleep 1/0` 설정이에요. 비밀번호를 저장하거나 sudoers를 고치지 않고, 끈다고 다른 앱의 assertion이나 유휴 타이머가 바뀌진 않아요.
- **화면 끄기**는 내장 디스플레이의 실제 밝기를 저장하고 0으로 만들어요. 감마 변경이나 검은 창이 아니에요. 포인터를 움직이면 복원되고, 비정상 종료 뒤 재실행하면 복구해요. 외장 모니터는 아직 지원하지 않아요. Apple Silicon에서는 문서화되지 않은 DisplayServices 함수를 써서 macOS 업데이트로 바뀔 수 있대요.
- **잠금+화면 끄기**는 표준 Control–Command–Q 단축키를 보내고 1.5초 뒤 화면 끄기를 요청해요. 단축키를 보냈다고 잠금이 확인된 건 아니라서, 앱은 '잠갔다'고 단정하지 않고 '요청했다'고 표시해요. 비공개 잠금 API는 쓰지 않아요.
