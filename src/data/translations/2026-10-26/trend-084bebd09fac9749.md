> David Lequin의 블로그 글을 거의 끝까지 읽었고, 마지막 'Claude Dashboards' 절은 앞부분만 읽었어요.

### 배경

직원 약 500명 회사에서 Looker에 연 약 **15만 달러**(약 300석)를 낸대요. 데이터 플랫폼 엔지니어는 3명이고, Snowflake, 모델 2,000개가 넘는 dbt, Airflow·Airbyte·DataHub·Kubernetes 관리에 대부분 시간을 써요.

1년 전엔 'chat with your data' 데모가 작은 스키마에선 멋져 보였지만 실제 규모에선 SQL은 돌아도 **숫자가 틀렸대요.** 그런데 1월 Opus 4.5의 Claude Code가 저장소에서 일하고 쿼리를 돌려 숫자를 확인할 수 있게 되자, 재무·운영·마케팅 사람들까지 하루 종일 프롬프트를 쓰게 됐어요. Claude는 차트가 든 **HTML 파일 하나**를 자주 내놨는데, 이게 Downloads 폴더에 묻히거나 Slack 첨부로만 돌았대요.

### 오후 하나로 만든 호스팅

팀원 Maddy가 하루 만에 S3 저장 + SSO + 테스트를 갖춘 작은 서비스를 바이브코딩했어요. Claude 플러그인 속 스크립트가 HTML을 올리면 사내 누구나 링크로 열 수 있었어요. 3월에 보는 사람의 **Snowflake OAuth 토큰**으로 도는 라이브 쿼리 API를 붙인 게 "올해 최고의 결정"이었대요. Snowflake에 이미 있는 역할 권한이 그대로 대시보드 권한이 됐거든요.

사람들이 좋아한 이유는 BI 업계로선 민망하게도 **대시보드가 예뻤기 때문**이래요. 주간 사용자는 3월 23명에서 6월 136명으로 늘었어요. 다만 보안은 "정말 나빴대요." 대시보드 JavaScript가 세션과 같은 origin에서 돌아 사실상 **거대한 XSS 구멍**이었어요.

### 제대로 다시 만들기: 네 가지 문제

1. **스크립트 대신 커넥터 하나.** 회사 전체용 원격 **MCP 커넥터**로 claude.ai, Claude Code, Slack의 Claude, 사내 분석 에이전트가 같은 도구를 써요. AI가 올린 건 초안이 되고 사람이 Publish를 눌러야 해요.
2. **모든 대시보드를 적대적이라고 가정.** 리뷰 없이 아무 HTML이나 올리는 게 제품이라 XSS를 막을 수는 없고, 대신 닿을 곳을 없앴어요. 대시보드마다 쿠키 없는 별도 origin의 **샌드박스 iframe**과 엄격한 CSP를 쓰고, 부모 페이지와 `postMessage`로만 통신해요. 콘텐츠 토큰은 1시간, 대시보드·사용자·호스트 하나에만 유효해요. 별도 메타데이터 서비스가 새 버전을 비동기로 읽어, 처음 보는 패키지 스크립트나 WebRTC 연결이 있으면 차단해요.
3. **신원과 권한은 Snowflake에.** 모든 쿼리가 보는 사람의 토큰으로 돌아, 대시보드를 공유해도 데이터 권한은 공유되지 않아요.
4. **콘텐츠 관리.** Google Drive를 흉내 내 일주일 만에 만들었대요.

### 비용 계산

- **커밋 325개, 코드 약 7만 4천 줄(테스트 2만 줄), Claude 토큰 약 6.4천 달러**, AWS 1.9천 달러. 3명이 8개월간 부업처럼 만들었고 코드는 대부분 Claude가 썼대요.
- 분석 에이전트 기준 대시보드 하나에 약 **100만 토큰**이 들고, Opus 5.5로 옮기자 비용이 약 2.5달러에서 **0.5달러**로 내려갔어요.
- 운영비는 AWS 연 약 6천 달러 + 기능 추가용 Claude 월 약 1.3천 달러, 대략 **연 2만 달러**예요.

Looker를 사면서 산 건 차트 UI, 권한 모델, 시맨틱 레이어, 호스팅 네 가지였는데, 차트는 Claude가, 권한은 Snowflake가, 시맨틱은 dbt가 하고 호스팅은 월 500달러래요. Looker 사용은 무너지기보다 **새어 나갔고**, 일부 팀은 여전히 Looker를 써요. 다만 가장 큰 비용인 엔지니어 시간은 셈에 넣지 못했고, 팀을 새로 뽑아야 한다면 계산이 달라진대요. 저자는 AWS·Snowflake처럼 규모의 이점이 있는 제품은 다르지만, 대시보드 제작이 가치의 대부분인 BI는 특히 흔들린다고 봐요. Anthropic이 10월 8일 베타로 낸 Claude Dashboards는 8개월 전 시작한 자신들에겐 기다릴 선택지가 아니었대요.
