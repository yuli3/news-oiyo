> Corgi 공식 페이지는 짧은 문구와 데모 위주라, 페이지 문구를 옮기고 기능 세부는 GeekNews 소개글로 보탰어요.

### 공식 페이지가 내세우는 것

- "모든 에이전트, 각자 무엇을 하는지, 누가 당신을 기다리는지."
- **Ctrl-T**로 새 작업이든 옛 작업이든 바로 들어가요.
- **이미 쓰는 계정을 모두** 그대로 써요.
- 에이전트에 마우스를 올리면 무엇을 했는지 보여요.
- tmux처럼 에이전트와 프로세스가 **백그라운드에서 계속** 돌아가요.
- 에이전트가 건드린 파일을 한 번에 스크롤해 보고, worktree를 정리해 줘요.
- 현대 터미널 기능을 살려 ⌘V로 이미지를 붙여 넣을 수 있대요(SSH에서도, 단 Ghostty Nightly 필요). Ctrl-Shift-T로 닫은 탭을 되살려요.
- 다른 터미널에서도 Corgi를 조작할 수 있고, `corgi --skill`이 에이전트에게 사용법을 가르쳐요.

### 기능 세부(GeekNews 정리)

**에이전트와 사용량**
- 작업 공간마다 폴더·탭·분할 패널을 두고 에이전트와 일반 터미널을 함께 돌려요.
- 사이드바가 작업 중, 입력 필요, 완료, 읽지 않은 결과를 구분하고 **F1**로 확인이 필요한 에이전트로 가요.
- 지원 에이전트는 **Claude Code, Codex, Pi, OpenCode**이고, 새 작업 화면에서 에이전트·모델·계정을 고르거나 이전 대화를 검색해 재개해요.
- 에이전트별 컨텍스트 사용률, 토큰·캐시 토큰, **계정 한도와 초기화 시점**을 보여 줘요.

**코드 변경과 worktree**
- 에이전트가 고친 파일을 한 리뷰 패널에서 diff로 보고, 줄마다 메모를 달아 에이전트에게 넘겨요.
- Git worktree마다 연결된 에이전트, 로컬 main 대비 앞서거나 뒤처진 커밋 수, 생성·수정 시점, 커밋 안 된 변경을 보여 줘요.

**세션과 자원**
- 화면에서 분리해도 프로세스는 계속 돌고 `corgi` 명령으로 다시 붙어요. 탭이나 패널을 닫으면 그 안 프로세스는 끝나요.
- 충돌·재부팅 뒤 화면 배치와 출력, 에이전트 대화를 복구하지만 일반 프로세스의 메모리 상태까지 되살리진 않아요.
- 작업 공간별 CPU, 메모리, 디스크 I/O, GPU·VRAM을 실시간으로 보여 줘요.
- macOS, Linux, WSL에서 쓰고 Corgi·tmux·Herdr·cmux 단축키 프리셋이 있어요.
