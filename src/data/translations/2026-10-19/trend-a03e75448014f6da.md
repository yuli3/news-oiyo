GitHub 저장소 README 전체와 저장소 정보(GitHub API, 2026-10-19 조회: 스타 약 2만560개, 포크 5,026개, Python, Apache-2.0)를 읽고 정리했어요. 거래소별 후원·추천 링크 표는 옮기지 않았어요. **정보 제공용이며 자동매매나 특정 거래소 이용을 권유하지 않아요.** 자동매매는 원금 손실 위험이 커요.

### 한 줄 요약
여러 중앙화(CEX)·탈중앙화(DEX) 거래소에서 돌아가는 자동매매 전략, 곧 **봇**을 설계·배포하게 해 주는 오픈소스 프레임워크예요. 프로젝트는 "고빈도 매매의 민주화"를 목표로 내세우고, 지난 1년간 사용자들이 140곳 넘는 거래 장소에서 340억달러 이상의 거래량을 냈다고 밝혀요(프로젝트 자체 수치).

### 시작하는 방법
| 방식 | 내용 |
|---|---|
| Condor(AI 하네스) | LLM 기반 의사결정을 Hummingbot API의 결정적 주문 실행에 연결, 텔레그램이나 웹 대시보드로 제어 |
| `hbot` CLI(권장) | 소스 설치(Anaconda/Miniconda 필요) 후 봇 시작·중지, 설정 작성·조정, 거래·손익·로그 조회를 스크립트로 처리. 결과는 간결한 마크다운과 안정적인 종료 코드 |
| Docker | `make setup` → `make deploy` → `make link-cli`로 같은 `hbot` 명령 사용, Gateway(DEX 미들웨어) 선택 가능 |
| TUI | 전통적인 전체 화면 클라이언트, Docker 기본값 |

처음 쓰면 거래소 API 키를 암호화할 키스토어 비밀번호를 묻고, `HBOT_PASSWORD`나 `--password-stdin`으로 비대화형 실행(스크립트·에이전트 워크플로)도 할 수 있어요. 예제는 바이낸스 실시간 시세로 모의 거래하는 `simple_pmm` **페이퍼 트레이딩** 스크립트라 API 키가 필요 없어요.

### 전략 구성 요소
- **Scripts**: 파일 하나짜리 파이썬 전략. 가장 쉬운 시작점이에요.
- **Controllers**: 백테스트·배포·실행 중 조정이 가능한 재사용형 V2 전략(예: `pmm_mister` 마켓메이킹).
- **Executors**: 포지션, DCA, 그리드, 차익거래, XEMM, TWAP, LP 등 주문 수명주기를 관리하는 블록.
- **V1 Strategies**: Pure/Avellaneda/Cross-Exchange 마켓메이킹 같은 레거시 전략.

### 커넥터 종류
| 종류 | 설명 |
|---|---|
| CLOB CEX | 중앙 지정가 호가창, 자금을 거래소가 보관, API 키 연결(현물·무기한 선물) |
| CLOB DEX | 온체인 호가창, 비수탁, 지갑 키 연결 |
| AMM DEX | AMM 프로토콜, Gateway로 연결(라우터, x*y=k 풀, 집중 유동성 CLMM) |

### 기타
관련 저장소로 Condor, Hummingbot API, Gateway(TypeScript DEX 커넥터), 문서 사이트가 있어요. 익명 데이터 수집·리포팅 정책은 공식 문서에 따로 안내돼 있어요.
