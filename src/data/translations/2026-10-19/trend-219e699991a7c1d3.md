Sphinx 소개 페이지 전체를 읽고 옮겼어요. 페이지 자체가 짧은 랜딩 페이지예요.

### 한 줄 소개
> "생각은 외주 줄 수 있어도, 이해는 외주 줄 수 없다." — 페이지가 손자(Sun Tzu)의 말이라며 내건 문구예요.

Sphinx는 **에이전트 보조 개발용 Git 훅**이에요. 에이전트가 만든 코드가 배포되기 전에, 그 코드가 실제로 무엇을 하는지 개발자에게 질문해요. 무료이고 FOSS예요. `npm install -g sphinx-understand`로 설치해요.

### 예시 대화(페이지의 예시)
11개 파일, +5,012 −3,147 변경을 main에 push하자 Sphinx가 이렇게 물어요. "웹훅 핸들러가 이제 `charge()`를 부르기 전에 이벤트 ID를 저장해요. Stripe가 타임아웃 후 같은 이벤트를 다시 보내면 어떻게 되나요?" 개발자가 "두 번 실행돼 이중 결제돼요"라고 답하자 "아니에요. 재시도는 저장된 ID를 보고 결제 없이 200을 돌려줘요. 그런데 ID가 결제 성공 전에 저장돼요. `charge()`가 실패하면 다음 재시도는 어떻게 하나요?"라고 다시 물어요. "결제를 건너뛰어 고객에게 청구가 안 돼요"라고 답하자 통과해 push가 진행돼요. 페이지는 이것이 설명용 예시이고 실제 질문은 diff에서 나온다고 밝혀요.

### 동작 방식
1. **push**: 직접 하든 에이전트가 하든, 보호한 브랜치에서 Git이 멈춰요.
2. **질문**: 채팅 내용을 본 적 없는 리뷰어가 diff를 읽고, 일이 잘못될 때 변경이 어떻게 동작하는지 물어요.
3. **답변**: 틀리면 이유를 배우고 새 시나리오를 받아요. 맞히면 push가 계속돼요.

### 특징
- 토큰을 최소로 쓰도록 만들었고, 기존 코딩 에이전트, OpenRouter, OpenAI 호환 엔드포인트 아무거나로 돌아가요.
- Codex, Claude Code, Cursor, OpenCode, Pi, 또는 그냥 Git과 함께 써요.
- 답변은 코딩 에이전트에 전달되지 않고, `.env` 파일과 키는 열지 않아요.
- 급하면 `sphinx yolo`로 통과시킬 수 있는데, 건너뛴 기록은 모두 남아요.
- 요구 사항은 Node 22.19+, macOS·Linux·WSL이에요. `sphinx install`이 Git과 코딩 에이전트를 연결하고 어떤 모델로 리뷰할지 물어요.
