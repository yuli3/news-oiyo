AI타임스 기사(박찬 기자) 본문 전체를 읽고 정리했어요. 기사에 인용된 OpenAI의 X 게시물(10월 16일) 내용도 포함돼 있어요.

### 무엇이 바뀌었나
OpenAI는 16일(현지시간) X로 **GPT-6 Astra Pro** 업데이트를 발표했어요. 게시물은 "더 빠른 응답, 플러그인과 도구 활용 개선, 그리고 이제 여러 에이전트가 작업의 서로 다른 부분을 병렬로 처리할 수 있고, 각 에이전트의 진행을 따라가며 완료된 작업을 열어 검토할 수 있다"고 적었어요. 새 모델이 아니라 기존 GPT-6 아스트라 프로의 기능 개선이에요.

### 병렬 에이전트
- 하나의 요청을 여러 에이전트가 쪼개 **동시에** 처리해요. 기사는 대규모 코드베이스 검토나 복잡한 자료 조사, 기업 분석 보고서(재무 자료, 경쟁사, 시장 동향을 각각 맡기기)를 예로 들어요.
- 기존처럼 한 에이전트가 단계를 차례로 밟는 방식 외에, 서로 독립적인 작업을 동시에 처리하는 방식을 고를 수 있어요.
- 대화 화면에서 에이전트별 진행 상황을 보고, 끝나면 개별 결과를 열어 무엇을 했는지 확인할 수 있어요.

### 공개되지 않은 것
- 응답 속도가 얼마나 빨라졌는지, 어떤 도구가 개선됐는지 수치가 없어요.
- 병렬 에이전트 최대 개수, 작업 분배 방식 같은 기술 세부도 공개하지 않았어요.
- 병렬 작업이 요금제 사용량과 한도를 얼마나 소모하는지 기준도 밝히지 않았어요.

### 제공 범위와 맥락
챗GPT 채팅 탭에서 일부 **Pro 요금제** 사용자에게 제공되고 계정마다 다를 수 있어요. Plus, Business, Enterprise 확대 일정은 없어요. 기사는 여러 에이전트 협업이 이미 클로드 코드나 Cursor 같은 코딩 도구에서 쓰이고 있으며, 이번엔 별도 개발 환경이 아닌 일반 채팅 화면에서 쓸 수 있게 했다는 점이 다르다고 짚어요. 또 작업이 서로 의존하거나 같은 내용을 고치면 결과 통합과 충돌 해결이 추가로 필요해 무조건 빨라지는 건 아니고, 병렬 실행이 사용량 자체를 줄이는 것도 아니라고 덧붙여요.
