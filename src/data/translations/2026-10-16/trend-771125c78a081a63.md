### 무엇인가
> Private WireGuard® networks made easy

이 저장소에는 Tailscale 오픈소스 코드 대부분이 들어 있어요. 특히 `tailscaled` 데몬과 `tailscale` CLI 도구가 핵심이에요.

- `tailscaled`는 Linux, Windows, macOS에서 돌고, FreeBSD와 OpenBSD에서도 정도 차이는 있지만 돌아가요.
- iOS와 Android 앱도 이 저장소 코드를 쓰지만, 모바일 GUI 코드는 여기 없어요.
- macOS, iOS, Windows 클라이언트는 이 코드에 작은 GUI 래퍼를 더한 거예요. 비오픈소스 플랫폼의 GUI 래퍼는 오픈소스가 아니에요.

관련 저장소로 Android 앱(`tailscale-android`), Synology 패키지, QNAP 패키지, Chocolatey 패키징이 따로 있어요. 어떤 부분이 왜 오픈소스인지는 Tailscale 사이트의 오픈소스 페이지에서 설명한다고 해요.

### 사용
여러 배포판과 플랫폼용 패키지를 `pkgs.tailscale.com`에서 제공해요.

### 빌드
항상 최신 Go 릴리스(현재 Go 1.27)가 필요해요. 릴리스는 Tailscale의 Go 포크로 빌드하지만 꼭 쓸 필요는 없어요.

```bash
go install tailscale.com/cmd/tailscale{,d}
```

배포용 패키지를 만들 때는 커밋 ID와 버전 정보를 바이너리에 넣도록 `build_dist.sh`를 쓰라고 해요.

```bash
./build_dist.sh tailscale.com/cmd/tailscale
./build_dist.sh tailscale.com/cmd/tailscaled
```

배포판 규칙상 이 스크립트를 쓸 수 없다면 같은 일을 배포판 방식으로 해서, 버그 리포트에 쓸모 있는 버전 정보가 남게 해 달라고 해요.

### 버그와 기여
코드나 호스팅 서비스 문제는 이슈 트래커에 올려 달라고 해요. PR은 환영하지만 버그를 먼저 등록하고 커밋 메시지에서 참조하라고 하고, 커밋에는 Developer Certificate of Origin `Signed-off-by` 줄이 필요해요.

### 기타
라이선스는 BSD-3-Clause이고, 수집 시점 기준 별 37.6k, 포크 3.3k예요. WireGuard는 Jason A. Donenfeld의 등록 상표라고 밝혀요.
