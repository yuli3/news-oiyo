GitHub README(한국어판) 원문을 읽고 정리했어요. 원문이 한국어라 번역보다는 핵심을 옮겨 정리했어요. 마지막 대규모 벤치마크 표 일부는 수집 범위 밖이라 빠졌어요.

### 무엇인가
> 파일은 기억나는데, 어디 저장했는지 생각나지 않을 때.

Weft는 내 파일을 위한 가벼운 검색 앱이자 에이전트용 로컬 검색 엔진이에요. 파일명을 몰라도 의미로 찾고, 결과에서 원문 위치와 검증된 문맥을 확인할 수 있어요. 검색과 임베딩은 모두 기기 안에서 돌아요. UI는 한국어·English·简体中文·日本語를 지원해요.

### 할 수 있는 일
- **Mac에서 바로 찾기**: ⌥Space로 열고 파일명/의미 검색을 전환해요. Quick Look이나 Finder로 바로 확인해요.
- **변경 따라가기**: 고른 폴더를 백그라운드로 색인하고 감시해요. 기본 작업 예산은 25%이고, 검색 요청이 오면 색인이 양보해요.
- **문서 내용 검색**: PDF, Word, PowerPoint, Excel, OpenDocument, EPUB, HWPX, 일반 텍스트를 색인해요.
- **정확한 이름과 관련도 구분**: 본문에 정확히 일치하는 식별자(예: `INV-2041`)는 추론을 건너뛰고, 관련도가 낮거나 1위 점수의 절반에 못 미치는 결과는 숨겨요.
- **키보드 명령**: `@설정`, `@메모`, `@녹음`, `@web`과 검색 범위 지정, 앱·URL 별칭을 지원해요.
- **에이전트 근거 찾기**: Codex, Claude Code 등에 Weft 스킬을 설치해 폴더 탐색, 파일 선택, 원문 문맥 확인을 맡길 수 있어요.
- **음성·Markdown 메모**: 다국어 음성을 기기에서 전사하고 메모를 로컬에 저장해요.

의미 검색은 다국어 모델로 8개 언어의 기본 동작을 확인했지만 언어별 정확도 평가는 아니라고 밝혀요. 한국어 부분 검색은 되지만 일본어·중국어 문장 중간 키워드 검색은 아직 보강이 필요하다고 해요.

### 설치
macOS 14 이상, Apple Silicon·Intel용 DMG를 따로 제공해요. 공증 없이 빌드될 수 있어 Gatekeeper가 막으면 "그래도 열기"를 쓰라고 안내해요. CLI는 이렇게 써요.

```bash
./scripts/install.sh --no-index
weft search "데이터베이스 재시도 정책" --json
weft index ~/Documents --watch
```

### 개인정보
검색어와 파일 내용은 외부로 보내지 않아요. 인덱스에는 경로, 해시, 위치, 벡터를 저장하고 원문 전체는 복사하지 않지만, 키워드용 역색인이 디스크에 남아서 인덱스도 개인 데이터로 다뤄야 한다고 해요. 온보딩만으로 전체 디스크를 스캔하지 않고, 사용자가 고른 폴더만 색인해요.

### 벤치마크(2026-10-15)
