Reactor의 모델 페이지를 직접 읽었어요. 원문은 데모 UI 위주의 짧은 소개 페이지라, 아키텍처·학습 방법·벤치마크 같은 기술 세부는 나와 있지 않아요. HN 제목의 "best open-source H3 model"이라는 표현을 뒷받침하는 수치도 페이지에서는 확인하지 못했어요.

### 무엇인가
- 이름: MiniMax FastH3 Omni
- 만든 곳: MiniMax + Hao AI Lab, Reactor에서 호스팅해요.
- 한 줄 소개: "Faster-than-realtime video generation with text, audio and image input." 텍스트, 오디오, 이미지를 넣으면 실시간보다 빠르게 영상을 만든다는 거예요.

### 데모 구성
- 사람, 사물, 장면 사진을 최대 9장까지 넣을 수 있어요.
- 사진을 먼저 넣은 뒤 목소리나 소리를 녹음해 붙일 수 있어요.
- "무슨 일이 일어나는지"를 글로 쓰고 Generate를 누르면 생성이 시작돼요.
- 문서(Docs)와 API 키 발급 버튼, 에이전트용 복사(Copy for Agents) 기능이 있어요.

### 예시 클립
Last Train Ramen(6초, 사진 3장, 오디오 2개), Morning Pour(8초, 사진 2장), Garage Take(8초, 사진 3장, 오디오 1개), Story Time With Fig, Rooftop Run, Say Hello, Lighthouse Keeper(사진 없음) 등 6–8초 길이 예시가 있어요.
