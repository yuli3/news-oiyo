### 무슨 일이 있었나
지난주 작은 팀이 순수 Rust로 다시 구현한 오픈소스 Photoshop을 공개했어요. 일주일 만에 GitHub 별 수천 개를 받았고, Premiere·Lightroom·InDesign·Word를 복제하는 형제 프로젝트도 생겼어요. Eric S. Raymond는 "Adobe가 방금 날아갔다. 클로즈드 소스는 죽었다"고 트윗했어요.

Raymond는 팀이 Photoshop을 디컴파일해 스펙으로 만들고 LLM에 Rust로 생성하게 했다고 추측했지만, 몇 시간 만에 커뮤니티 노트가 붙었어요. PhotoCraft README에는 공개 스펙과 관찰된 동작만으로 구현했고 독점 코드·셰이더·에셋은 없다고 적혀 있어요. 다음 날 Naval은 "모델이 소프트웨어의 마지막 해자"라며 더 많은 소프트웨어가 서버로 물러나 증류에 저항할 거라고 했어요. 저자는 모두 반쯤 맞다고 봐요.

### 실제로 일어난 일
- PhotoCraft는 ArtCraft 팀의 "Craft" 앱 계열로, 9월 말부터 storytold GitHub 조직에 올라왔어요. 모두 Rust, MIT 또는 Apache 라이선스이고 macOS·Windows·Linux와 WebAssembly 브라우저에서 돌아가요.
- PSD 파서는 Adobe의 공개 파일 스펙으로 작성했고, 실제 Photoshop 파일 모음으로 테스트하며 Photoshop 합성 출력과 비교해요.
- 모든 명령이 CLI와 MCP 서버로 열려 있어 에이전트도 사람처럼 편집기를 조작할 수 있어요. AGENTS.md도 있고 커밋 기록에 Claude가 공동 작성자로 나와요.
- 디컴파일 이야기는 근거 없는 추측이에요. WebProNews는 로드맵을 보고 Photoshop 대비 기능 동등성을 50% 미만으로 추정했어요. 피사체 선택, 내용 인식 채우기, 복구 도구가 없고 생성형 기능은 의도적으로 빠졌어요.

걱정해야 할 건 지금 PhotoCraft가 얼마나 좋은가가 아니라, 여기까지 오는 데 비용이 얼마나 적게 들었느냐라고 해요.

### 코드가 싸졌다
1984년 Phoenix Technologies가 IBM PC BIOS를 클린룸으로 복제할 때는 원본을 분석해 스펙을 쓰는 팀과 원본을 본 적 없는 구현 팀이 몇 달을 써야 했어요. 2026년엔 같은 패턴이 프롬프트 하나예요. 3월 npm 소스맵으로 Claude Code 소스가 유출된 뒤 Claurst라는 프로젝트가 바로 나왔는데, 한 에이전트가 동작 스펙을 쓰고 다른 에이전트가 원본을 보지 않고 Rust로 구현했다고 해요.

법도 대체로 이를 허용해요. 저작권은 표현을 보호하지 기능을 보호하지 않고, Sega v. Accolade, Google v. Oracle, EU 소프트웨어 지침과 SAS Institute v. World Programming 판결이 근거로 나와요. 특허·상표 위험과, 학습 중 원본을 봤을 수 있는 모델이 한 작업도 "클린"한지는 아직 검증되지 않았다고 해요.

### 무엇이 새고 있나
- **기능 해자**: PhotoCraft에는 Photoshop 메뉴 트리 전체를 돌며 자기 명령 목록과 대조하는 빌드 작업이 있어요. 기능 동등성이 CI 작업이 된 거예요.
- **UX 친숙함**: "Photoshop을 알면 PhotoCraft도 안다"가 프로젝트 문구예요. 근육 기억은 의외로 스펙으로 쓰기 쉽다고 해요.
- **파일 형식**: PSD는 수백만 디자이너를 Creative Cloud에 묶어 둔 조용한 해자였는데, PhotoCraft는 테스트 파일 대부분을 왕복 변환한다고 주장해요.
