### 무엇인가
PowerShell은 크로스 플랫폼(Windows, Linux, macOS) 자동화·구성 도구이자 프레임워크예요. 기존 도구와 잘 어울리고, 다음을 다루는 데 최적화돼 있어요.

- JSON, CSV, XML 같은 구조화 데이터
- REST API
- 객체 모델

명령줄 셸, 스크립트 언어, cmdlet 처리 프레임워크를 함께 담고 있어요.

### Windows PowerShell과 PowerShell 7+
이 저장소는 Windows PowerShell 코드베이스의 포크로 시작했지만, 여기서 바뀐 내용은 **Windows PowerShell 5.1로 거꾸로 옮겨지지 않아요.** 그래서 여기서 다루는 이슈는 PowerShell 7.x 이상만 해당해요. Windows PowerShell 관련 문제는 피드백 허브 앱에서 "Apps > PowerShell" 분류로 보고하라고 안내해요.

### 설치와 업그레이드
- PowerShell은 Windows, macOS, 여러 Linux 플랫폼을 지원하고, 자세한 건 "Installing PowerShell" 문서를 보라고 해요.
- 처음 PowerShell을 쓴다면 시작하기 문서를 먼저 보라고 권해요.
- 업그레이드는 처음 설치할 때 쓴 방법과 같은 방법으로 하는 게 가장 좋다고 해요. 플랫폼과 설치 방법마다 업데이트 방식이 다르기 때문이에요.
