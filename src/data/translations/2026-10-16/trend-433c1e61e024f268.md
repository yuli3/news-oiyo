### 빌드 의존성
데스크톱 버전 GUI는 Flutter 또는 Sciter(지원 중단 예정)를 써요. README 튜토리얼은 시작하기 쉬운 Sciter 기준이고, Flutter 버전 빌드는 CI 설정을 보라고 안내해요. Sciter 동적 라이브러리는 직접 내려받아야 해요.

### 기본 빌드 단계
1. Rust 개발 환경과 C++ 빌드 환경을 준비해요.
2. vcpkg를 설치하고 `VCPKG_ROOT` 환경 변수를 맞게 설정해요.
3. 의존 라이브러리를 설치해요.
   - Windows: `vcpkg install libvpx:x64-windows-static libyuv:x64-windows-static opus:x64-windows-static aom:x64-windows-static`
   - Linux/macOS: `vcpkg install libvpx libyuv opus aom`
4. `cargo run`을 실행해요.
