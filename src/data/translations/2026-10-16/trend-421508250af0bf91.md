### 변환
본 모델과 비전 프로젝터(mmproj)를 따로 변환해요.

```bash
python convert_hf_to_gguf.py <super-3.5-checkpoint> --outfile super-3.5.gguf
python convert_hf_to_gguf.py <super-3.5-checkpoint> --mmproj --outfile super-3.5-mmproj.gguf
```
Bolt 74B A9B도 같은 방식이에요.
