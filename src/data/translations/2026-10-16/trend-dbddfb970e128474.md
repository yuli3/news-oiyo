AI타임스 기사 원문을 끝까지 읽고 해요체로 옮겨 정리했어요. 같은 발표의 Meta 블로그 원문은 오늘의 다른 항목에 따로 있어요.

### 무엇을 공개했나
메타가 15일(현지시간) 개인용 컴퓨터에서 복잡한 코딩과 여러 단계 작업을 하는 데 초점을 맞춘 오픈웨이트 모델 '뮤즈 스파크 오픈'의 가중치를 공개하고 외부 플랫폼 API 서비스를 시작했어요. 메타는 "현재까지 가장 뛰어난 미국 오픈웨이트 모델"이라고 소개했고, 애플과 협력해 맥 스튜디오 두 대를 연결한 환경에 최적화했어요.

- 총 8,160억 개 매개변수 중 토큰당 420억 개를 쓰는 MoE 구조예요.
- 컨텍스트는 100만 토큰, 텍스트·이미지·동영상·음성 입력에 텍스트 출력이에요.
- 계획 수립, 도구 호출, 오류 진단과 재시도를 하는 장시간 에이전트 작업이 핵심이에요.
- 추론 강도는 로우부터 엑스하이까지 네 단계이고 기본값은 엑스하이예요.

### 벤치마크
메타 자료 기준으로 도구 사용과 일부 추론이 두드러졌어요.

- 잡벤치 61.8점(GLM 5.3 61.4, 키미 K3 54.3)
- MCP-아틀라스 89.2점(GLM 5.3 84.2, 키미 K3 82.3)
- 도구 없는 HLE-다이아몬드 26.1점(키미 K3 22.2, 큐원 3.8 17.3)
- 제로벤치 50점(키미 K3 41)

코딩은 중국 모델에 뒤졌어요. 터미널벤치 2.1은 76.4점으로 GLM 5.3(83.9)과 키미 K3(85)보다 낮았고, 딥SWE 1.1도 60점으로 두 모델(67, 68)에 못 미쳤어요. 모델 카드의 Artificial Analysis 지능지수는 39점으로 잉클링(26), 네모트론 3 울트라(23) 같은 미국 오픈 모델보다 높지만 GLM 5.3(45), 키미 K3(44), 큐원 3.8(40)보다는 낮아요.

### 가격과 라이선스
- API는 투게더AI, 파이어웍스, 베이스텐, 네비우스 등이 제공해요. 100만 토큰당 입력 1.25달러, 출력 4.25달러, 캐시 입력 0.15달러예요. 제공업체마다 컨텍스트 길이와 조건은 달라요.
- 가중치는 자체 '뮤즈 모델 라이선스'로 배포돼요. 많은 개발자가 무료로 쓸 수 있지만, 모델을 API 같은 서비스로 제공하는 사업자 중 계열사 포함 연 매출이 2,000만 달러를 넘으면 메타와 별도 계약을 맺어야 해요. 기업 내부 이용이나 자체 제품에 AI 기능을 넣는 경우는 이 조건에서 빠져요.

### 반응
벤처비트는 도구 사용 등 특정 분야에 강점이 있지만 전반적인 성능이나 비용 우위가 입증된 건 아니라고 분석했어요. 개발자 커뮤니티는 가중치 공개를 반기면서도 모델 크기가 부담스럽고, 대형 API 사업자의 별도 계약 의무가 가격 경쟁을 제한할 수 있다는 의견을 냈어요. 마크 저커버그는 X에 애플과의 협업 덕분에 새 맥 스튜디오에서 잘 돈다고 썼어요.
