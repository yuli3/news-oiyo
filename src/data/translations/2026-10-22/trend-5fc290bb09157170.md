### 무엇인가

Omnara는 **오픈소스 관리형 에이전트 플랫폼**이에요. README는 스스로를 "Claude Managed Agents와 OpenAI Agents API의 셀프 호스팅 대안"이라고 소개해요. API로 어떤 모델, 어떤 머신에서든 AI 에이전트를 돌릴 수 있고 도구, 시크릿, 권한, 스트리밍이 기본으로 들어 있어요. Apache 2.0으로 무료로 직접 호스팅하거나, 관리형 서비스인 Omnara Cloud를 쓸 수 있어요. 저장소는 Go 백엔드와 프런트엔드, 마이그레이션, 관측(observability) 설정, Docker Compose 파일로 구성돼 있어요.

### 빠른 시작 (Omnara Cloud)

app.omnara.com에 로그인하면 첫 프로젝트에 모델 제공자(`omnara-openrouter`)와 관리형 샌드박스 풀(`default-pool`)이 미리 붙어 있어서, 아래 설정이 그대로 돌아가요.

```yaml
version: v1
instruction: |
  You are an engineering assistant. Use your machine to run commands.
model:
  provider_config: omnara-openrouter
  name: anthropic/claude-fable-5.1
machine_sources:
  - machine_pool_name: default-pool
```

이를 `agent.yaml`로 저장하고 CLI(Node.js 22 이상)로 띄워요. 로그인이 안 돼 있으면 첫 명령이 브라우저를 열어 로그인시켜요.

```
npx omnara agents launch --file agent.yaml --name "Machine assistant" --message "Report this machine's operating system and free disk space."
```

그다음 `npx omnara agents chat <agent-id>`로 터미널에서 대화하거나, 대시보드에서 에이전트의 도구 호출을 보며 답할 수 있어요.

### 정리

핵심은 특정 벤더의 관리형 에이전트 서비스에 묶이지 않고, 같은 형태의 API를 직접 운영하거나 다른 모델로 바꿔 쓸 수 있다는 점이에요.
