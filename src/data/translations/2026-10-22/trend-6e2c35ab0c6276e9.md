### 무엇인가

**Numpad**는 "키보드에 없는 숫자"를 위한 macOS 기본(native) 메뉴 막대 앱이에요. 저장소 설명 그대로 "숫자 패드 없는 키보드는 끔찍하다"는 불편에서 출발했어요. 오른쪽 ⌘ + 오른쪽 ⌥를 누르고 숫자를 탭하면 돼요. 이미 있는 터치 표면을 숫자 키패드로 바꾸고, 안내 오버레이와 햅틱 피드백을 줘요. Mac에서 녹화한 36초짜리 데모 영상도 있어요.

### 기능

- **탭해서 입력**: 숫자, 소수점, 사칙연산 기호, Return, Backspace. 짧게 탭하면 손가락을 뗄 때 한 번 입력돼요.
- **입력마다 촉감**: 터치 시작과 입력 확정에 서로 다른 햅틱을 주고, 5 자리 가운데에는 더 강한 기준 햅틱을 줘요.
- **자리 만들기**: 반투명 오버레이를 원하는 곳으로 끌어 화면 가장자리나 가운데에 붙이거나, 포커스된 입력 칸을 따라다니게 할 수 있어요.
- **방향 선택**: 연산자를 왼쪽이나 오른쪽에 둘 수 있어요. 한 손가락을 올려 둔 채 다른 손가락으로 반복 탭할 수도 있어요.
- **로컬 전용**: 계정, 네트워크 요청, 분석, 입력 로그 파일이 없어요. 오버레이 위치를 잡으려고 입력 칸의 위치·크기만 읽고 내용은 읽지 않아요.
- **언어**: 기본은 영어이고 설정에서 한국어로 바로 바꿀 수 있어요(재시작 불필요).

### 시작하기

1. 최신 DMG를 내려받아 Numpad를 응용 프로그램 폴더로 끌어다 놓아요. 릴리스 빌드는 Developer ID로 서명되고 Apple 공증을 받았어요.
2. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 허용해요.
3. 앱은 메뉴 막대에 있어요. 텍스트 칸에 포커스를 두고 오른쪽 ⌘ + 오른쪽 ⌥를 눌렀다 떼면 키패드가 켜져요.
4. 트랙패드에서 키 위치를 탭해요. Esc나 같은 단축키로 원래 트랙패드로 돌아가요.
