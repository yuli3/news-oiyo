### 무엇인가

Brello Scan은 **OpenAI와 Anthropic의 사용량·비용 CSV를 분석해 AI API 비용이 새는 곳을 찾아 주는 무료 스캐너**예요. 파일은 브라우저 안에서만 처리되고 서버로 나가지 않는다고 해요. 사이트는 익명 클릭만 수집한다고 밝혀요. 내 파일 대신 샘플 데이터로 먼저 써 볼 수도 있어요.

### 찾아 주는 세 가지

1. **과하게 비싼 모델**: 예를 들어 단순 요약에 gpt-5.5를 쓰고 있다면 gpt-5.4-mini 같은 작은 모델을 제안해요.
2. **의심스러운 급증**: 모르는 키에서 하루 사이 $1,112가 나가는 식의 갑작스러운 비용 증가를 짚어요.
3. **놓친 할인**: 프롬프트 캐싱이나 Batch를 쓰지 않는 경우를 보여 줘요.

### 사용 순서

1. 제공자의 Usage 페이지에서 CSV를 내려받아요. 사용량(usage) 내보내기가 더 자세하고, 비용(cost) 내보내기도 지원해요. OpenAI와 Anthropic 내보내기 가이드가 따로 있어요.
2. 파일을 올려요.
3. 처리는 브라우저에서만 이뤄져요.
4. 리포트를 받아요.

### 앞으로

이 리포트는 지난 데이터를 돌아보는 용도예요. 제작자는 "키가 유출되면 청구서가 오기 전에 사용 순간 잡아내는" 실시간 보호를 다음으로 만들고 있다며 대기자 명단을 받아요. 설문에 올린 가격 후보는 이래요.

- 실시간 유출 알림·자동 차단: 월 $9
- 환불 지원(사건당): $29
- 스파이크 보상(놓친 유출 피해를 크레딧으로): 월 $39

스캔 자체는 계속 무료라고 해요. 설문에서는 샘플 데이터를 썼는지 내 파일을 썼는지만 기록하고 사용량 숫자는 보내지 않는다고 밝혀요.
