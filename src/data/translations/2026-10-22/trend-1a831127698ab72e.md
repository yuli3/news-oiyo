> 페이지가 스크립트로 렌더링돼 D2 콘텐츠 API로 본문 전체를 읽었어요. 원문이 한국어 장문이라 핵심을 간추려 옮겼어요.

### 연재 재개

2016년부터 이어 오다 2020년에 멈춘 "JavaScript의 동향"이 6년 만에 돌아왔어요(글쓴이: 네이버 박재성). 그사이 ECMAScript 명세는 여섯 번 개정됐어요. 연재는 ① JavaScript(ECMAScript) ② 브라우저 밖의 JavaScript ③ WebAssembly ④ 라이브러리와 프레임워크 네 편이고, 2026년 10월 기준이에요.

### 2020년 예측은 어떻게 됐나

- **ESM 전환**은 느렸어요. Node.js의 `require(esm)`(22.12.0 LTS)로 큰 장벽이 풀렸고, ESM을 제공하는 인기 패키지 비율은 2021년 7.8% → 2026년 6월 38.0%예요. 여전히 60% 이상은 ESM이 없어요.
- **도구의 비JS 언어 전환**은 빨랐어요. esbuild(Go), Rolldown·Oxc·Biome(Rust)이 주류가 됐고, Go 기반 **TypeScript 7.0**이 2026년 7월 정식 출시됐어요.
- Temporal은 Stage 4, Pipeline Operator는 Hack 스타일로 Stage 2, Records & Tuples는 철회되고 Composites(현재 Stage 2)로 이어졌어요.

### TC39의 변화

2023년 11월 Stage 2와 3 사이에 **Stage 2.7**이 생겼어요. 테스트와 검증 구간이에요. 조건부 진행이 늘었지만, Explicit Resource Management는 조건부 Stage 4 뒤 Test262 리뷰 부족으로 1년이 걸렸어요. Decorators는 2026년 5월 Stage 2.7로 되돌아갔어요.

### ES2026과 ES2027

ES2026(6월 30일 승인)은 `Array.fromAsync`, `Error.isError`, `Math.sumPrecise`, Uint8Array base64/hex, `Iterator.concat`, `JSON.rawJSON`, `Map.prototype.getOrInsert` 7개예요. ES2027에는 **Temporal**(9년 만에 Stage 4), `using` 선언, `Atomics.pause`, `Iterator.zip`, chunking·includes·join이 들어갈 예정이에요. V8의 Temporal은 Rust 라이브러리 temporal_rs를 써요.

### 엔진과 상표권

Chromium 계열 점유율이 80%에 가깝고 Firefox는 3% 아래예요. Ladybird는 독자 엔진을 만들고 있고, QuickJS·quickjs-ng·LLRT·Boa 같은 임베디드 엔진은 선택지가 늘었어요. Deno가 Oracle의 'JavaScript' 상표 취소 심판을 청구했는데, 2026년 8월 합의 협상을 이유로 절차가 중지됐어요.

### TypeScript

TS 6.0은 strict·esnext 기본값과 ES5·AMD 폐기 예정, 7.0은 빌드 8~12배 향상(Slack CI 7.5분 → 1.25분)이에요. 다만 안정된 API가 없어 Vue·Svelte·Astro 플러그인은 당분간 온전히 쓰기 어려워요. 런타임의 타입 스트리핑 때문에 `erasableSyntaxOnly`가 중요해졌어요.

### AI 도구의 영향

- State of JS 2025 응답자의 코드 중 평균 29%가 AI 생성이에요(전년 20%).
- Octoverse 2025에서 TypeScript가 처음 1위가 됐고, GitHub은 이유로 AI를 꼽았어요. LLM 생성 코드 컴파일 오류의 94%가 타입 검사 실패라는 연구를 인용해요.
- 학습 데이터 시차 문제로 MDN이 공식 MCP 서버를 냈고, Next.js 16.3은 AGENTS.md에 "학습 데이터와 다르다"는 경고를 넣어요.
- Ladybird는 Claude Code·Codex로 LibJS 약 2만 5천 줄을 2주 만에 Rust로 옮겼고 Test262 회귀가 없었어요. 반면 2026년 6월부터 외부 PR은 받지 않아요.
- TC39는 글 기여는 본인이 직접 써야 한다는 AI_POLICY.md를 뒀어요.

글은 AI가 퍼질수록 공개 테스트와 타입 검사 같은 **표준과 검증의 가치가 커진다**고 맺어요.
