### 무엇인가
**devvm**은 "프로젝트마다 하나의 VM"을 내건 개발 환경 도구예요. 프로젝트 도구 체인이 준비된 격리 샌드박스를 사람이나 코딩 에이전트가 바로 쓰게 하는 게 목표예요. 백엔드로 **Lima**를 쓰고, `devcontainer.json`·커스텀 이미지·레이어·VM 간 링크·데스크톱 세션도 문서에 나와요.

### 문서에 보이는 기능
- 설치, 첫 VM, 일상 명령, 코딩 에이전트, 도구 체인, SSH·에디터, 포트·크기
- 이미지·도구 관리, 클론 작업, 컨테이너 이미지에서 시작
- 안전: 네트워크 티어, `.git` 보호, 공격 벡터 안내
- 에이전트: `devvm agent` / import / login / save
- 시크릿, 네트워크 allow/deny, 포트, 히스토리 import·export 등 촘촘한 CLI
