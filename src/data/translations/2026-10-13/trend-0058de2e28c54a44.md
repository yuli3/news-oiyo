GeekNews의 Show GN으로 소개된 **이음(ieum)**은 "한국어 문장으로 쓰는 프로그래밍 언어"예요. 원래 한국어 README를 바탕으로 정리했어요.

### 어떻게 생겼나
README 첫 예제는 이래요.

```
`수`를 팩토리얼구하는 법:
    `수`가 1 이하이면:
        1을 반환한다.
    (`수` * ((`수` - 1)을 팩토리얼구한 값))을 반환한다.

(5를 팩토리얼구한 값)을 출력한다.

과일들은 ["사과", "배"]이다.
과일들에 "감"이 없으면:
    과일들에 "감"을 추가한다.
(과일들을 ", "로 연결한 값)을 출력한다.

학생들은 [{"이름": "하나", "점수": 92}, {"이름": "두나", "점수": 75}]이다.
학생들 중 학생의 점수가 80 이상인 학생마다:
    학생의 이름을 출력한다.
```

출력은 `120`, `사과, 배, 감`, `하나`예요. 함수 정의는 "~하는 법:", 호출 결과는 "~한 값", 조건은 "~이면:", 반복은 "~인 학생마다:" 같은 관형절로 써요. 변수는 백틱으로 감싸고, 값 대입은 "~은 ~이다."로 표현해요.

### 설치와 도구
Rust 1.85 이상이 필요하고, 파이썬 연동을 쓰려면 빌드·실행 때 PATH에 Python 3.8 이상이 있어야 해요.

```sh
cargo install --path .
cargo install --path . --features python   # 파이썬 모듈을 쓰려면
```

명령은 `ieum 파일.이음`(실행), `ieum check`(실행 없이 검사), `ieum fmt`(정리한 코드 출력), `ieum test 폴더`(폴더 안 `test_*.이음` 실행), `ieum repl`(대화형)이 있어요. 편집기용으로 언어 서버 `ieum lsp`와 VS Code 확장도 제공해요. 문서는 언어 안내와 내장 동사 문서로 나뉘어 있어요.

### 예제로 보는 기능
저장소의 예제 목록을 보면 꽤 넓은 기능을 다뤄요.
- **기본:** 출력, 정의와 변경, 큰 정수, 나눗셈, 조건 문장, 포함 검사, 사전
- **함수:** 재귀, 범위·조건 반복, 클로저, **조사로 정하는 인자**, 기본값, 결과 잇기, `-는지`로 정의한 동사를 조건으로 쓰기(피즈버즈), 형용사 함수
- **자료형:** 자료형 정의, 값 만들고 바꾸기, JSON, 튜플 집합·튜플 키 사전(생명게임)
- **오류:** 예외 처리와 정리 블록, 직접 낸 오류
- **파일:** 파일 쓰기·덧붙이기·읽기, 경로, 폴더 정리(찾기·옮기기·지우기)
- **동시성:** 기다리는 일을 `함께` 실행하기, 계산을 `병렬로` 여러 코어에 나누기
- **응용:** 하노이탑(명령줄 인자), 에라토스테네스의 체, 여덟 퀸(백트래킹, 부정 관형절), 재고관리, 로그 집계, 가계부(서식 맞춘 표), 여러 파일로 나눈 성적처리(CSV, 테스트)
- **파이썬 연동:** numpy, pandas, `.py` 파일 가져오기(`--features python` 빌드 필요)
