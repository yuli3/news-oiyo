**OpenFatigue™**는 "Open is the new closed(오픈은 새로운 폐쇄다)"를 내건 **패러디 사이트**예요. 실제 제품이 아니라, 이름에 "Open"을 붙이고 실제로는 거의 아무것도 공개하지 않는 AI 업계의 '오픈 워싱'을 제품 소개 페이지 형식으로 비꼬아요.

### 가짜 기능 목록
- **Open-ish Licensing:** 라이선스는 누구나 *읽을* 수 있어요. 사용·수정·배포는 법무팀과 별도로 상의해야 해요.
- **Weights Available\*:** 41쪽짜리 이용 정책(AUP), 월간 활성 사용자 상한, 그리고 "바이브 체크"에 동의하면 가중치를 내려받을 수 있어요.
- **Source Visible:** 분기마다 소스 코드의 고해상도 스크린샷을 공개해요. 풀 리퀘스트는 팩스로 받아요.
- **Community Edition:** 활기찬 커뮤니티 1명(현재 안식년 중)이 만들어요. 나머지 기능은 Enterprise Edition에 있어요.
- **Open Door Policy:** 문은 늘 열려 있어요. 건물은 출입증이 있어야 들어오고, 출입증 리더기는 클로즈드 소스예요.
- **Open Roadmap:** 로드맵은 완전히 공개돼 있고, 전부 희망 사항이며, 다음 주에 존재할지 모를 비영리 이사회가 바꿀 수 있어요.

### 인터랙티브 장난감
- **Openness Meter™:** 슬라이더로 "얼마나 오픈한지"를 GPL → MIT → Source available → 가중치 "공개" → GitHub 있음 → 이름에 Open 들어감 → 보도자료 순으로 보정해요.
- **Open Name Generator™:** "Open + 명사"로 시드 라운드를 한 번에 따내요. 예시 결과는 태그라인 "피곤해지기 위한 오픈 플랫폼", 라이선스 "Open License™(All Rights Reserved)", 실제 개방도 3%, 기업가치 12억 달러예요.
- **Is It Open?™:** 제품 이름을 넣으면 "클로즈드 소스 모델"이 얼마나 오픈한지 알려 주는 분류기예요.

### 요금제(Open pricing†)
- **Open — 월 0달러\*:** README 읽기, 저장소 star(필수), Discord 참여(읽기 전용). 소프트웨어 실행은 포함되지 않아요.
- **Open Pro — 월/좌석/토큰/바이브당 49달러:** 41쪽 AUP가 붙은 가중치, 이메일 서명에 "Open" 넣기, MAU 7억 미만 상업 사용.
- **Open Enterprise — 영업 문의:** 감독 아래 방 안에서 소스 열람, 전담 "Openness Success Manager", 요청하면 "오픈"이라고 부르는 걸 멈춰 줌. 버튼 이름은 "Talk to Closed Sales"예요.

MAU 7억 상한이나 장문의 AUP 같은 디테일은 실제 "오픈 가중치" 모델 라이선스들을 떠올리게 하는 장치예요.
