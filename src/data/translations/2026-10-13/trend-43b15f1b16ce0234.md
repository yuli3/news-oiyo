AI타임스 임대준 기자의 기사예요. 한국어 원문이라 핵심을 해설 형식으로 정리했어요. (메타 공식 발표는 같은 날 항목 "Muse Wonder"에 따로 번역돼 있어요.)

### 출시 개요
메타는 12일(현지시간) **뮤즈 원더(Muse Wonder)**와 **뮤즈 원더 풀(Muse Wonder Full)**을 발표했어요. 원더는 메타 모델 API와 코딩 도구 '뮤즈 코드'에서 쓸 수 있고, 상위 모델인 풀은 뮤즈 코드 구독자 전용이라 공개 API로는 쓸 수 없어요. 개인 AI 에이전트 '뮤즈'에도 원더를 넣되 구독자에게 먼저 제공해요. 알렉산드르 왕 CAIO가 이끄는 MSL의 자체 최고 모델로, 기존 '뮤즈 스파크' 제품군보다 훨씬 크고 발전된 상위 버전이에요. 메타는 AI 개발 체계를 전면 개편한 지 14개월 만에 프런티어 경쟁 단계에 올라섰다고 강조했고, 두 모델은 오하이오주 프로메테우스 데이터센터에서 학습됐어요.

### 핵심 기능
- **액티브 메모리:** 대화 전반에 걸쳐 중요한 사용자·업무 정보를 유지하고 필요할 때 활용해요.
- **액티브 포커스:** 작업 중 오류나 장애물이 생겨도 다른 방법을 찾아 목표를 계속 수행해요. 왕은 CNBC 인터뷰에서 매번 멈춰 확인을 요청하는 대신 다른 접근을 시도하도록 훈련했다며, 예약·보험 처리·전문 문서 작성·장기 소프트웨어 개발에 쓸 수 있다고 했어요.
입력은 텍스트·이미지·영상·음성, 출력은 텍스트예요. 컨텍스트 창은 스파크 1.3과 같은 100만 토큰으로, 크기보다 정보 활용과 작업 지속 능력 개선에 초점을 뒀어요.

### 벤치마크
- **딥SWE 1.1:** 풀 79.0%, 원더 78.8% — 클로드 오퍼스 5.5(74.2%), GPT-6 아스트라(74.1%)를 앞섰어요.
- **SWE-마라톤:** 풀 57.5%, 원더 53.1% — 오퍼스 5.5(46.3%), 아스트라(42.5%)보다 높아요. 다만 모델별 코딩 도구와 풀의 추론 설정이 달라 통제된 비교는 아니라고 메타가 명시했어요.
- 약점도 있어요. **터미널벤치 4.0**에서 풀은 57.1%로 오퍼스 5.5(59.6%), 아스트라(59.1%)에 못 미쳤고, 전문 건강 질문 평가 **헬스벤치 프로**에서도 62.3%로 두 경쟁 모델보다 낮았어요.

### 독립 평가(Artificial Analysis)
지능 지수 AAII v4.3 최대 추론 기준 풀 56점, 원더 52점이에요. 풀은 클로드 소네트 5.5와 같고, GPT-6 아스트라·제미나이 4 아르곤·클로드 페이블 5.1(53점)을 앞섰지만 오퍼스 5.5(58점)엔 뒤졌어요. 6주 전 나온 스파크 1.3(48점)보다 크게 나아졌고, 풀의 터미널벤치는 33%→57%, 전문 업무 평가 GDPval-AA는 1681→1857 Elo로 올랐어요. 풀은 지수를 구성하는 10개 평가 중 6개에서 상위 3위 안에 들었어요. 코딩 에이전트 지수에선 뮤즈 코드+풀 68점, 원더 63점으로 스파크 1.3(54점)보다 높고, 클로드 코드+소네트 5.5(68점)와 같았어요.

### 가격과 비용
원더 API는 100만 토큰당 입력 4달러, 출력 20달러, 캐시 입력 0.20달러로 오퍼스 5.5와 같고, 아스트라·페이블 5.1(입력 10달러, 출력 50달러)보다 싸요. 하지만 작업당 평균 비용은 원더 4.52달러로 오퍼스 5.5(5.98달러), 페이블 5.1(7.63달러)보다는 낮지만 아스트라(3.26달러), 아르곤(1.99달러)보다 높아요. 풀은 토큰 가격이 공개되지 않았고, 월 50달러나 200달러 뮤즈 코드 구독이 필요하며, 기업이 API로 연결할 수 없다는 제약이 있어요.

### 외신의 시각과 과제
외신은 기술 경쟁력 회복과 수익화 전략이라는 두 관점에서 분석했어요. 경량 스파크에서 대형 프런티어 모델로의 도약과 장기 기억이 주목받은 반면, 풀의 API 제한·비공개 가중치·데이터 사용 및 보존 조건이 도입을 좌우할 거라는 지적도 있어요. 뮤즈 앱에서 원더를 쓰려면 월 20달러나 100달러 구독이 필요해, 광고 외 AI 수익원을 만들려는 시도로 해석돼요. 메타 주가는 발표 당일 오후 약 4% 올랐어요. CNBC는 일부 이용자가 뮤즈의 개인 메시지 접근에 불만을 제기했다고 전했고, 메타는 무단 접근을 부인했으며 왕은 사용자가 이전에 준 권한을 잊는 경우가 있어 안내를 강화하고 있다고 했어요. 기사는 기억·작업 지속성 개선이 실제 업무 완수율과 반복 이용으로 이어져야 막대한 투자를 수익으로 바꿀 수 있을 거라고 맺어요.
