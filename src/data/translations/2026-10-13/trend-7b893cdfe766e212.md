Show HN에 올라온 오픈소스 macOS 앱 **Atticus**예요. 저장소 README를 바탕으로 옮겼어요. 사용법은 단순해요. ⌃ control + ⌥ option + space를 누른 채 원하는 걸 말하고 손을 떼면, Atticus가 창을 옮기고 파일을 찾고 화면을 읽어 일을 처리해요. Windows용으로는 다른 개발자가 만든 Atticus for Windows(Home Assistant·Jellyfin·Immich 연동)가 있어요.

### 세 가지 특징
- **빠름:** 간단한 요청은 AI를 아예 건너뛰어요. 앱은 0.08초에 열려요. 한 번 요청한 동작은 학습해서 다음부터 AI 없이 무료로 즉시 실행해요. 예컨대 "계산기와 체스 열어"는 5.5초에서 0.4초가 됐어요.
- **API 키 불필요:** 이미 쓰는 Claude Pro/Max 플랜으로 Claude Code의 `claude -p`를 통해 돌아요. 요청당 플랜 사용량은 약 0.14센트(API 정가 기준 1달러에 약 700회)이고, Atticus 자체는 무료예요.
- **기억:** "기억해: '열어'는 앞으로 가져오라는 뜻이야"처럼 말하면 이후 모든 요청에 적용돼요. 이름·도시·자주 쓰는 앱 같은 지속적 사실을 익히고, 사용자가 고쳐 주면 규칙으로 저장해 다음엔 제대로 해요. 설정에서 모두 편집할 수 있어요.

### 이런 걸 할 수 있어요
- "코드는 큰 화면에, Chrome과 터미널은 노트북에" → 두 디스플레이에 창 세 개를 배치해요.
- "Spotify 열어", "터미널 왼쪽으로" → AI 없이 즉시 실행해요.
- "도쿄 여행 메모 찾아 줘" → 파일 내용으로 검색해 다른 화면에 열어요.
- "이 코드 뭐가 문제야?" → 화면을 보고 한 줄로 답해요.
- "이 글 세 줄로 요약해" → 페이지를 읽어 줘요.
- "답장: 좋아, 7시에 봐" → 지금 앱에 입력만 하고 **절대 보내지 않아요**.
- "집중 모드라고 하면 Slack 닫고 할 일 목록 열어" → 기억했다가 다음엔 두 단어로 실행해요.

### 프라이버시와 안전
음성은 Apple 온디바이스 음성 인식으로 텍스트가 되고 오디오는 Mac을 떠나지 않아요. 앱·창·파일·설정·웹·화면을 다루며, 앱 안 클릭·스크롤·입력은 네이티브 손쉬운 사용(Accessibility) 제어로 해요. 안전 모드에서는 AI 명령을 Claude Code 샌드박스에서 돌려 임시 폴더에만 쓸 수 있고, 삭제·전송·구매·파일 변경 전에는 먼저 물어요. `rm`, `sudo`, 디스크 도구, 종료는 항상 막히고, 실행한 정확한 명령은 모두 요청 로그에 남아요.

### 단축키와 오버레이 동작
설정에서 "누르고 말하기(Hold)"와 "눌러서 켜고 끄기(Toggle)"를 고를 수 있어요. 응답 중 단축키를 누르면 멈추고, Esc는 보내지 않고 듣기를 취소해요. 토글 녹음은 60초가 지나면 자동 전송 대신 검토 화면으로 가요. 답을 클릭하면 복사되고, 내 요청을 클릭하면 고쳐서 다시 물을 수 있어요. 가려진 창이나 다른 Space·디스플레이에서 작업할 때는 그 창을 보여 주는 실시간 미니 화면이 뜨는데, 이 미리보기는 AI에 보내거나 저장하지 않아요. AI 도구나 학습된 단축 경로는 Apple의 최종 전사가 요청을 확정한 뒤에야 실행돼요.
