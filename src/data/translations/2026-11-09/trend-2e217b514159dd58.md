Hugging Face 모델 카드(tencent/Qwen3.8-27B-DSpine-b16)의 앞부분을 읽고 옮겼어요. 수치는 모델 카드의 보고값이에요.

### 무엇인가
DSpine은 드래프트 토큰을 병렬로 생성해요. 각 레이어가 예측한 선행 특징을 인접 위치에 넘겨 인과 의존성을 네트워크 깊이로 전달해요. 이 체크포인트는 Qwen3.8-27B용 5층 드래프트 모델이고, 블록 크기는 16, 슬라이딩 윈도우는 8,192토큰이에요.

### 평가 조건
SGLang 0.5.22, BF16, FlashAttention 3, 동시성 8로 측정했고, 드래프트 블록은 DSpine 16, 공식 DFlash2 8이에요. DSpine 추론은 DSpark를 참조한 동적 검증과 ReplaySSM을 켰어요. 일반 벤치마크는 xhigh 추론, 탐욕/온도 샘플링, 최대 4,096 신규 토큰이고, 에이전트 벤치마크는 서브셋당 20개 대화의 도구 결정 접두를 순서대로 재생해요.

### 결과
- **수락 길이(T=0, DFlash2 → DSpine)**: GSM8K 5.69→7.20, MATH-500 5.49→6.49, HumanEval 4.87→5.71, MBPP 5.04→6.14, MT-Bench 4.11→4.48이에요.
- **에이전트 수락 길이(low 추론)**: WorkBuddy Code 4.19→5.08, SWE-bench Pro 4.19→4.99, τ²-bench 4.70→5.53 등이에요.
- **에이전트 종단 처리량(low)**: 자기회귀(AR) 대비 DSpine이 WorkBuddy Code 2.71배, Web 3.13배, Office 3.84배, SWE-bench Pro 2.95배, τ²-bench 3.20배예요(DFlash2는 2.33~3.17배). xhigh에서는 2.87~3.55배예요.

### 사용
`git clone https://github.com/Tencent/DSpine.git` 후 `pip install -e .`로 설치하고, `sglang serve`에 `--speculative-algorithm DSPINE`, 드래프트 모델 경로, `--speculative-num-draft-tokens 16` 등을 지정해요. 카드는 DFlash, SpecForge, SGLang, FlashInfer에 감사를 표하고 동적 검증은 DSpark를 참조한다고 밝혀요.
