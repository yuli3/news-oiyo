AI타임스 기사의 앞부분을 바탕으로 요점만 다시 정리했어요. 국내 언론 기사라 본문을 옮기지 않았어요.

### 보고서 개요
- Anthropic은 5일(현지시간) 공식 블로그에 '과학적 발견을 위한 AI: 연구자들은 클로드를 어떻게 사용하는가' 보고서를 공개했어요.
- 8월 2일부터 9월 30일까지 Claude와 Claude Code에서 이뤄진 과학 연구 관련 세션 20만7,049건을 분석하고, 과학자 528명을 따로 설문했어요.
- 특정 문제를 푼 성공 사례가 아니라, 실제 연구 현장에서 AI를 어떤 업무에 쓰는지를 대규모로 본 조사예요.

### 주요 결과
- 일반 Claude에서는 '데이터 분석'이 전체 세션의 33.7%로 가장 많았고, 논문 작성과 결과 정리 같은 글쓰기·소통이 32.0%로 뒤를 이었어요. 둘을 합치면 약 66%예요.
- 코딩 에이전트인 Claude Code에서는 데이터 분석 비중이 48.1%로 더 높았어요. 통계 분석 코드 작성, 데이터 정리, 결과 시각화 등에 썼어요.
- 연구자들은 가설 생성을 과학적 발견에서 가장 중요한 활동으로 꼽았지만, 실제 AI 사용 비중은 4% 수준에 그쳤어요.

### 맥락
기사는 Anthropic이 최근 Claude를 활용한 새 효소 시스템 발견과 단백질 3D 구조 규명 같은 연구 성과를 잇달아 발표했다고 전해요. 이번 보고서는 그와 달리 AI가 새로운 아이디어보다 분석과 작성에 집중적으로 쓰이고 있다는 현실을 보여 준다는 점이 핵심이에요.
