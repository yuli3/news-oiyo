### 무엇인가
Gatus는 개발자 지향 헬스 대시보드예요. HTTP, ICMP, TCP, DNS 질의로 서비스를 모니터링하고, 상태 코드, 응답 시간, 인증서 만료, 응답 본문 같은 값에 조건 목록을 적용해 결과를 평가해요. 각 헬스 체크에는 Slack, Teams, PagerDuty, Discord, Twilio 등을 통한 알림을 붙일 수 있어요. 작성자(TwiN)는 자신의 Kubernetes 클러스터에 배포해 핵심 앱 상태를 감시한다며 status.twin.sh를 예로 들어요. 관리형 서비스를 원하면 Gatus.io가 있어요.

### 빠른 시작
`docker run -p 8080:8080 --name gatus ghcr.io/twin/gatus:stable`로 실행하고, Docker Hub 이미지(`twinproduction/gatus:stable`)도 쓸 수 있어요.

### 문서 구성
목차에는 엔드포인트, 외부 엔드포인트, 스위트(알파), 조건(플레이스홀더, 함수), 웹, UI, 공지, 저장소, 클라이언트 설정, 터널링, 그리고 AWS SES, Bark, ClickUp, Datadog, Discord, Email, Gitea, GitHub 등 다양한 알림 설정이 있어요.

### 저장소 정보
Go로 작성됐고 Apache-2.0 라이선스예요. 읽은 시점 기준 스타 약 1.26만, 포크 893개였어요. 토픽은 alerting, monitoring, self-hosted, status-page, uptime-monitoring 등이에요.
