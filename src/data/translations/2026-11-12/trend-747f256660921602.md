GitHub README를 처음부터 끝까지 읽고 정리했어요. 설치 명령과 환경변수 표 같은 세부는 줄였어요.

### 무엇인가

**Windmill**은 워크플로, 앱, AI 에이전트를 위한 코드 우선(code-first) 플랫폼이에요. 엔지니어는 20개 넘는 언어로 코드를 쓰고 Git과 동기화하고, 비즈니스 팀은 같은 플랫폼에서 AI로 만들어요. 스스로를 Lovable, Retool, n8n의 셀프호스팅 대안이자 단순화된 Temporal이라고 소개해요. 완전 오픈소스(AGPLv3)이고 Windmill Labs가 전용 인스턴스와 상용 지원을 제공해요.

### AI로 만들고 리뷰로 배포

- **AI 세션**은 워크스페이스 포크에서 스크립트·플로·앱을 AI로 만들고, 라이브 미리보기와 diff를 보고 배포해요.
- 워크스페이스 역할과 폴더로 팀별 작성 범위와 AI가 닿을 수 있는 리소스·스킬·MCP 서버를 제한해요.
- 보호 규칙은 직접 배포를 막아 엔지니어 리뷰 뒤에만 프로덕션에 반영되게 해요. 개발 워크스페이스는 자체 자격증명을 갖고 Compare & Deploy나 Git PR로 승격하고, 워커 그룹으로 AI가 만든 코드를 별도 워커에서 돌릴 수 있어요.

### 핵심 개념

스크립트는 평범한 함수예요. 타입이 있는 인자가 자동으로 폼, HTTP 엔드포인트, CLI 명령이 돼요. 스크립트를 이어 플로로 만들고, 그 위에 UI를 얹을 수 있어요. 스케줄, 웹훅, HTTP 라우트, Kafka, WebSocket, 이메일 등으로 실행돼요. 데이터 쪽으로는 워크스페이스 관리형 Postgres 테이블, DuckDB, 레이크하우스 테이블인 DuckLake, 읽고 쓰는 데이터로 스크립트를 잇는 Pipelines(알파)가 있고 기존 dbt 프로젝트도 그대로 돌려요.

### 개발 도구

CLI(`wmill init`이 Claude Code, Cursor 등을 위한 `AGENTS.md`와 스킬 파일을 만들어요), VS Code 확장, 양방향 Git 동기화, 코딩 에이전트가 스크립트를 실행하고 작업을 모니터링하는 MCP 서버를 제공해요.

### 성능과 구조

- Airflow, Prefect, Temporal과 비교한 벤치마크(가벼운 작업 40개 플로, 오래 걸리는 작업 10개 플로) 모두에서 가장 빨랐다고 주장해요.
- 큐에서 작업을 꺼내 시작하고 결과를 DB에 되돌리는 추가 지연은 약 50ms이고, 가벼운 Deno 작업은 총 100ms 정도라고 해요.
- 상태 없는 API 서버와 워커가 PostgreSQL을 공유하고, 워커는 태그로 작업을 가져가요. 백엔드는 Rust예요. nsjail과 PID 네임스페이스로 작업을 격리하고 워크스페이스마다 암호화 키를 둬요.
- Docker Compose 파일 3개나 Helm 차트로 셀프호스팅할 수 있어요.
