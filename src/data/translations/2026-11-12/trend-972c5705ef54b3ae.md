### 무엇인가

**Human-readable writing**(JangHyun-bin/human-readable-writing)은 전문적인 산문을 위한 휴대용 에이전트 스킬이에요. 대상 런타임은 Claude Code, Codex, OpenCode, Pi, oh-my-pi이고, 런타임마다 검증 범위가 달라요. 연구 노트, 재무 분석, 투자 검토, 정책 메모, 설계 기록, PR 설명, 장애 공지를 다루며, 독자가 주장과 근거·조건·실제 결과를 이어 읽도록 돕는 게 목표예요.

### 지시 내용

스킬은 Markdown 파일로만 배포되고 설치 패키지에 스크립트가 없어요. 모델에게 이렇게 요구해요.

- 압축된 명사구를 "누가 무엇을 하는지" 말하는 문장으로 바꾸기
- 기술 용어와 원문 사실은 유지하기
- 각 조건과 불확실성을 그것이 제한하는 주장 바로 옆에 두기
- 독자의 작업 순서에 맞게 정보 배치하기
- 원문에서 관계가 불분명하면 지어내지 말고 묻기

### 예시

README는 로그아웃 뒤 도착한 프로필 응답이 이전 사용자 데이터를 다시 띄우는 문제를 다룬 PR 설명을 고쳐 보여 줘요. 고친 글은 문제와 해결책(로그아웃 때 `sessionVersion` 증가, 응답 도착 시 버전 일치할 때만 화면 갱신)을 먼저 말하고, "진행 중인 요청은 취소하지 않는다", "브라우저에서만 확인했다"는 한계를 따로 분명히 남겨요. 이 예시는 실제 실행 결과가 아니라 의도를 보여 주려고 쓴 것이라고 밝혀요. 연구 해석, 재무 분석, 정책 평가 등은 영어·한국어 전문 예시가 따로 있어요.

### 한계와 설치

개인 글쓰기 도구로 시작했고 평가가 제한적이에요. 특정 런타임 버전에서 로드되고 몇몇 출력이 원문 사실을 지켰다는 기록만 있고, 이해도·읽기 시간·전반적 글 품질 향상은 입증되지 않았다고 해요. 설치는 `npx skills add`(Node.js 22.20 이상)로 프로젝트 단위 또는 `-g`로 사용자 단위로 하며, `skills` CLI는 익명 사용 데이터를 보내니 `DISABLE_TELEMETRY=1`로 끌 수 있다고 안내해요.
