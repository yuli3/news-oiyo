ZDNet Korea 기사(방은주 기자)를 끝까지 읽고 정리했어요. 기사 끝의 회사 소개 문단 일부는 잘려 있었어요.

### 무엇을 냈나

사이버 위협 인텔리전스 기업 **AI스페라**는 자사 플랫폼 **크리미널 IP(Criminal IP)** 의 위협 정보를 **스플렁크(Splunk)** 에서 쓸 수 있는 새 앱 **'Criminal IP TI Feed'** 를 출시했어요. 스플렁크는 보안 위협 탐지와 IT 시스템 관리를 돕는 글로벌 기업이고, 이 앱은 공식 마켓플레이스 스플렁크베이스(Splunkbase)에서 받을 수 있어요.

### 기능

- 크리미널 IP가 가진 악성 IP 정보와 기업의 **방화벽 통신 기록**을 자동으로 비교·분석해요.
- 내부 시스템이 악성 IP와 통신을 시도했는지, 실제로 연결됐는지를 확인해요.
- 통신이 **차단된 경우와 실제 연결된 경우를 구분**해 위험 수준과 조사 우선순위를 판단하게 도와요.
- 최신 위협 정보를 주기적으로 모으고, 지난 **30일** 통신 기록을 다시 분석해 당시엔 알려지지 않았던 악성 IP와의 통신 이력도 찾아내요.
- 결과는 대시보드로 보고, **슬랙(Slack)** 알림으로 주요 위협을 빠르게 공유할 수 있어요.

### 기존 앱과의 관계

AI스페라는 앞서 스플렁크베이스에 IP 위협 정보 조회용 'Criminal IP Search'와 이상거래·악성 접속 모니터링용 'Criminal IP FDS'를 냈어요. 이번 TI Feed로 IP 조회와 접속 모니터링에 이어 네트워크 위협 분석까지 지원해, 보안관제센터(SOC)의 운영 효율을 높일 수 있다고 해요.

강병탁 대표는 "위협 인텔리전스는 기업 내부에서 실제 발생한 네트워크 통신 기록과 연결될 때 더 유용해진다"며 보안 담당자가 악성 IP와 통신한 자산을 빨리 찾아 위험도가 높은 위협부터 대응하게 돕겠다고 말했어요.
