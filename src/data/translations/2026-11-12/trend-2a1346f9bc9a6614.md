r/LocalLLaMA에 올라온 Hugging Face 모델 페이지(Zyphra/ZONOS3-Mini) README를 빠른 시작 절까지 읽고 옮겼어요. 구조 절과 블로그의 평가 수치는 반영하지 못했어요.

### 무엇인가

**ZONOS3-Mini**는 Zyphra의 소형 오픈소스 텍스트 음성 변환(TTS) 모델이에요. 활성 파라미터 **1억 개**로 자연스럽고 안정적인 음성과 고품질 음성 복제를 낸다고 해요. 휴대폰과 노트북, 브라우저 안에서도 **실시간**으로 돌아가요. 가중치는 **Apache 2.0**이에요.

- 오디오 샘플로 목소리를 복제하거나 나이, 억양, 음색을 조절해 캐릭터 목소리를 설계해요.
- 감정, 속도, 전달 방식을 **단어 단위**까지 조절할 수 있어 게임, 내레이션, 음성 비서에 쓰라고 해요.
- **43개 언어**를 지원해요. 동아시아는 중국어(표준어), 일본어, 한국어가 들어 있고 남아시아 언어도 11개 포함돼요.

### 실행 방법

- **브라우저**: WebGPU로 내 GPU에서만 돌아 설치도 서버도 필요 없어요. 첫 방문에 모델을 받아 캐시해요. 전체 기능의 Zonos Voice Studio와 빠른 복제용 Lite가 있어요.
- **SGLang-Omni**: NVIDIA GPU에서 OpenAI 호환 `/v1/audio/speech` 엔드포인트로 서빙해요. 참고 클립만으로(전사 없이) 음성을 복제하고, 44.1kHz 오디오를 생성하는 대로 스트리밍할 수 있어요.
- **자체 런타임**: GitHub 저장소에 NVIDIA용 CUDA 서버, Apple Silicon용 MLX 서버, C++/ggml 서버와 CLI(CPU·CUDA·Metal·Vulkan), 브라우저 WebGPU 빌드가 있고 같은 HTTP API를 써요. 언어별로 묶은 기본 목소리 27개가 함께 있어요.
- Zyphra Cloud에서 호스팅 버전도 제공해요.
