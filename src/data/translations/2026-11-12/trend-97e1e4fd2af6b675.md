GitHub README 전체를 읽고 정리했어요. 스크린샷 이미지는 텍스트로 옮길 내용이 없어 제외했어요.

### 무엇인가

**Plane**은 이슈를 추적하고, 사이클(README에서는 '스프린트'를 지우고 '사이클'이라고 불러요)을 운영하고, 제품 로드맵을 관리하는 오픈소스 프로젝트 관리 도구예요. "도구 자체를 관리하는 혼란 없이" 쓰는 걸 목표로 한다고 소개해요. 매일 발전 중이라며 포럼과 GitHub 이슈로 의견을 받는다고 해요.

### 설치

- **Plane Cloud**: 무료 계정으로 인프라 걱정 없이 가장 빨리 시작할 수 있어요.
- **셀프호스팅**: 데이터와 인프라를 직접 통제하고 싶으면 Docker Compose, Kubernetes, 올인원 Docker 방식 중 고를 수 있어요. 인스턴스 관리자는 'God mode'에서 인스턴스 설정을 바꿔요.

### 기능

- **Work Items**: 파일 업로드를 지원하는 리치 텍스트 에디터로 작업을 만들고, 하위 속성과 관련 이슈 참조를 붙여요.
- **Cycles**: 번다운 차트 등으로 팀의 진행을 추적해요.
- **Modules**: 복잡한 프로젝트를 작은 모듈로 나눠요.
- **Views**: 필터로 관련 이슈만 보이게 하고 저장·공유해요.
- **Pages**: AI 기능이 있는 리치 텍스트 에디터로 아이디어를 정리하고, 메모를 실행 항목으로 바꿀 수 있어요.
- **Analytics**: 모든 Plane 데이터에 대한 실시간 인사이트로 추세를 보고 병목을 찾아요.

### 문서와 커뮤니티

제품 문서와 개발자 문서를 따로 두고 있고, 로컬 개발은 CONTRIBUTING 문서를 보라고 안내해요. 포럼과 GitHub 이슈로 버그와 기능 요청을 받고 행동 강령을 따른다고 해요.
