ZDNet Korea에 실린 슈퍼마이크로 보도자료(PRNewswire) 기사를 고객 편익 절 앞부분까지 읽고 정리했어요(**partial**). 이후 편익 항목과 제품 구성 세부는 이번 정리에 넣지 않았어요.

### 발표 내용
슈퍼마이크로(나스닥: SMCI)는 11월 5일 IBM, 엔비디아와 함께 새 **KV 캐시 스토리지 솔루션**을 발표했어요. 구성은 이래요.
- AMD EPYC 9005(Turin)를 쓰는 Supermicro Petascale 올플래시 스토리지 서버
- IBM Storage Scale 소프트웨어
- NVIDIA Dynamo 추론 프레임워크
- NVIDIA Spectrum-X 이더넷 네트워킹

이 조합으로 AI 모델이 응답을 시작하는 시간을 크게 줄일 수 있고, KV 캐시 용량을 GPU 메모리 한계 너머로 넓혀 GPU 활용률과 처리량을 높이면서 서비스 중단 없이 용량을 늘릴 수 있다고 해요. 찰스 리앙 CEO는 에이전틱 AI와 긴 컨텍스트 다중 턴 생성형 AI 같은 고처리량 추론을 하는 기업과 네오클라우드 사업자가 병목을 풀어야 GPU 효율이 오른다고 말했어요.

### 왜 KV 캐시인가
추론은 프리필과 디코드 두 단계예요. 프리필에서 입력을 토큰으로 바꾸고 LLM이 처리해 중간 KV 상태를 만드는데, 이를 영구 저장형 KV 캐시에 두면 같은 컨텍스트를 다시 계산하지 않고 재사용할 수 있어요. 에이전트 워크플로, 코딩 도우미, 긴 컨텍스트 RAG, 멀티모달, 다중 턴 앱은 KV 상태를 많이 만들어 GPU·CPU 메모리를 금방 넘기기 때문에 대용량 공유 네트워크 스토리지로 옮겨야 한대요.

### 검증 결과(보도자료 기준)
- 세 회사가 높은 동시 처리, 다른 워크로드가 네트워크를 간섭하는 상황까지 포함해 클러스터 수준에서 시험했어요.
- 1,200억 파라미터 LLM 테스트에서 영구 KV 캐시는 13만 토큰 프롬프트의 TTFT를 **최대 56배** 줄였어요.
- 입력이 3만에서 13만 토큰으로 늘 때 KV 캐시를 쓰면 TTFT가 0.377초만 늘었고, 쓰지 않으면 29.55초 늘었어요.
