AI타임스 기사 전문을 읽고 정리했어요. 한국어 기사라 번역 대신 요지를 옮겼어요.

### 공개 내용
문샷 AI는 4일(현지시간) 허깅페이스로 **키미 K3.1 프로** 가중치를 배포했어요. 지난달 출시 때 예고한 일정이에요. 저장소 용량은 약 1.56TB이고 가중치는 96개 파일로 나뉘어 있으며, 모델 설정과 입력 처리 코드도 함께 올렸어요.

### 모델 사양
- 총 2조8,000억 파라미터 중 추론 때 1,040억을 활성화하는 MoE 모델
- 텍스트와 이미지를 처리하고 최대 약 100만 토큰 문맥 입력
- 전체 93개 계층 중 69개는 KDA, 24개는 게이트형 DSA. 키미 K3에서 전체 어텐션을 하던 '게이트형 MLA' 계층을 DSA로 바꿨어요. DSA는 입력 토큰 중 참조할 대상을 골라 긴 문맥 처리 효율을 높이는 기술이에요.
- 가중치는 MXFP4, 활성값은 MXFP8을 쓰는 저정밀 구조이고, 학습 단계부터 양자화 인식 학습(QAT)을 적용했어요.
- 자체 구동용으로 vLLM, SGLang, TokenSpeed 추론 엔진을 권장하고, 문샷 AI API로도 쓸 수 있어요.

### 라이선스 조건
사용, 수정, 미세조정, 재배포, 상업적 활용은 자체 라이선스로 허용해요. 다만
- 모델 서비스 사업자와 계열사 합산 매출이 연속 12개월 동안 2,000만 달러(약 268억 원)를 넘으면 상업적 이용 전에 별도 계약을 맺어야 해요.
- 이 모델을 쓰는 상용 제품의 월간 활성 사용자가 1억 명을 넘거나 월매출이 2,000만 달러를 넘으면 화면에 모델명을 표시해야 해요.
- 내부 이용과 문샷 AI 공식 제품·인증 추론 파트너를 통한 이용에는 이 조건이 붙지 않아요.

### 안전 조치
키미 K3.1 프로는 코딩, 3D 제작, 금융 연구 같은 에이전트 작업을 강화한 모델이에요. 문샷 AI는 출시 때 가중치 공개에 따른 악용 가능성을 줄이려고 중간 학습 데이터와 강화학습 과제에서 사이버 보안 관련 내용을 골라 뺐다고 설명했어요. 일반 코딩 능력은 유지하면서 취약점 악용 능력을 낮추려는 조치예요.
