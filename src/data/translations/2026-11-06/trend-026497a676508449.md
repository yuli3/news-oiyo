### 소개
작성자는 Qwen-Image 2.1 Turbo를 중심으로 한 로컬 사진 편집기 **Kokon**의 개발자예요(stable-diffusion.cpp 기반, Mac에서는 자체 엔진). 0.12 버전에 **Layers lab**을 더했어요. 이미지 속 객체를 클릭하면 각각을 별도 레이어로 떼어 내고 그 뒤 배경을 다시 그려 줘서, 객체를 옮기거나 PSD로 내보낼 수 있어요.

### 파이프라인
Qwen-Image 2.1은 레이어 출력이 없어서 편집 모델을 둘러싼 파이프라인으로 만들었어요.
1. **선택**: 클릭하면 MobileSAM(ONNX, CPU, 44MB)이 마스크를 만들어요. 한 번 더 클릭하면 더 큰 부분을 잡아요.
2. **잘라내기**: Fast는 CPU용 matting 모델(객체당 몇 초), Quality는 머리카락·털 경계를 Qwen이 다시 그려요.
3. **채우기**: 마스크 편집으로 객체 뒤를 다시 그려 배경에 구멍이 없게 해요. 가장 비싼 단계로 RTX 5070 Ti에서 객체당 15–25초, M2 Pro에서 1–2분이 걸려요.
4. **장면에 섞기(선택)**: 객체를 옮긴 뒤 각 객체가 어디 서 있는지 읽어(수정 가능) 접촉 그림자와 반사를 한 번 더 편집해 끌 수 있는 레이어로 넣어요.

### 아직 실패하는 것
- 큰 객체를 지운 자리에 새 객체를 지어내기도 해요(큰 사람을 지우면 다른 사람이 나타남).
- 붙어 있는 사람이나 군중은 합쳐지거나 잘못 나뉘어요.
- 다른 객체에 가려진 부분은 완성되지 않아요.
- Blend는 아직 잘 안 될 때가 많고, 객체별보다 장면 전체 blend가 나아요.

작성자는 8단계 모델로는 조정에 한계가 있어 실험 기능으로 내놓고 실제 사용자가 겪는 문제를 고치겠다며, 실패 사례(이미지와 클릭 위치)를 보내 달라고 했어요.

### 지난 글 이후 바뀐 점
- 0.11부터 로컬 서버 구조가 됐어요. 앱이 127.0.0.1의 서비스와 통신하고, "Other devices"를 켜면 LAN의 휴대폰이나 다른 PC에서도 쓸 수 있어요(비밀번호, 기본 꺼짐, 해시·속도 제한). NVIDIA용 Docker 이미지, 헤드리스 Linux용 옵션, 에이전트가 쓸 수 있는 MCP 서버(npm `kokon-mcp`)도 있어요.
- Apple Silicon용 Qwen-Image 2.1 엔진을 Swift/Metal로 직접 짰어요. M2 Pro에서 1MP 이미지당 약 1분으로 범용 백엔드보다 4배 빠르고, 기여자가 M5 GPU 신경 가속기 경로를 더해 M5 Pro에서 37초가 29초로 줄었어요.

무료(AGPL)이고 Windows, macOS 15+, Linux를 지원해요. NVIDIA 12GB(8GB 베타), AMD/Intel은 Vulkan(베타)이에요. 가중치는 Qwen 라이선스(비상업)를 따라요.
