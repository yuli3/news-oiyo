OpenAI 보안 문서(2026-11-04)의 개요와 방법론 첫 문단까지 읽고 옮겼어요(**partial**). 방법론 세부와 결과 분석은 이번 번역에 넣지 않았어요.

### 요약
OpenAI는 취약점 발견, 익스플로잇, 패치를 자율로 수행하는 파이프라인을 개발했어요. 사이버 모델로 한 번 돌렸을 때 Linux의 **로컬 권한 상승(LPE) 취약점 948건**을 검증하고 패치를 만들었고, API 비용은 **120만 달러**였어요.

예전에는 발견 하나하나마다 따로 오랜 조사가 필요했던 보안 연구가 점점 체계적인 프로세스로 돌아가고 있다고 해요. 취약점 발견은 확장하기 쉬워졌지만, 우선순위를 정하고 검증하는 일이 여전히 운영상 병목이래요.

### 결과
통제된 연구 환경에서 Linux 커널의 보안 결함을 찾는 프로토타입을 만들었어요.
- 커널 후보 발견 **2,308건** 식별·분석
- 그중 **1,724건**을 동적으로 재현
- 권한 없는 로컬 사용자가 root를 얻을 수 있는 LPE 익스플로잇 **948건** 생성

이 증거로 보고할 취약점의 우선순위를 정하고, 메인테이너 검토용 후보 패치를 만들었어요. Linux 커널 커뮤니티의 안내에 따라 치명적 취약점부터 시작했고, Patch the Planet 파트너들과 추가 보고·패치를 진행 중이에요.

### 배경
6월 Patch the Planet 이니셔티브에서 OpenAI는 GPT-5.5 Cyber가 Linux 커널 취약점을 찾고 이를 검증·보고하려고 LPE 익스플로잇 24건을 만들었다고 공유했어요. 이번에는 이를 곧 나올 사이버 모델 기반 파이프라인으로 넓혀 발견, 동적 검증, 익스플로잇 가능성 평가, 패치 생성까지 다뤘어요. 끝난 뒤에는 사람 연구자가 결과를 검토하고 발견한 취약점을 패치와 함께 보고했어요.

### 방법론(개요)
파이프라인은 먼저 Linux 커널에서 보안상 중요한 부분을 찾고, 그 감사 대상을 정적으로 스캔해 후보를 뽑고, 격리 환경에서 동적으로 재현한 뒤, 익스플로잇 가능성을 보여 주는 개념 증명(PoC) 익스플로잇을 만들고 패치를 생성하는 순서로 움직여요.
