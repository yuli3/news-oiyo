### 무엇인가요
JuiceFS는 Apache License 2.0으로 공개된 고성능 POSIX 파일시스템이에요. 데이터는 Amazon S3 같은 오브젝트 스토리지에 영구 저장하고, 메타데이터는 상황에 따라 Redis, MySQL, TiKV 등 호환 데이터베이스 엔진에 저장해요. 코드 수정 없이 대용량 클라우드 스토리지를 빅데이터, 머신러닝, AI 등 운영 환경 플랫폼에 바로 연결해 로컬 스토리지처럼 효율적으로 쓰게 해준대요.

### 주요 기능
- **완전한 POSIX 호환**: 로컬 파일시스템처럼 기존 앱에 그대로 붙어요.
- **Hadoop 호환**: Hadoop Java SDK가 Hadoop 2.x·3.x와 생태계 컴포넌트를 지원해요.
- **S3 호환**: S3 게이트웨이로 S3 호환 인터페이스를 제공해요.
- **클라우드 네이티브**: 쿠버네티스 CSI 드라이버를 제공해요.
- **공유 가능**: 수천 개 클라이언트가 동시에 읽고 쓸 수 있어요.
- **강한 일관성**: 확정된 변경은 같은 파일시스템을 마운트한 모든 서버에서 바로 보여요.
- **성능**: 지연은 몇 밀리초 수준까지 낮고, 처리량은 오브젝트 스토리지 규모에 따라 거의 무한히 늘릴 수 있대요.
- **암호화**: 전송 중·저장 시 데이터 암호화를 지원해요.
- **전역 파일 잠금**: BSD 잠금(flock)과 POSIX 레코드 잠금(fcntl)을 모두 지원해요.
- **압축**: LZ4나 Zstandard로 모든 데이터를 압축할 수 있어요.

### 아키텍처
세 부분으로 이뤄져요.
1. **JuiceFS 클라이언트**: 오브젝트 스토리지와 메타데이터 엔진을 조율하고 POSIX, Hadoop, 쿠버네티스, S3 게이트웨이 같은 인터페이스를 구현해요.
2. **데이터 스토리지**: 로컬 디스크, 퍼블릭·프라이빗 클라우드 오브젝트 스토리지, HDFS 등에 데이터를 저장해요.
3. **메타데이터 엔진**: 파일 이름, 크기, 권한, 생성·수정 시간, 디렉터리 구조 같은 메타데이터를 Redis, MySQL, SQLite, TiKV 등에 저장해요. 예를 들어 Redis는 빠른 인메모리 키-값 저장소라 메타데이터 저장에 특히 잘 맞는대요.
