GitHub 저장소(musicurgy/delta-inference-engine) README의 앞부분(소개와 빠른 시작)을 읽고 옮겼어요(**partial**). Reddit 글 본문의 v0.93 변경 상세와 README 뒷부분은 이번 번역에 넣지 않았어요.

### 소개
**Delta Inference Engine**은 DeepSeek-V4.1-Flash-1017의 5,520억 파라미터 전체(전문가는 2비트)를 일반 소비자용 PC 한 대에서, Windows 네이티브로 돌려요. `http://127.0.0.1:8080/v1`에서 OpenAI 호환 API를 제공하고 컨텍스트는 최대 1M 토큰이에요. Strata 위에 만든 Xolotl의 Windows 포트이고, 업스트림은 Linux 대상이에요.

### 필요한 것
- NVIDIA RTX 12GB 이상(24GB가 가장 빠름)
- RAM 64GB 이상(128GB 이상 권장)
- 기본 모델용으로 빠른 NVMe에 약 320GB 여유 공간(드라이브 속도가 중요)

### 빠른 시작
1. 저장소를 ZIP으로 받거나 짧은 경로에 git clone 해요. Releases의 build-ds41 zip은 따로 받을 필요가 없어요.
2. `Start DeepSeek.bat`을 더블클릭하면 처음에는 빠진 것을 단계별로 설치하고, 큰 작업 전에는 물어봐요.
   - Python 3.10–3.12가 없으면 winget으로 python.org Python 3.11을 현재 사용자에게만 설치하자고 해요.
   - 엔진은 CPU에 맞는 사전 빌드본(1GB 미만)을 받거나, Visual Studio Build Tools·CUDA Toolkit·Git이 있으면 직접 빌드해요.
   - 모델은 RAM에 맞는 것을 추천해 Hugging Face에서 받아요(233–395GB, SHA-256 검증, 이어받기 가능).
3. 서버가 뜨면 브라우저에 채팅 페이지가 열려요. 앱은 `/v1`(OpenAI)이나 `/v1/messages`(Anthropic)로 연결하고 API 키는 아무거나 써도 돼요.

다음부터는 같은 파일을 다시 실행하면 약 1분 안에 준비돼요. 다른 양자화 모델은 `Choose Model.bat`, 업데이트는 `UPDATE.bat`이나 git pull로 해요.
