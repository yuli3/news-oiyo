- 11월 4일 올라온 Unsloth의 새 **UD-IQ3_XXS**(Dynamic v3.1)는 16GB 카드에서 많이 쓰는 GSQ-RCO IQ3_S와 크기가 같지만 더 정확해요. wikitext perplexity가 3.382에서 3.247로 내려가 BF16(3.273)과의 차이가 사실상 사라졌어요. 대신 디코드 속도가 1–3.5% 줄어요.

### Lamina 드래프팅
Basalt는 모델 자체의 MTP 레이어로 드래프트를 만들고, Lamina는 그 레이어를 더 학습한 버전이에요. 텐서 구조가 같아 그대로 바꿔 끼울 수 있어요. 실제 세션 재생에서 드래프트 채택률이 83.1%에서 85.8%로 올랐어요. Lamina README는 temperature 0.7, 최대 3개 드래프트를 권하지만, 3개 제한은 도구 호출이 많은 작업에서 1–1.8% 느렸고 0.7은 모델 출력 자체를 바꿔서 모델 기본 샘플링(1.0/0.95/20)을 유지했대요.

### 작성자가 Basalt에 낸 변경(모두 업스트림 PR)
- Host KV prefault: 긴 대화의 KV 캐시가 처음 RAM으로 넘칠 때 0.6–2.4초 멈추던 것이 약 75ms로 줄었어요.
- 일반 페이지 기반 Host KV pool: 메모리가 조각난 PC에서 투명 hugepage 압축 때문에 생기던 1.5–3.7초 지연이 약 23ms로 줄었어요.
- 디코드 루프 대기에 spin-then-yield: 드래프트 구간당 시간이 약 1.3% 줄었어요.
- 예전 v1 expert start profile이 이 PC에서 v0.2.0보다 2% 빨랐어요.
- 그 밖에 대화 디스크 캐시 스트리밍, expert 교체용 `--adapt-margin`, RAM 복사 없는 elastic KV, 각종 타이밍 진단을 더했어요.

### 설치
작성자의 Basalt 브랜치(`flashnext-5080-setup`)에 설치 스크립트가 있어요. 스크립트는 PC를 점검하고 빌드한 뒤 약 90GB(고정 리비전, 파일마다 SHA-256 검사)를 내려받아 모델 파일과 설정을 만들어요. CUDA 13을 쓰는 RTX 카드, 64GB RAM, 여유 디스크 약 180GB가 필요해요. 이미 GSQ-RCO IQ3_S를 받았다면 28.8GB n-gram 샤드를 재사용할 수 있어요.
