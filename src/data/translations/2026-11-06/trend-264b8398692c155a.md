### 모델 소개(Reddit 글)
**Xing4.0-29B-A4B**는 China Telecom 인공지능기술 회사가 만든 Xing 시리즈(옛 TeleChat)의 차세대 모델이에요. 총 29B 파라미터 중 토큰당 4B만 활성화되고, 256K 컨텍스트를 기본 지원하며 512K까지 늘릴 수 있어요. 이 규모로는 처음으로 **Ascend NPU와 MindSpore 프레임워크만으로 학습**한 모델이라고 해요.
- mHC + MLA + MTP 구조로 다단계 계획, 도구 호출, 긴 추론을 지원해요.
- Ascend 910C 클러스터 최적화로 학습 처리량을 기본 대비 약 96% 높였대요.
- LLaMA-Factory·MindFormers 파인튜닝, SGLang·vLLM·KTransformers 추론을 지원하고, OpenCode, Claude Code, OpenClaw, Hermes 같은 에이전트 프레임워크에 맞춰 형식을 정렬했어요.

### PR 내용
이 PR은 아키텍처 등록과 하이퍼파라미터, 텐서 로딩, HF→GGUF 변환 스크립트, mHC/MLA/MoE/MTP 추론 그래프를 더해요. **새 ggml 연산자는 넣지 않았어요.**
- mHC: deepseek4의 hyper-connection 융합 연산자 3개를 재사용(CPU·CUDA 구현 완료)
- MLA 어텐션: deepseek2와 같은 표준 연산 조합과 q/kv 흡수 최적화
- MoE와 MTP 헤드: 기존 범용 연산자로 구현하고, MTP는 기존 투기적 디코딩 틀에 연결
