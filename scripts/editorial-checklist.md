# news.oiyo.net 특별 아티클 발행 전 체크리스트

> 특별 아티클(블로그형, 데일리 큐레이션 외)은 발행 전 이 체크리스트를 통과해야 한다.
> 근거: company-brain `information-hygiene-editorial-policy` 5원칙의 news 특화 적용.
> 결정권자: 사용자(2026-06-30 비준, 2026-07-04 재확인).

## ❌ 피해야 할 것 — 하나라도 해당하면 발행 보류

- [ ] **이해관계 은폐** — 인용 매체·발화자의 특정 이익/회사/관계자/광고 링크를 무시하지 않았는가? (예: SBS↔태영건설)
- [ ] **종교·집단 관계 은폐** — 매체 배후 종교/이익 집단 관계를 무시하지 않았는가? (예: 세계일보↔통일교)
- [ ] **과장 단어** — 학계·사회 합의를 벗어난 선정적 표현이 없는가? (예: "안 산 사람=벼락거지")
- [ ] **선택적 나열** — 특정 입장·특정 사실만 집중 나열하지 않았는가? (steelman: 주요 입장 각각을 공정히)
- [ ] **원인 무시** — 결과만 보도하고 원인·구조를 생략하지 않았는가?

## ✅ 지향할 것 — 구조

- [ ] **1문단 요약**을 맨 앞에 두었는가?
- [ ] **원인-결과 분석**이 있는가? (무엇이 무엇을 낳았는가)
- [ ] **상관관계 분석**이 있는가? (더 큰 구조와의 연결 — 예: 전세계 화폐 공급 확대 → 국내 부동산 상승)

## 공통 (5원칙)

- [ ] 사실/의견 분리 — 검증 가능한 사실만 단정, 평가·전망은 attribution
- [ ] 출처 의무 — 사실 주장에 공식·1차 출처 + 확인일자
- [ ] 프레임 투명화 — 용어는 학술/원의 정의 우선
- [ ] 비개입 — 무엇을 믿/투표/구매하라 권하지 않음 (금융≠투자조언·정치 중립·건강≠의료자문)

## 아티클 아이디어 백로그
- 가짜뉴스·선동·거짓 필터링 프롬프트 공유 (사용자가 복붙해 LLM에 바로 쓰는 형태)
- ChatGPT/Gemini/Claude 프롬프트 프리필 링크 (실현 가능성: chatgpt.com·claude.ai 쿼리 파라미터 지원 여부 재확인 필요)
